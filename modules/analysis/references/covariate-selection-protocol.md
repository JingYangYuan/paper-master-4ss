# 协变量选择协议

管三件事：**该条件在什么上、怎么条件、代价是什么**。不管 DiD/IV/RD 的识别设计。

## 适用场景

可观测选择设计：匹配、倾向得分加权、回归调整、双稳健（AIPW）、熵平衡。

## 前置条件

- 已写出目标参数：ATE / ATT / ATO，三者需要的假设与重叠条件不同。
- 已确认没有不可观测混杂这条后门（否则走 IV/RD/DiD/合成控制）。

## 阶段 I：设计

**动作 1 先写估计量，再写假设对**
- 非混淆是**两条**假设：`(Y(0),Y(1)) ⟂ D | X`（不可检验）+ `0 < p(X) < 1`（可在数据里查）。
- ATE 需要两条；ATT 只需 `Y(0) ⟂ D | X` 且 `p(X)<1`；ATO 由权重本身定义总体。
- **不同估计量目标不同**：最近邻匹配目标 ATT、HT-IPW 目标 ATE、overlap 权重目标 ATO、修剪样本目标的是「原总体」以外的参数。选方法前先声明要哪一个。
- 两条要记住的话：条件独立是**分派过程**的假设，不是数据的性质——平衡表、R²、设定检验都支持不了它，只能像排除限制那样做制度性的、可反驳的论证；**协变量多不构成证据**，条件在错误的大集合上比条件在小而对的集合上更糟。

**动作 2 每个协变量给一个处置（填表，先于任何估计）**

| 类别 | 在 DAG 中的角色 | 纳入？ |
|---|---|---|
| 混淆变量 | D 与 Y 的共同原因 | **纳入** |
| 仅预测结果 | 只影响 Y | 纳入（降方差、降低对残余混杂的敏感度） |
| 仅预测处理（「似工具」） | 只影响 D | **不纳入**——放大方差并**放大**残余混杂偏误 |
| 中介／处理后期 | 在 D→Y 路径上 | **不纳入**——条件掉要测的那部分效应 |
| 对撞 | D（或其原因）与 Y（或其原因）的共同结果 | **不纳入**——条件会**制造**关联 |
| 未观测混淆的代理 | 有测量误差 | 通常纳入（部分调整，可能引入新偏误） |
| 处理后期但平行趋势需要 | 被 D 影响且改变未处理结果 | 特殊机制，走 DiD 协议 |

**没有处置的变量 = 没想过的变量。** 这张表进论文附录；它的作用与 IV 协议的渠道穷举表相同：断言不可反驳，逐行处置可以。

**动作 3 测量时点按「预期日」而不是「实施日」定**
- 处理前 = **任何人可能对处理做出反应之前**：公告、指定、申报、第一波可信传闻之前。
- 公告后、实施前的产业结构／资格分／调查波次，都可能已是处理后期。
- 只有公告后测量时：用更远的滞后（并论证）、按坏控制处理（走 DiD）、或两版并报并把差距当界。
- 两个例外（预处理变量并不总安全）：M-bias（预处理对撞）与预处理「仅预测处理」变量的偏误放大。

**动作 4 声明比较池、样本与聚类**
- 未处理单位从哪来、有多少、变异层级与聚类维度、修剪或匹配**之前**的样本长什么样。
- 每个 Stage III 的数字都是关于这个样本的数字；换比较池对估计的影响大于换估计量。

## 阶段 II：设计阶段——重叠与平衡，结果变量不进房间

**铁律（本文件最高回报的习惯）**：整个协变量阶段**不看结果变量**做完——定倾向得分、修剪、匹配、重设、再平衡，全部在结果未知时冻结设计，然后估计一次。对着**平衡**迭代是正当的；对着**估计值**迭代是多几步的设定搜索。

**动作 5 先看重叠，再选任何东西**
- 画按处理状态分组的 `p̂(X)` 分布；报三个数：处理组高于对照最高分的质量、对照组低于处理组最低分的质量、是否有堆积在 0/1。
- 修剪规则四选一，并**说明它对估计量的改变**：固定卡尺（0.1/0.9）、Crump 最优规则、overlap 权重（只加权不丢弃，目标 ATO）、共同支撑限制（目标 ATT）。
- **修剪不是稳健性检验，是换问题**：修剪后的参数是重叠子总体的效应；报各臂丢弃数与丢弃者与保留者的协变量差异。需要丢掉一半处理单位的设计，结论应写成「数据只对**这个**子总体识别效应」。

**动作 6 选调整方法（按情形）**

| 情形 | 首选 | 理由 |
|---|---|---|
| 少数离散协变量、格子填充良好 | 分层／精确匹配 | 透明、非参数、无函数形式 |
| 多协变量、重叠好、对照池大 | 倾向得分加权或双稳健 | 降维且不产生空格子 |
| 连续协变量、要 ATT | 匹配 + 偏差修正 | 匹配误差是 O(N^{-1/k})，必须修正 |
| 重叠差 | overlap 权重，或明确重定义总体 | 不要用灵活模型外推后再叫它调整 |
| 平衡是硬约束 | 熵平衡／CBPS／稳定平衡权重 | 平衡是被 impose 的，不是盼来的 |
| 高维 X、灵活 nuisance | DML/TMLE + 交叉拟合 | 转 ML 与因果 ML 协议 |
| 问题本身是异质性 | 因果森林／元学习器 | 转异质性协议 |

**动作 7 正确地查平衡**
- 报**标准化均值差**，不报 t 检验：平衡是这个样本的性质，不是关于总体的假设；平衡 t 检验把不均衡与样本量混在一起，删单位可以「改善」p 值却让不均衡更糟。|SMD|<0.1 是惯例不是定理。
- 平衡**整个分布**：方差比、分位数/eCDF 或 KS、以及结果模型在意的交互与平方项。
- **平衡必要但永不充分**：X 上完美平衡对不可观测量什么也没说——那是动作 9 的事。

## 阶段 III：估计、施压、报告或退出

**动作 8 正确的修正与正确的标准误**
- 连续协变量上匹配不精确时做**偏差修正**（减去配对间回归差）。
- **不要对最近邻匹配估计量做 bootstrap**（标准 bootstrap 对匹配估计量无效）；用解析方差，或改用推断已确立的加权/双稳健估计量。
- **估计倾向得分，不要用已知得分**（估计得分加权更有效，且其不确定性要进 SE）。
- 任何 ML nuisance 都要交叉拟合；聚类在分派层级，报**修剪与匹配之后**的 N 与簇数。

**动作 9 对不可检验的那一半施压**

| 工具 | 回答什么问题 |
|---|---|
| Rosenbaum 界 | 配对内偏离随机分配的比值要多大才翻转显著性 |
| Cinelli–Hazlett 稳健值 | 混淆变量要比某个已观测协变量强多少倍才能杀掉估计 |
| Oster δ | 不可观测选择要比可观测选择强多少才能把效应推到零 |
| 安慰剂／负对照结果 | 设计会不会在理论上不该有效应的地方「发现」效应 |
| 安慰剂处理／前期检验 | 处理组在处理前是否已经不同 |
| 界（Manski/Lee） | 不依赖该假设时数据能说什么 |

**报敏感性必须带基准**：「一个不可观测混淆变量要在处理与结果上都比人均 GDP 强 1.8 倍才能翻转」是论证；「估计是稳健的」不是。

**动作 10 报告清单与退出判据**

报告：目标参数及其所需假设版本 · 逐行处置的协变量表 · 测量时点规则与预期日 · 比较池与规模 · 倾向得分设定 + **且说明它是盲结果对着平衡选的** · 重叠图与修剪规则、各臂丢弃数、修剪后总体 · 调整方法与它目标什么 · SMD 平衡表（前后、含高阶矩与关键交互）· 加权估计量的有效样本量 · 匹配的偏差修正 · 方差估计量及理由 · 带基准的敏感性分析 · 若估计随协变量集变化，**全部设定并说明 DAG 支持哪一个**。

| 退出判据 | 触发条件 | 动作 |
|---|---|---|
| A 没有预处理协变量集能堵住后门 | 选择走的是不可观测量 | 去找变异：IV／RD／DiD／合成控制 |
| B 没有重叠 | 处理单位没有可比对照 | 重定义总体并说明，或停止 |
| C 结论依赖哪些协变量进入且无 DAG 理由 | — | 作为敏感性诚实报告，不挑一列当主设定 |
| D 敏感性显示可信混淆就能翻转 | — | 论文的真实主张变成「要求完全无不可观测混淆」 |

触发后禁止：加控制直到系数像样；用「从回归换到匹配」来解决不可观测选择（匹配是估计量不是设计，它做的是同一条假设）；报 R² 最大的设定；把平衡表说成外生性的证据。

## 常见失败模式

条件在「仅预测处理」的变量上（放大偏误）；把中介当控制；用公告后测的变量当预处理；用平衡 t 检验判断平衡；用 bootstrap 给匹配估计量做推断；把修剪当稳健性；敏感性只写「稳健」。

## 风险与限制

- 「盲结果选设计」对既有流程顺序有约束：描述统计若含结果变量，须在协变量阶段之后再跑。
- 修剪与匹配改变目标总体，任何跨研究比较都要说明总体。
- 本协议不解决不可观测混杂，也不替代识别设计。
