# 合成控制八动作协议

一个或少数处理单位、有较长处理前期、要构造加权对照的情形，走本协议，不走 DiD 协议。
核心判断：**「图看起来贴」不是拟合判据；推断靠安慰剂分布，不靠标准误。**

## 适用场景与分流

- 一个处理单位（地区、国家、企业）：经典合成控制。
- 少数处理单位且采纳时点不同：合成双重差分或交互固定效应类方法。
- 多数处理单位且从未处理组充足：回 DiD 协议。

## 动作 1：定目标参数，确认是不是合成控制问题

三个问题先答：
1. **处理单位有几个**（决定走哪一族）。
2. **处理前有多少期**：偏误随处理前期数增长而缩小，但前提是拟合精确；期数少 + 拟合不精 = 未观测异质性不会被抵消。
3. **目标参数**：处理后各期 ATT 及其汇总方式（逐期／平均／累积），**看结果之前定**。

产出：单位、时间、结果、处理时点的形式化陈述 + 一句「为什么这是合成控制不是 DiD」。

## 动作 2：先看数据形状

拟合之前画三件事：处理状态矩阵（含是否有状态回退）、缺失结构、结果轨迹。
**缺失极敏感**：供体在处理前缺一段，就不该在池子里。

## 动作 3：选供体池（它是一个选择，不是「剩下的所有单位」）

三条排除：
1. 受溢出影响的单位（邻近地区被同一政策间接影响 ⇒ 稀释效应）。
2. 结构上不可比的单位：处理单位在水平上是「独角兽」时，非负且和为一的权重**在定义上**配不出它。
3. 自身在处理后期经历其他冲击的单位。

**凸包含义**：经典合成控制要求权重非负且和为一，保证反事实是内插不是外推；代价是处理单位必须落在供体凸包内。落不进去先回本动作查池子，不要急着换估计量。

## 动作 4：拟合，并判断拟合够不够好

**两件产出**：
1. **平衡表**：预测变量在处理单位、合成控制、**供体池简单平均**三列。第三列是核心对照——合成控制配得上而简单平均配不上，才是「合成」有价值的证据。
2. **处理前 RMSPE**：一个数，动作 6 的推断直接用。

拟合不好时的顺序：回动作 3 查池子 → 回动作 1 问处理前期数 → 最后才考虑放松约束（那是用**模型依赖**换拟合）。

## 动作 5：方法路由（按情形，不按偏好）

| 情形 | 方法类型 |
|---|---|
| 经典合成控制 + 要预测区间 | 合成控制预测区间法 |
| 拟合不完美，用结果模型纠偏 | 交互固定效应／矩阵补全类 |
| 怀疑交互固定效应（因子结构） | 交互固定效应类 |
| 想用矩阵补全 | 矩阵补全类 |
| 处理单位多、要 DiD 与 SC 的双稳健 | 合成双重差分 |
| 关心分布而不只是均值 | 分布型合成控制 |
| 想在一个接口里横向比较多个估计量 | 多估计量封装 |

**放松非负约束有代价**：增广／岭类方法允许负权重换来更好拟合，但因果推断从此依赖结果模型的正确性，而不是「用近邻加权近似反事实」。这个代价必须写进论文。

## 动作 6：推断——安慰剂分布，不是标准误

只有一个处理单位时常规标准误无从谈起。做法：
1. 每个供体依次当作「处理单位」重跑，得到一组安慰剂 gap 路径；
2. 对每个单位算 **RMSPE 比值 = 处理后 RMSPE / 处理前 RMSPE**；
3. 按比值排序，真实单位的**排名／单位数**即 p 值。

**为什么用比值不用效应大小**：处理前就拟合很差的安慰剂单位，处理后 gap 大是理所当然；除以处理前 RMSPE 把这类剔除。

互补（不是替代）：预测区间（把不确定性拆成权重估计与处理后噪声）、等价检验（TOST）与阈值化判据阶梯——后者优先用成熟实现，不要在本协议里重造。

## 动作 7：稳健性与报告（必报四样）

1. **权重表**：哪些单位拿到非零权重、各是多少。稀疏权重是合成控制相对回归的核心优势；把两者并排是「为什么不用回归」的核心论证。
2. **平衡表**（含供体池简单平均列）与**处理前 RMSPE**。
3. **留一法**：逐个剔除最大权重供体，看结论是否由单个供体撑起。
4. **时间安慰剂**：把处理时点提前若干期，应当看不到效应。

呈现：路径图（处理单位 vs 合成控制）+ gap 图；安慰剂 gap 叠图；RMSPE 比值排序图。

## 动作 8：退出判据（建议非门禁）

| 判据 | 触发条件 | 动作 |
|---|---|---|
| A 处理前拟合无法接受且池子已查过 | 处理单位落在供体凸包之外 | 数据里没有它的反事实；换设计 |
| B 处理前期数太少 | 长前期与精确拟合两者都缺 | 换时间窗口或换设计 |
| C 安慰剂推断给不出证据 | 供体太少（p 值最小可能值 1/N）或真实单位排在安慰剂中间 | 换设计或改层级 |
| D 供体池不干净 | 无法排除的溢出，或多个供体处理后期有别的冲击 | 换对照情境 |

触发后禁止：换一个允许外推的估计量把拟合「修好」再照常报告。

## 常见失败模式（审阅已有研究按频率排序）

只报点估计与一张路径图、没有安慰剂推断；没有平衡表或平衡表缺「供体池简单平均」列；没有权重表；供体池是「剩下的所有单位」；用了增广／岭方法但不说明模型依赖代价。

## 风险与限制

- 八动作编排是来源方约定；方法卡的 API 与阈值不在本协议内。
- 分布型合成控制与多估计量封装的成熟度低于经典合成控制，正文只列情形不推荐默认。
