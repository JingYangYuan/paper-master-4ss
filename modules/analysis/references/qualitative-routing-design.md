# 质性研究路由与设计

> 覆盖质性研究全过程模型中的**定位立场 → 聚焦困惑 → 设计方案**阶段。用于确定分析路径前的方法路由、设计家族选择和抽样策略。

---

## 0. 质性研究全过程模型

质性研究不是从"拿到数据"开始的。分析决策应与前序阶段的设计选择保持一致：

1. **定位探究立场**：明确世界观（后实证主义/建构主义/批判/实用主义）如何约束编码和分析策略
2. **聚焦研究困惑**：将研究问题中的"核心现象-参与者-探究行动"映射到分析方法
3. **设计方案**：选择设计家族（叙事/现象学/扎根/民族志/个案/行动研究/口述史）——见 §1.1
4. **收集密集数据**：访谈、观察、文档/影像、田野札记 ——见 `qualitative-data-collection.md`
5. **归纳迭代分析**：准备数据 → 通读 → 备忘录 → 编码 → 缩减编码 → 构建主题 → 关联主题 → 检验解释 ——见 `qualitative-analysis-methods.md`
6. **验证与反身审核**：三角测量、成员检验、负面案例、同行汇报、审核链、编码者协议、反身性写作 ——见 `qualitative-quality-integration.md`
7. **写作与意义呈现**：厚描述、证据呈现、研究者角色、局限性、设计特定结构 ——见 `qualitative-quality-integration.md`

**分析阶段的衔接**：步骤 5-6 是本参考体系的核心覆盖范围，但步骤 1-4 的决策直接影响分析阶段的选择。例如，选择扎根理论意味着必须在分析阶段执行理论抽样和持续比较；选择现象学意味着必须在分析阶段执行本质还原。

## 1. 方法路由

| 需求 | 方法 | 典型产出 | 理论传统 |
|------|------|---------|---------|
| 从材料中归纳新概念/理论 | 扎根理论 (Grounded Theory) | 核心范畴、理论命题 | 符号互动论、实用主义 |
| 已有框架，检验或套用到材料 | 框架分析 (Framework Analysis) | 矩阵、摘要表 | 政策研究、应用研究 |
| 提炼共享意义模式 | 主题分析 (Thematic Analysis) | 主题地图、主题叙述 | 现象学、解释主义 |
| 量化文本中框架/话题/态度频率 | 内容分析 (Content Analysis) | 编码频次表、交叉表、信度系数 | 传播学、社会心理学 |
| 解释因果机制（过程追踪） | 过程追踪 (Process Tracing) | 因果机制图、证据表 | 比较政治学、案例研究 |
| 多编码者一致性和可复现性 | 信度评估 | Cohen's κ / Krippendorff's α | 内容分析、系统编码 |
| 大规模文本初筛 | LLM 辅助编码 | 初编码、主题簇 | 计算方法、NLP |
| 解释回归机制或统计发现 | 混合方法整合 | joint display、案例选择矩阵 | 实用主义、批判实在论 |
| 分析叙事/生命史 | 叙事分析 (Narrative Analysis) | 叙事结构、身份建构 | 叙事心理学、社会学 |
| 分析话语/权力/知识关系 | 话语分析 (Discourse Analysis) | 话语策略、主体位置 | 后结构主义、批判理论 |
| 改善实践、参与式变革 | 行动研究 (Action Research) | 行动评估、反思循环 | 批判理论、实用主义 |
| 保存/解释叙述记忆 | 口述史 (Oral History) | 叙事重建、记忆框架 | 历史社会学、记忆研究 |

### 1.1 设计家族选择决策

在按"需求→方法"选择分析技术之前，先确定研究的**设计家族**。设计家族决定最终产出和分析义务：

| 设计家族 | 核心问题 | 预期产出 | 分析义务 |
|---------|---------|---------|---------|
| **叙事研究** | 一个或少数几个人如何经历某段时间？ | 重组的故事（开端-发展-转折-结局） | 叙事编码、时间线重构、主题提取 |
| **现象学** | 多人对同一现象的共享经验本质是什么？ | 经验本质的复合描述 | 意义单元提取、现象学还原、本质描述 |
| **扎根理论** | 过程中行动/互动如何展开？ | 数据中涌现的过程理论 | 开放-主轴-选择编码、持续比较、理论饱和 |
| **民族志** | 文化共享群体如何从内部运作？ | 文化肖像（厚描述） | 领域分析、分类分析、成分分析、主题分析 |
| **个案研究** | 有界个案如何照亮更大的议题？ | 个案描述+主题+断言+证据链 | 模式匹配、解释建构、时间序列分析、跨个案综合 |
| **行动研究** | 如何通过研究改善实践？ | 实践改变+知识生产 | 循环评估、参与式分析、行动反思 |
| **口述史** | 记忆如何叙述生命和集体历史？ | 保存、解释、归档的叙述记忆 | 叙事分析、记忆框架分析、档案组织 |

**设计-方法匹配规则**：如果研究问题问"过程如何展开"，扎根理论比现象学更合适。声称使用某个设计意味着承担其全部分析义务——不能只借标签不执行方法。

### 1.2 分析的认识论前提

质性分析不是范式中立的。研究者的认识论立场约束编码、主题生成和解释方式：

| 范式 | 认识论 | 分析策略 | 质量标准 |
|------|--------|---------|---------|
| **后实证主义** | 实在论：社会事实外在于个体 | 系统编码、信度评估、编码者间协议 | 内部效度、可复现性 |
| **建构主义/解释主义** | 建构论：意义由社会文化建构 | 归纳编码、主题涌现、情境化解释 | 可信性、反身性透明 |
| **批判理论** | 权力/意识形态揭示 | 权力分析编码、话语解构、解放导向主题 | 启蒙性、社会转化 |
| **实用主义** | "什么有效" | 混合方法整合、Joint Display | 实用效度、可操作性 |

**操作要求**：在分析备忘录中明确记录认识论立场，以及它如何影响：编码是预定义还是涌现、是否报告信度系数、反身性的角色、对"客观性"的宣称程度。

### 1.3 质性适用性判定

**适合质性研究**当研究问题问的是：
- 某事物**意味着什么**
- 一个过程**如何展开**
- 人们**如何解释**某一处境
- 一个文化或群体**如何运作**
- 一个案例**如何阐明**某一议题
- 实践如何通过参与**被改变**

**不适合质性**当主要需求是：流行率估计、效应量大小、因果效应检验、广泛总体的假设检验——此时优先定量或混合方法。

### 1.4 研究问题语法

中心问题应命名三个要素：**中心现象** + **参与者或场域** + **开放的探索性动作**。

**好的动词**：理解、探索、描述、解释、呈现、考察。
**避免的动词**：影响、导致、决定、预测（因果性）；与…相关（变量驱动）；评估、判断（评价性）。

一个中心问题 + 若干子问题。子问题分解中心问题的不同维度（如：参与者如何经历X？什么条件影响了他们的经历？他们如何理解这种经历？）。

**反模式**：研究问题听起来像变量假设——"X 是否影响 Y？"本质上是定量问题。

## 2. 编码单位与抽样

### 2.1 编码单位选择

| 单位 | 适用场景 | 示例 |
|------|---------|------|
| 词/短语 | 内容分析、关键词统计 | 政策文本中的"可持续发展"词频 |
| 句子 | 短开放题、政策条款 | 问卷中"为什么支持该政策" |
| 段落 | 访谈逐字稿、田野笔记 | 受访者讲述工作经历的一段话 |
| 话轮 | 对话、焦点小组 | 焦点小组中某成员的一轮发言 |
| 事件/情节 | 案例研究、过程追踪 | 某政策从提案到落地的完整过程 |
| 文档 | 组织文件、新闻报道 | 某企业的年度可持续发展报告 |

### 2.2 抽样策略

| 策略 | 说明 | 适用 |
|------|------|------|
| 目的性抽样 (Purposive) | 按理论相关性选择个案 | 典型案例、关键案例 |
| 最大变异抽样 | 覆盖最广泛的变异范围 | 异质性大的总体 |
| 极端/偏差案例 | 选择极端值或异常值 | 检验理论边界 |
| 滚雪球抽样 | 通过受访者推荐下一个 | 隐藏或难以接触的人群 |
| 理论抽样 | 边收集边分析，按新兴理论引导下一步 | 扎根理论 |
| 分层目的抽样 | 在子群体内做目的性抽样 | 跨群体比较 |
| 类型代表性策略 | 以理论类型而非统计总体为推断目标（个案→理论类型） | 个案研究的外推 |

### 2.3 饱和度判断

- **理论饱和 (Theoretical Saturation)**：新数据不再产生新的理论见解或范畴属性。扎根理论的核心停止标准。
- **主题饱和 (Thematic Saturation)**：新数据不再产生新主题。适用于主题分析和框架分析。
- **数据饱和 (Data Saturation)**：没有新的信息/模式出现。最保守的标准。
- 实际操作中，建议在预计数据收集量的 80% 时做一次饱和评估，决定是否需要补充。
