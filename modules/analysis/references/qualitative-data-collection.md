# 质性数据收集

> 覆盖质性研究全过程模型中的**收集密集数据**阶段。用于田野观察、深度访谈和焦点小组的数据收集协议。

---

## 1. 田野观察与札记

### 1.1 参与观察角色谱

| 角色 | 参与程度 | 适用 | 风险 |
|------|---------|------|------|
| 完全观察者 | 不参与，仅观察 | 公开场合、初步勘查 | 缺乏内部视角 |
| 观察者即参与者 | 有限参与 | 正式组织 | 角色混淆 |
| 参与者即观察者 | 深度参与 | 长期田野 | 过度投入、失去分析距离 |
| 完全参与者 | 隐蔽完全参与 | 封闭群体 | 伦理风险、记录困难 | 例：王宁、严霞(2011) 以打工妹身份进入广州J工业区化妆品店一个多月，同吃同住同工作 |

### 1.2 田野札记五层结构

每次田野记录应包含五个层次，并在札记中明确标注：

1. **描述层 (D)**：客观记录观察到的事件、行为、对话、空间、物品、时间
2. **分析层 (A)**：初步分析直觉、涌现模式、与已有编码或理论的连接
3. **方法层 (M)**：记录观察选择、焦点变化、数据收集决策及其理由
4. **反身层 (R)**：记录研究者的情感反应、角色感知、权力关系变化
5. **追问层 (Q)**：列出下次观察或访谈需要追问的问题

### 1.3 观察抽样维度

观察不能覆盖一切。在进入田野前明确选择：

- **时间抽样**：哪些时段？（上午/下午/工作日/周末/特定日期）
- **地点抽样**：哪些空间？（前台/后台/公共/私密/过渡空间）
- **事件抽样**：哪些类型的事件？（常规/仪式/冲突/边界事件）
- **行动者抽样**：观察哪些人？（核心/边缘/守门人/新来者）
- **互动抽样**：哪些互动类型？（正式/非正式/上下级/平级/跨群体）

### 1.4 守门人与撤场

- **守门人策略**：识别正式和非正式守门人、建立信任、协商访问范围
- **撤场伦理**：提前预告、逐步减少参与、完成承诺的反馈、保持联系通道

## 2. 访谈与焦点小组数据收集

### 2.1 访谈指南七要素

1. **基本信息记录**：日期、地点、时长、编号
2. **介绍与同意**：研究目的、保密和匿名化承诺、录音许可、退出权
3. **开场问题**：宽泛、轻松的问题让受访者进入叙述状态
4. **核心问题**：围绕研究问题的开放式问题（5-8 个）
5. **追问提示**：为每个核心问题预设 2-3 种追问方向
6. **跟进问题**：根据受访者回答灵活跟进
7. **结束说明**：感谢、后续联系方式、资料用途确认

### 2.2 追问技能十类

| 追问类型 | 示例 |
|---------|------|
| 举例 | "能举一个具体的例子吗？" |
| 原因 | "是什么让您做出了这个决定？" |
| 对比 | "这次和之前的经历有什么不同？" |
| 时间线 | "从开始到现在经历了哪些阶段？" |
| 感受 | "当时您的感受是什么？" |
| 含义 | "这件事对您意味着什么？" |
| 情境 | "当时周围的环境是怎样的？" |
| 行动者 | "还有谁参与了这件事？" |
| 后果 | "这件事后来产生了什么影响？" |
| 澄清 | "您刚才说的 XX，能再多解释一下吗？" |

### 2.3 焦点小组设计原则

- **群体构成**：6-8 人为宜，同质性/异质性根据研究目的选择
- **主持人角色**：引导互动而非主导发言
- **互动目标**：激发讨论、揭示共识、暴露分歧
- **讨论提示**：设计 4-6 个开放式讨论题
- **基本规则**：一轮一人发言、尊重不同意见、保密约定
- **群体层面分析**：不把焦点小组还原为"多个个别访谈"，分析互动中的共建、争论、沉默和权力动态
