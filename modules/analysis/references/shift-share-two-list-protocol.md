# Shift-Share IV 协议

shift-share（Bartik）工具的外生性有两种互不相同的来源，**先选路径再动手**：识别从冲击来，还是从份额来。两条路径的估计、推断与 balance 对象都不同，**不得各拿几步拼盘**。

## 适用场景

单位层暴露份额 × 冲击层增长（行业、来源国、地区）构造的工具；移民份额、贸易暴露、政策暴露。

## 动作 0：先选路径

| | 路径 A：多个外生冲击 | 路径 B：外生份额 |
|---|---|---|
| 识别论证 | 冲击 as-good-as-random，且只通过处理影响结果 | **每个**份额满足平行趋势：高低暴露单位在无处理时趋势相同 |
| 估计 | 控制份额加总（不为一时）与冲击层控制的 shift-share 聚合 | 份额当作工具：一次一个，或经 2SLS/LIML 合并 |
| 推断 | **exposure-robust 标准误**（等价冲击层 IV 回归） | 常规异方差/聚类稳健标准误 |
| Balance 对象 | 工具**与冲击本身** | 工具**与高 Rotemberg 权重份额** |
| 何时是 non-starter | 冲击太少或明显内生 | 份额是 **generic** 的（暴露于任何行业冲击） |

**tailored vs generic 是路径 B 的生死线**：份额必须只中介你研究的那一个处理。同一套滞后就业份额既可用于「中国进口竞争」又可用于「机器人化」，它就是 generic——份额路径不可用。

**产出**：一句声明「识别来自冲击／来自份额」，以及为什么另一条不选。

## 路径 A：多个外生冲击（七步）

| 步 | 动作 | 关键规则 |
|---|---|---|
| A1 | 用理想化的冲击层实验来动机化 | 先写 OLS 偏误来自哪些混淆，再描述什么样的随机分配会产生无关又能推动处理的冲击 |
| A2 | 弥合观测冲击与理想冲击的差距 | 冲击层混淆要控制**同一套份额聚合出的** q_k；单位层混淆直接控制 |
| A3 | **incomplete share control** | 份额加总 S_i 不为一时工具是加权和而非加权平均，必须控制 S_i；份额滞后了 S_i 也要同样滞后；多期重复截面加 S_i × 期间固定效应 |
| A4 | 份额滞后到自然实验起点 | 避免冲击反向影响份额；跨期序列相关时滞后到第一期或取冲击创新；**冲击有动态直接效应时滞后救不了** |
| A5 | 报告冲击层描述统计与**有效冲击数** | 有效冲击数 = 1 / Σ_k s̄_k²（重要性权重的 Herfindahl 倒数）；它是 SSIV 版的「有效样本量」 |
| A6 | 对冲击本身也做 balance | 单位层 pre-trend 照常；**冲击层 balance 是本路径特有动作**（g_k 对可能代理不可观测的冲击层变量回归） |
| A7 | exposure-robust 标准误出主估计 | 份额相似单位的 z_i 与 ε_i 机械相关，常规聚类严重低估 SE；用 AKM 估计量或 BHJ 等价冲击层回归；敏感性：换控制集、加不加单位权重 |

**与 IV 协议的衔接**：首阶段/简约式散点在**冲击层**画；F 与区间全部换成 exposure-robust 口径——常规 effective F 在这里不是正确的强度度量。

## 路径 B：外生份额（五步）

| 步 | 动作 | 关键规则 |
|---|---|---|
| B1 | 判定份额是否配当工具 | 标准是「你愿意把任何一个 s_ik 单独当工具用」（每个都是一条 DiD）；份额须 tailored；滞后有帮助但不保证外生，要论证「滞后减少与误差的协方差多于减少与处理的协方差」 |
| B2 | 选单位层控制 | 份额外生可条件化：控制某些份额之和，让工具只用**构成**变异（如控制初期移民总份额后比较来源构成） |
| B3 | 算 **Rotemberg 权重** | 估计 = 各份额单独估计的加权和；权重度量对每个份额外生性违背的敏感度。要报：负权重之和/占比/负正权重比（参照量级约 6%）、权重集中度（前五名占比）、corr(α̂_k, g_k)，并翻译成一句可讨论的比较 |
| B4 | 对单个份额做 balance | 集中在高 Rotemberg 权重份额以避免多重检验。**份额被期初特征强预测**比 pre-trends 更常出问题（R² 常达 0.18–0.57）——可观测量能预测份额，就有理由担心不可观测量也能 |
| B5 | 检查对份额组合方式的敏感性 | 份额外生 ⇒ 过度识别：Sargan–Hansen、visual IV 图、单份额估计对 F 的 GPSS 图、换组合重估（只用高权重份额／2SLS／高效 GMM；K 大时 2SLS 有 many-weak-IV 偏误） |

**过度识别检验失败怎么读（常被读错）**：效应同质时，失败 = 份额外生性被拒；效应异质时，不同组合本来就估计不同效应组合，失败不必然否定外生性——但「对组合敏感」本身就是解释上的坏消息。**检验之间会打架，两个都要报**（例：五个估计高度一致但 Sargan 拒绝）。

## 报告规范

1 路径声明与理由；2 z_i 的构造：冲击与份额各是什么、测于何时、份额加总是否为一；3(A) 理想冲击实验叙述与差距；4(A) 冲击层描述统计与有效冲击数；5(A) 冲击层 balance + 单位层 pre-trend（exposure-robust 口径）；6(A) incomplete share control 与 exposure-robust 主估计；7(B) 份额 tailored 论证与滞后两条件；8(B) Rotemberg 权重表与高权重份额点名；9(B) 高权重份额 balance、过度识别检验、visual IV/GPSS 图、换组合估计；10 敏感性（换控制集、单位权重）；11 **工具构造脚本与中间数据**——SSIV 的争议全在份额与冲击怎么来的，不交构造代码等于藏起最该被检查的一步；12 其余照 IV 协议报告清单。

## 退出判据（建议非门禁）

| 判据 | 触发条件 | 动作 |
|---|---|---|
| A 两条路径都是 non-starter | 冲击少或内生，**且**份额 generic | 没有第三条路径，换设计 |
| B 有效冲击数太小 | 1/Σs̄_k² 只有个位数：大数定律不适用，单位再多也没用 | 换设计或改在冲击层做 |
| C 序列相关冲击的动态效应无法处理 | 滞后救不了、创新又提不出来 | 换设计（不是换标准误能解决） |
| D 份额路径 balance 挂了且同质性说不过去 | 组合敏感 + balance 失败 + 无合理异质效应故事 | 无效工具选择 / 部分识别 / 换设计 |

## 常见失败模式

- 两边各拿几步拼盘（估计按 A、balance 按 B、推断按常规聚类）。
- 份额加总不为一却不控制 S_i。
- 用常规聚类 SE 报 SSIV（严重低估）。
- 只报顺手的那个检验信号；不报负权重与集中度。
- 不交代工具构造代码。
