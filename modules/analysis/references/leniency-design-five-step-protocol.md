# 宽严度设计五步协议

适用于以「决策者宽严度」为工具的 IV 设计：法官量刑、审查员批准、医生收治、教师评分。
核心判断：**这类设计不是「一个工具」，而是 K 个虚拟变量构成的 many-instrument 问题**；把 K 个压成一个标量不会把它变成一个工具。

## 适用场景

处理由某个决策者个案决定，决策者在同一制度下随机分派，且宽严度不同。

## 执行层

UJIVE 的实现放在 `templates/03-regression/04-causal/ujive.do`（Mata，单内生回归元、任意工具数）：

```
do "…/templates/03-regression/04-causal/ujive.do"
ujive <y> <d> <z1 z2 …> [, controls(<w1 w2 …>)]
ujive_selftest, n(3000) k(60)        // 自检：真值已知的模拟对照
```

它同时报告 OLS、2SLS、UJIVE 与首阶段 F，便于展示偏误方向；稳健（HC1）标准误。**R 侧无等价实现**，跨语言复现须走 Stata 或自行实现。

## 步骤 1：定必要控制，据此选估计量与标准误

**必要控制** = 使分派成为 as-good-as-random 所必需的那些，由制度知识决定、不是数据挑出来的。典型形态：分派在「决策者 × 时段」内随机 ⇒ 用该格子固定效应。
**精度控制** = 处理前、能解释结果变异的特征，只降标准误，可选。

同一分派机制还决定两件事：
- **排除限制**：决策者除该处理外还做什么，要制度性论证（沿用 IV 协议的渠道穷举表）。
- **用哪个分派：初始的还是最终的**。若被处理者能排队换决策者（按不可观测量排队），工具本身被污染，balance 兜不住。优先级：改用初始分派 → 访谈行政人员确认排队发生率 → 都做不到就写进限制并给出偏误方向（向零）。

**1a 估计量（默认不是 2SLS）**

| 估计量 | 何时用 |
|---|---|
| 2SLS（决策者虚拟变量） | 只在决策者很少时可靠；多决策者下向 OLS 偏、标准误同时缩小 |
| **UJIVE（留一法相对宽严度）** | **默认**；近似无偏，小 F 不成问题 |
| 经典 JIVE1/JIVE2 | 控制变量多时会把自身观测偏误放回来，方向常与 2SLS 相反 |
| FEJIV | 正交性好但更噪、更慢 |
| 偏误修正 2SLS | 只在同方差下有效 |

**1b 禁止手工构造宽严度再当工具**：那等于手工两阶段最小二乘——构造细节的微小差异对偏误影响很大，且第二阶段标准误是错的（不反映宽严度的估计误差）。也不要把「宽严度测度的方差」当作设计强度信号（估计噪声会高估真实变异）。

**1c 标准误与聚类：默认不聚类**

- 推理依据：决定标准误的是 `ℓ̃_i ε_i` 的相关模式；分派若跨个体独立，该乘积不相关。
- 规则：**在分派发生变异的层级聚类**。个体层随机 ⇒ 异方差稳健即可；分派成簇（按月、按班次）⇒ 按簇聚类。
- **永远不按决策者聚类**；「聚类后标准误变不变大」不能用来判断该不该聚类；「以防万一」地聚类会过度保守。
- 分派成簇时，聚类还**改变估计量**：需用留出整簇的 UJIVE 变体。

## 步骤 2：用同一套 UJIVE 设定检验 balance

对每个可观测特征，把它当结果跑**与主结果完全相同**的 UJIVE 设定（同处理、同工具、同控制）。显著即提示不均衡与识别威胁。

为什么不换成「把可观测量对宽严度测度回归」：常规首阶段构造的宽严度在多决策者 + 固定效应下会产生机械相关；留一宽严度自身仍有误差变量偏误；对整套虚拟变量做联合 F 在多决策者下默认无效。

**用事后变量查排除限制**：同一设定，把**分派之后**才实现的变量当结果。显著即提示排除限制被违反；补救是把它建成第二个处理（同时工具化），或把处理与之交互。

## 步骤 3：用 UJIVE 出主估计，并与 2SLS、OLS 并列

并列的目的不是稳健性，而是**显示偏误的方向与量级**：
- 多工具 2SLS 会落在 OLS 与 UJIVE 之间或贴近 OLS——这是有限样本偏误，不是「IV 修正了衰减」。
- 2SLS 标准误比 UJIVE 小三到四倍——**统计病理，不是效率增益**。
- 即便用别人构造的留一宽严度，标准误照样偏小。

## 步骤 4：检验 average monotonicity

**为什么不用通常的单调性**：它等价于「每个决策者对案件优劣的排序相同、只是门槛不同」，多维评价 + 技能差异让这在实践上不现实。没有单调性时，成对 IV 识别的加权差会给 defier 负权重，可能**符号反转**。

**要检验的是 average monotonicity**（没有单位「平均而言」是 defier）：
- 把结果换成 `ỹ_i = y_i × v_i`（`v_i` 为分派前决定的变量），其余设定不变；average monotonicity 下识别的是 `v_i` 的**凸**加权平均。
- `v_i` 为二值时该平均必须落在 [0,1]；**落在界外即 LATE 定理出问题**（先排除随机分派与排除限制的问题，再归因于单调性）。
- 它只能查出**严重违反**；它是「随机分派 + 排除 + 单调性」的联合零假设检验。
- 控制变量要足够灵活，使 `E[z|w]` 对协变量线性；决策者跨多个格子且宽严度因格子而异时，只做可加固定效应是设定错误的——用更灵活设定做稳健性，权衡偏误与方差。

## 步骤 5：刻画 complier，评估外部有效性

把结果换成「协变量 × 处理」，得到 complier 的协变量加权平均（权重与主估计相同）。用 `1 − 处理` 得到未处理 complier 的特征，在 as-good-as-random 下两者应相等。
- complier 特征接近全样本 ⇒ 估计大致可代表总体；
- 差异大 ⇒ 效应只属于「处理状态取决于分派」的那一小群，政策结论必须收窄。
- complier 估计落在逻辑界内，也是对 average monotonicity 的又一次支持。
- LATE 权重 = 各对决策者宽严度差的平方（凸加权，无负权重）。

## 报告规范（14 项）

1 分派机制的制度证据 + 必要控制与精度控制分列；2 排除限制论证；3 估计量与其理由；4 聚类层级 = 分派变异层级（不聚类要说明理由）；5 分派成簇时是否用留簇外变体；6 UJIVE balance 表并与处理效应量级对比；7 事后变量 balance；8 UJIVE 与 2SLS、OLS 并排并点出偏误方向；9 average monotonicity 检验（哪些 `v_i`、区间是否在界内、声明是联合零假设）；10 更灵活控制设定的稳健性；11 complier 特征表与全样本对照；12 弱工具信噪比 `√K×(E[F]−1)` 及不足时的稳健检验；13 用初始还是最终分派；14 决策者严宽本身有没有绕过目标处理的渠道。

## 退出判据（建议非门禁）

| 判据 | 触发条件 | 动作 |
|---|---|---|
| A 分派故事讲不出来 | 说不出规则、说不出条件于什么才随机 | 没有必要控制，换设计 |
| A2 只有最终分派且有排队证据 | 工具被污染，balance 兜不住 | 写进限制并给偏误方向；能拿初始分派就先拿 |
| B 事后变量 balance 挂了且无法建成多处理 | 排除限制被违反 | 建成多处理继续，否则停 |
| C average monotonicity 被拒 | 加权平均落到 [0,1] 外 | 先排随机分派与排除限制，再归因；符号反转风险实质化则停 |
| D 信噪比不足 | `√K×(E[F]−1)` 小到区间无信息 | 用弱工具稳健检验；仍无信息即退出 |

## 与 IV 协议的三处替换（其余照走）

| IV 协议 | 在宽严度设计里 |
|---|---|
| 五个 F 一起读、effective F 定路由 | **不按 F 路由**（UJIVE 小 F 下依然近似无偏）；F 只作 2SLS 偏误量度与信噪比输入 |
| 按 effective F 路由 AR/tF/bootstrap | 换成弱工具稳健检验（用 `β₀` 残差而非 UJIVE 残差）；tF 是单工具程序，K 大时不适用 |
| 声明聚类结构 | **按分派机制定，不按残差相关**；不按决策者聚类；成簇则同时换估计量 |

## 常见失败模式（审阅已有研究按频率排序）

按决策者聚类；手工构造宽严度且不报其估计误差；只报 2SLS 并把窄区间当精度；完全不检验单调性或只援引通常版本；不刻画 complier 却做全样本政策外推。

- 方法文献：Goldsmith-Pinkham, Hull & Kolesár, "Contamination Bias in Linear Regressions", *AER* 114(12), 2024（Phase 03 核实；UJIVE 归属需在正文注明为该文提出的估计量）。
- **执行层**：UJIVE 见 `templates/03-regression/04-causal/ujive.do`（已实现并自检：K=1 时与 2SLS 一致；无混淆时两者都接近真值；有混淆时两者同向偏移，说明它修正的是 many-instrument 偏误而非混淆偏误）。average monotonicity 检验仍无现成命令，需按步骤 4 自行实现（简化做法：把结果换成 y×v，跑同一 UJIVE 设定，看加权平均是否落在 [0,1]）。

## 风险与限制

- 本协议不承诺可执行代码；方法本身依赖 many-instrument 渐近理论，实现难度高于常规 IV。
- 「初始分派优先」一条来自第二来源（不在 GHK 内），正文已标注。
- 部分场景（决策者极少）2SLS 反而更可取，协议保留该例外。
