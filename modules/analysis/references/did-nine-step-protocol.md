# DiD 九步协议

本文件规定 DiD 研究的**推进顺序**，不规定用哪个包。方法路由见 §12 与三语言模板。
核心立场：**正向工程**——先定目标参数，再陈述识别假设，最后才落到估计与推断。
从数据结构或可用软件倒推设计（反向工程）不得作为默认路径。

## 适用场景

处理—对照两组、两期或多期、交错采纳、事件研究、三重差分。用户在问「DiD 怎么做／这个设计站不站得住／审稿人质疑稳健性」时读本文件；只问「哪个命令能跑」时读 §12。

## 前置条件

- 已有明确的处理定义、单位、时间口径。
- 已排除 always-treated（`g <= min(t)` 的单位既非处理也非控制）。
- 已有队列数与各队列单位数、处理铺开网格。

## 操作步骤

| 步 | 产出 | 通过标准 |
|---|---|---|
| 1 定目标参数 | 潜在结果记号；building block（2×2 为 ATT、多期为 ATT(t)、交错为 ATT(g,t)）；summary 参数 + **聚合权重定义**；样本权重 ω 的作用说明 | 参数由研究问题决定，不是由数据结构决定 |
| 2 陈述识别假设 | 点名依赖哪一条：PT / PT-ES / PT-GT-ALL / PT-GT-NEV / PT-GT-NYT / CPT / NA / SO；条件版本须附重叠证据 | 每条假设有制度性实质论证；认领一类「单位为什么被处理」的机制 |
| 3 平行趋势证据 | 事件研究 pre-period 的 ATT(g,t)；先说明系数算法是长差分还是短间隔；功效报告（80% 功效可检测的最小线性违背） | 不用「不显著」当作成立的证据；交错采纳不得用单一处理时点的通用检验 |
| 4 选估计量 | 无条件 2×2 用样本均值；条件 DiD 在 RA／IPW／**DR 默认**间选；交错采纳先估 ATT(g,t) 再按步 1 权重聚合；TWFE 不作默认 | 附加建模限制写清（工作模型形式、倾向得分形式、修剪阈值） |
| 5 估计与推断 | 随机性来源声明（抽样／设计基础／模型基础）；哪些量当固定哪些当随机；聚类层级及其理由；聚类数；少聚类补救 | 推断立场先于标准误类型；事件研究报 pointwise 与 simultaneous 两类区间；两步估计的 SE 要含第一步不确定性 |
| 6 敏感性 | Rambachan–Roth 识别集与稳健置信区间（相对幅度限制 M 从 1.0 起）；非劣效性思路（足以解释掉效应的差异趋势值作原假设）；必要时补缺失数据四方向 | 标准是「对可能发生、量级合理的违背稳健」，不是「对所有失败稳健」 |
| 7 异质性 | 回到步 1 重新定义子群参数（随时间／按协变量／按处理变异来源），再走步 2–6 | 异质性不是事后 fishing；子群参数要有独立的目标参数定义 |
| 8 稳健性与报告 | 至少两个估计量交叉；never-treated 与 not-yet-treated 各一版；伪时点与伪结果；逐队列剔除；带与不带协变量各一版；流失率×事件时间表 | 每个数字都写清 estimand、比较组、聚合权重、聚类层级；任何缩减样本的 warning 如实写出 |
| 9 退出判据 | 见下节四条 | 触发即改设计，不是换估计量 |

## 交付前检查槛

1. 识别策略一节删掉所有「我们假设……」后，仍剩下关于**这个制度下为什么两组未处理趋势会平行**的论证。
2. 报告的每个系数都能回答：哪个目标参数、哪种比较组、什么权重。
3. 事前趋势不显著时，正文没有把它写成平行趋势成立的证据。
4. 若报 TWFE，同时报了目标参数明确的估计量，并用 Goodman-Bacon 类分解解释差异来源。
5. 聚类层级与聚类个数写明；少聚类有对应补救。
6. 敏感性分析给的是区间，不是「系数依然显著」。

## 常见失败模式

- 目标参数从未定义，直接从回归设定开始（最常见的缺口）。
- 把「不确定性来源」简化成一句「标准误在 X 层面聚类」。
- 用单位特异线性趋势「吸收」违背（依赖参数模型，且有不依赖模型的替代方案）。
- 把有效应改写成「不显著」后照发：识别失败与精确估计的零效应是两回事。
- 换比较组直到 pre-trends 看起来干净：用估计量选择掩盖识别问题。
- 事件研究系数算法（长差分／短间隔）未声明，把两种算法当同一件事解释。

## 退出判据（四条，建议非门禁）

| 判据 | 可核对的问题 | 触发后的动作（按代价从低到高） |
|---|---|---|
| A 事前不可信 | 识别假设的实质论证写不出来 | 缩小目标参数 → 换假设版本或比较组（须重走步 2–6）→ 换设计 → 报告为不确定 |
| B 被证据推翻 | pre-trend 估计显著且量级与待报效应可比；或功效分析连「足以解释掉效应」的趋势值都排除不了 | 同上 |
| C 识别集无内容 | 在可辩护的最小违背幅度下，稳健区间仍覆盖两个方向上「重要」的效应 | 同上 |
| D 硬性证伪 | 未处理潜在结果不满足鞅性质（按时变、处理前不可观测因素选入处理） | 换设计 |

触发后禁止三件事：换更宽松的估计量；加单位特异线性趋势；把结论改写成「不显著」。

## 报告规范

- 主表：目标参数、比较组、聚合权重、聚类层级与个数。
- 图：事件研究图（两类区间）+ 事件期样本构成。
- 稳健性：多估计量、替代比较组、伪时点、逐队列剔除、带/不带协变量。
- 诊断：Bacon 类分解（TWFE 在场时）、pre-trends 功效、敏感性区间。

## 风险与限制

- 九步是流程建议，不是门禁；阈值（聚类数、M 取值）为提示性约定，需结合制度知识判断。
- 三重差分的识别假设是 parallel bias 而非平行趋势；替代组在证伪中应等于零、在 DDD 中应等于主组偏误——同一数字两种相反读法，正文必须点名读的是哪一种。
- 本文件不覆盖合成控制族（一个或少数处理单位）：走合成控制协议。
