# RDD 四阶段协议

规定断点回归**按什么顺序做**：先把设计说清楚、选定识别框架，再进主分析、证伪、扩展。
RD 是研究设计，不是估计策略；从 `rdrobust` 默认输出倒推设计属于方向相反。

## 适用场景

score + 事先已知 cutoff + 规则分配处理。政策资格线、录取线、行政区划边界、任职门槛。

## 前置条件

- 三件套能写清：score 是什么、cutoff 谁定的、分配规则如何执行。
- 已确认 sharp / fuzzy、score 连续 / 离散、单一 / 多个 cutoff。

## 阶段 I：设计

**动作 1 形式化设计与目标参数**
- 产出设计声明（score、cutoff、分配规则、合规性、score 类型、cutoff 数）。
- 目标参数：sharp RD 为 τ_SRD = E[Y(1)−Y(0) | X=c]；局部随机化下变为窗口内 θ_SRD——**换框架就是换参数**。
- 写下局部性声明：效应只在断点处识别，政策结论的适用范围与之一致。

**动作 2 选择识别框架并陈述假设**
- 连续性框架：E[Y(1)|X]、E[Y(0)|X] 在 c 处连续；估计靠局部多项式外推到 c；推断靠大样本渐近。
- 局部随机化框架：窗口内 (LR1) score 分布已知 + (LR2) 潜在结果不依赖 score；估计为窗口内均值差；推断含 Fisherian 精确推断。
- 选择判据：score 连续时 LR **严格更强**，默认以连续性为主分析、LR 为稳健性；断点附近观测很少或 score 离散时 LR 可作主分析。
- LR2 不由「窗口内随机分配」自动蕴含，是额外排除限制，必须单独陈述。
- 另需实质论证：单位为什么不能精确操纵自己落在断点哪一侧。

## 阶段 II：主分析

**动作 3 RD plot**
- 两层：分侧 4/5 阶**全局多项式**（只画图，不估计）+ 不相交 bin 的局部均值点。
- bin 位置等距 / 分位距；bin 数量 IMSE 最优 / mimicking variance（先看 MV，再与 ES 对比）。
- 同时画**处理概率对 score** 的图（fuzzy 时必需，sharp 时核对是否真的 sharp）。
- 动作 4 定稿后用带宽内局部线性拟合重画主图。
- 图形不能替代推断；「看不出跳跃」是功效不足的单向早停信号，不能反过来说「看出跳跃」就是证据。

**动作 4 连续性框架主分析**
- 4a 点估计：带宽内分侧加权最小二乘，**三角核 + 局部线性 p=1**；禁用全局高阶多项式做正式分析。
- 4b 带宽：数据驱动。h_MSE（`mserd/msetwo`）用于点估计，h_CER 用于推断；禁止 ad hoc 带宽。
- 4c 推断：**稳健偏差修正（RBC）**。报告规范三行——点估计取 `Conventional` 行，**p 值与置信区间取 `Robust` 行**；用 conventional p 值必须论证偏差可忽略。
- 4d 协变量与聚类：只用预定协变量，线性可加、**不与处理交互**，带宽用协变量感知选择器重选；聚类进入带宽选择器，会改变点估计。协变量只买效率，**修不了识别**。
- 4e 离散 score 的文献分歧：按驱动变量聚类（Lee 2008 路线）与反对意见（Kolesár–Rothe 2018：此类区间不防设定误差，建议改用 honest CI）。操作建议：至少并列报「按质点聚类」与「不聚类」两套 RBC 区间，或走 honest CI，并在文中写明选了哪条。

**动作 5 局部随机化**
- 5a 选窗：用**预定协变量**平衡做嵌套扩窗，取平衡首次被拒之前的最大窗口；最小窗口每侧约 10 个观测；α*≥0.15。先选窗、后看结果。
- 5b 窗口内估计：Fisherian 精确推断（sharp null 下 p 值任意样本量精确；均值差**不可当作估计效应**解释）+ 大样本法（HC2/HC3）。

## 阶段 III：证伪（与主结果同等重要）

先收集制度证据（score 生成方式、cutoff 是否事先公开、有无申诉通道），再做五项：

1. **预定协变量与安慰剂结果**：每个协变量按与结果**完全相同**的流程跑一遍（各自最优带宽 + RBC）。期望全为零。
2. **score 密度连续性**：小窗口精确二项检验 + 局部多项式密度检验（对 McCrary 的改进版）。
3. **安慰剂断点**：只在同侧同处理状态的观测上重估；远离断点的连续性「既非必要也非充分」。
4. **Donut**：剔除 |X−c|<r 后重估。它**换了估计目标**，必须与主结果并列报告、不能替换。
5. **带宽敏感性**：只在 h_MSE / h_CER 附近的小范围内变动。

**堆点核查（独立于上述五项）**：score 在整数/舍入点上异常堆积可造成偏误，而密度检验**通过不代表没有堆点**——密度检验查的是断点处密度是否连续，不是 score 轴上有没有系统性堆积。自查方式：把断点挪到 score 上其他同类整数处重估，若那里也「有效应」，估的是堆点不是断点。fuzzy 设计下所有证伪**基于分配 T，不基于接受 D**。

证伪只能证伪：全部通过不构成设计有效的证明；任何一项不通过都必须在正文正面回应。

## 阶段 IV：界外

**动作 7 扩展路由**（canonical setup 六特征任一被打破即换扩展，而不是放弃 RD）

| 被打破 | 扩展 | 关键规则 |
|---|---|---|
| 合规不完美 | Fuzzy RD | 先查首阶段；RD 语境弱工具阈值 **F≥20**；F 不足**只报 ITT**；complier 解释需排除限制 + 单调性 |
| score 离散 | 离散 RD | 先数质点；质点多数百个可继续用连续性方法，但有效观测数是质点数；质点少转局部随机化 |
| 多个 cutoff | Multi-cutoff | 分清 cutoff 是否累积；报 cutoff-specific 与归一化合并两套，合并权重要明示 |
| 多维 score / 地理 | Multi-score | 化为到处理边界的标量距离；地理用测地距离；检查距离零附近有无观测 |

**动作 8 退出判据（建议非门禁）**

| 判据 | 触发条件 | 动作 |
|---|---|---|
| A 设计三件套写不清 | score 是构造出来的、cutoff 事后挑、规则未执行 | 任何估计量都救不回，换设计 |
| B 操纵证据成立且无制度解释 | 密度检验 + 二项检验都拒绝、无制度解释、**且**预定协变量不平衡（三者齐备） | donut + 制度解释并列报告；否决则换设计 |
| C fuzzy 首阶段弱 | F<20 | 只报 ITT 与首阶段，不报 fuzzy 参数 |
| D 断点附近没有数据 | 带宽内有效观测寥寥；离散 score 每侧凑不够约 10 个观测 | 报告设计不可行 |

触发后禁止：扫带宽/窗口直到显著；用协变量「修复」不平衡；退回全局高阶多项式；把「未拒绝」当有效证明。

## 报告规范

- 主表：点估计（Conventional 行）、RBC p 值与区间（Robust 行）、带宽与选择器、核与阶数、聚类层级。
- 图：RD plot（含 ES/QS 与 MV 对比）+ 处理概率—score 图 + 带宽内局部线性拟合图。
- 稳健性附录：五件套 + 堆点核查 + 离散 score 两套区间（或 honest CI）。

## 常见失败模式

- 报 conventional p 值，或用 MSE 最优带宽却不做偏差修正推断。
- 带宽 ad hoc、只报一个带宽。
- 无密度检验/协变量证伪；fuzzy 设计的证伪错用 D。
- 协变量与处理交互，或用协变量遮掩断点处不平衡。
- 政策结论超出断点局部性。

## 风险与限制

- 阈值（F≥20、每侧 10 个观测、α*≥0.15）是实践建议的操作化，不构成机械标准。
- 离散 score 下的聚类决定存在文献分歧，本文件不给唯一答案。
- donut 改变估计目标，报告时必须说明剔掉的是谁。
