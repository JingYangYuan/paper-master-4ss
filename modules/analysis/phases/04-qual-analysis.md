# Phase 04：质性材料分析

## 0. 顾问派发门控

质性、文本或混合方法任务进入编码前，须派发 `modules/analysis/agents/qual-mixed-consultant.md` 复核分析单位、编码路径、去标识化方案、信度核查与混合整合方式。意见写入 `paper-workspace/_logs/agents/analysis-[YYYY-MM-DD]/qual-mixed-consultant.md` 并同步至 `agent-synthesis-analysis-[YYYY-MM-DD].md`。

## 1. 适用材料

访谈文本、田野笔记、开放题回答、政策文本、新闻文本、档案文献、组织文件与会议纪要。

## 2. 研究伦理与去标识化门控

### 2.1 全程伦理核查

- **田野前**：进入许可、知情同意、风险评估、保密与存储销毁方案、互惠安排；
- **田野中**：权力关系管理、情感伤害预防与退出机制、记录授权、无条件退出权；
- **田野后**：避免刻板印象与污名化、严格去标识化、原始身份数据访问隔离与发表影响评估。

### 2.2 AI / LLM 辅助处理去标识化硬门控

将访谈或文本交由模型阅读或辅助编码前，必须完成五步隔离：
1. 扫描姓名、电话、邮箱、住址、单位、学校、医院、精确日期、身份证号与罕见可识别事件；
2. 建立本地匿名映射表（文件名须包含 `DO-NOT-SHARE`）；
3. 生成 `ANON_` 前缀的去标识化文本；
4. 二次扫描 `ANON_` 文本确认无残留身份线索；
5. 后续流程仅允许读取 `ANON_` 文本，严禁读取、复制或展示真实身份映射表。

## 3. 转录规范、语料准备与备忘录

### 3.1 转录策略（选定后保持全篇一致并记录理由）

| 策略 | 处理方式 | 适用方法 |
|---|---|---|
| **逐字转录（Verbatim）** | 保留全部词语、重复、停顿词及副语言特征 | 话语分析、叙事分析、扎根理论 |
| **编辑转录（Edited）** | 去除口语填充词与重复，保持语义完整 | 主题分析、框架分析、内容分析 |
| **智能转录（Intelligent）** | 轻度编辑并保留关键停顿、强调与情感标注 | 现象学、口述史 |

语料准备步骤：① 统一文本格式与说话人标签 -> ② 按选定分析单位（句子/段落/话轮/事件/文档）划分唯一 `segment_id` -> ③ 全量通读记录全局印象 -> ④ 撰写首批备忘录 -> ⑤ 标注录音模糊、残缺或翻译疑点。

### 3.2 四类研究备忘录

分析全周期保持记录：**编码备忘录**（新建/合并/拆分编码依据与边界）、**主题备忘录**（主题定义、支撑证据、反例与替代解释）、**决策备忘录**（方法与路径取舍理由）及**怀疑备忘录**（存疑解释、冲突证据与待补数据）。

### 3.3 文本分段表结构

| 字段 | 说明 |
|---|---|
| `document_id` | 文档或访谈编号 |
| `segment_id` | 文本片段唯一编号 |
| `speaker` | 说话人代号或材料来源 |
| `date_or_period` | 时间信息 |
| `text` | 去标识化文本内容 |
| `memo` | 初始备忘 |

## 4. 编码本构建与编码策略

编码本固定十列：`code_id, code_name, parent_code, level, definition, inclusion_criteria, exclusion_criteria, typical_example, boundary_case, notes`。

三种编码策略对比：

| 策略 | 起点与适用场景 | 实施要点 |
|---|---|---|
| **归纳编码** | 无预设框架，适合探索性研究与扎根理论 | 优先保留参与者原生表达（in-vivo code） |
| **演绎编码** | 理论/文献/研究问题驱动，适合框架分析 | 增设「其他/待归类」开放编码并定期复核 |
| **混合编码** | 先搭理论骨架，再纳入材料涌现编码 | 明确标注各编码来源（理论预设 vs. 数据涌现） |

## 5. 质性分析方法路径

- **扎根理论**：开放编码（逐段提炼 in-vivo/描述性/过程性编码）-> 主轴编码（按因果条件、现象、背景、干预条件、行动策略与后果组织范畴）-> 选择性编码（识别核心范畴并撰写 500–800 字 storyline）-> 结合理论备忘录输出范畴关系图与理论命题。
- **主题分析（Braun & Clarke 流程）**：熟悉材料 -> 生成语义与潜在编码 -> 聚合候选主题 -> 回溯已编码片段与全文复核 -> 界定并命名主题 -> 撰写主题结果段落（主题须表达共享意义模式，而非话题标签）。
- **内容分析**：明确抽样单位、记录单位与语境单位，输出编码频次、交叉表、共现矩阵与可视化。

## 6. 编码信度与 LLM 辅助编码规范

- **信度指标**：双编码者采用 Cohen's kappa；多编码者或含缺失值采用 Krippendorff's alpha。最低可接受阈值 `0.60`，常规目标 `0.70`，高质量目标 `0.80`；未达标须修订编码本并记录分歧解决过程。
- **LLM 辅助编码（可选路径）**：须严格满足使用去标识化文本、建立人工金标准（gold standard）且测试 `kappa >= 0.70`、低置信度片段人工复核、抽检 10–20% 语料、排查顺序/长文本/多数类偏差，并归档提示词、模型、温度、成本与人工复核比例。

## 7. 质性脚本执行门槛

若编写了去标识化、分段、编码、信度计算或内容分析脚本，须立即执行（Python 优先，R 用于信度或绘图，Stata 经 `statamcp`）并将命令、退出码、stdout/stderr 路径与产物记入 `run-log-[date].md`：

```bash
python3 "paper-workspace/04-analysis/scripts/qual-analysis.py"

```

未执行成功前不得声称已完成编码、去标识化或信度检验。
