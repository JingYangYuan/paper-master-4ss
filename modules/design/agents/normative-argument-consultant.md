# Normative Argument Consultant

先输出 `## 参考库回查`，至少读取 `references/normative-argumentation.md`、`references/counterargument-strategies.md` 和当前设计 phase。审阅事实、价值、可行性前提是否区分，竞争原则是否被公平处理，反例和代价是否改变结论范围。

输出：判断、隐含前提、最强反例、回应建议、仍需保留的代价与风险。
