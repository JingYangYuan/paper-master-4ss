# design 模块参考库回查底座

本文件是 `design` 模块 4 个顾问角色的唯一参考回查源。各顾问卡仅保留指针行 `参考库回查: base=design-2026.10.24; tier=…; 判据=…; 缺口=…`。

## B1 核心摘录（≤1200 字，主流程注入用）

研究设计阶段的核心任务是判断研究问题能否在对应学术共同体中被有效追问、论证支撑与评估。

选题成立需同时满足三项条件：概念使用准确（完备概念账本：工作定义、必要条件、正例、边界例、反例、相邻概念与使用规则）、机制链条成立（`X -> 机制 -> Y` 具备可解释担保而非简单堆砌引文）、理论贡献明确（指明属于概念、解释、规范、阐释或整合贡献中的哪一类）。

不同研究取向不得混用判准：实证取向要求可操作化、可识别与可复现；概念/解释取向要求核心论题具备可争辩性；规范取向要求区分事实前提、价值前提与可行性前提并比较竞争原则代价；思想史/文本阐释取向要求文本版本、历史语境、解释单位与竞争诠释各得其所。不得将纯理论论题强制改写为经验命题。

期刊与论文类型约束应体现为结构、证据强度与篇幅的匹配，不以单一实证顶刊为默认标准。目标期刊公开要求缺失时须标注「未执行」，不得凭主观印象补齐。

方法论可行性核查四项：问题类型是否分清、变量或材料是否可操作、识别或解释路径是否与问题结构匹配、所需资料是否确实可得。识别路径与问题结构错配（如用截面数据检验动态因果机制）属于致命缺陷。

交付前须通过四层检查：L0 路由（学科匹配、模式与研究取向已锁定）、L1 FRAME（理论定位充分、空白有据且候选理论 ≥ 3）、L2 STORM（覆盖 ≥ 2 学科且清理 FATAL FLAW）、L3 DESIGN（理论—方法对齐、稳健性与反驳回应充分）、L4 整体（实质内容、逻辑自洽、可操作、完整）。任一层不通过须退回修改。

研究者主导权优先：默认不自动连续推进阶段、不自动派发顾问、不自动启动并行复核；外部检索、脚本执行、导出及变更项目状态的写入须先呈报方案、风险与证据缺口，经确认后执行。

## B2 判据条目

C01 理论概念是否准确使用：具备完备概念账本（工作定义/必要条件/正例/边界例/反例/相邻概念/使用规则），同一概念不在文中隐含改变外延（见 `references/argument-standards.md` §概念分析）。

C02 机制链条是否成立：X、机制、Y 与范围条件形成可解释链条；理论嫁接具有实质机制，避免「A 类似于 B」式表面类比。

C03 贡献可见度：明确归属概念、解释、规范、阐释或整合贡献之一，并说明继承、修正与拒绝对象；仅套用既有理论于新案例不构成理论贡献（见 `references/argument-standards.md` §理论贡献类型）。

C04 领域定位：研究问题嵌入既有学术争论，指明现有研究未充分解释的现象，领域贡献具体明确。

C05 期刊与论文类型适配：结构、证据强度与篇幅匹配目标期刊或学位论文要求，不预设实证优先；缺失目标期刊要求时标注 `期刊特定核验: 未执行`。

C06 问题类型区分：因果、解释、规范与阐释四类问题边界清晰，不混用判准。

C07 识别或解释路径匹配：识别策略与问题结构相匹配（`references/method-feasibility.md` §一–§三）；理论路径可审查材料与论证可行性，不强制要求变量、功效或回归。

C08 资料可得性与可复现性：变量、样本、时间跨度、文本或档案材料可获取；如实列明数据不可得、反向因果与遗漏变量风险。

C09 致命缺陷识别：研究问题不可检验/过宽/贡献不明、理论与方法脱节、存在不可处理的替代解释、材料不足/概念漂移/结论先行；命中任一项即判为 FATAL FLAW 并移出候选。

C10 最强反例与限定语：按 Toulmin 六要素（主张/根据/担保/支撑/限定语/反驳）核查担保与限定语，并回应最公平表述的强异议（见 `references/argument-standards.md` §Toulmin 论证框架、§反驳策略）。

C11 概念边界压力测试：核心概念能否排除至少一个相邻概念并处理边界例；无法排除时须界定为家族相似概念（见 `MODULE.md` §范式专属复核清单·概念）。

C12 规范前提分离：区分事实前提、价值前提与可行性前提，比较至少一个竞争原则及其代价，并用反例界定适用范围（见 `MODULE.md` §范式专属复核清单·规范）。

C13 文本语境与竞争诠释：交代文本版本、行动者位置、历史语境、阅读单位与解释规则，比较至少一种竞争诠释的依据与遗漏，说明时代错置风险（见 `MODULE.md` §范式专属复核清单·阐释）。

C14 四层质量门控：L0 路由、L1 FRAME、L2 STORM、L3 DESIGN、L4 整体（`phases/05-quality-gates.md`），任一层不通过须返回修改。

C15 研究者主导权：默认不自动推进阶段、不自动派活、不自动并行；高影响外部操作先呈报方案与风险（`references/researcher-agency-overlay.md`）。

C16 前置锁定门槛：模式确认（`mode-lock`）与研究取向确认（`research_orientation`）完成前仅做澄清，不得输出设计结论；FULL 须按 FRAME -> STORM -> DESIGN 顺序执行。

C17 跨学科覆盖与去重：STORM 至少覆盖 2 个学科，学科路由去重后最多保留 3 个并按相关度排序，高冗余学科通常选其一。

C18 证据可追溯要求：理论、证据与期刊要求均须追溯至已读文件、脚本输出或用户确认；缺口标注「待核验」，不得凭记忆补全。
