# Phase 01：FRAME 模式 — 单学科理论框架探索

进入本阶段前须已锁定工作模式（`FRAME` 或 `FULL` Stage 1）与研究取向（`research_orientation`）。若研究取向为「尚未确定」，仅比较备选取向与所需材料，不生成正式设计报告。

顾问派发遵循风险驱动原则：仅在理论适配、概念边界、领域定位或致命反例存在实质风险时选派最少必要角色，并将「待决问题—风险—选派角色—预期产出—未选理由」及顾问意见写入 `paper-workspace/_logs/agents/design-[YYYY-MM-DD]/`；轻量任务可记录 `agent-skip` 后直接生成报告。

按已确认取向补充要求：
- **实证取向**：保留可操作化与经验命题；
- **概念/解释取向**：补充概念账本、相邻概念区分、理论谱系与竞争框架；
- **规范取向**：补充评价对象、规范标准、原则冲突与反例；
- **思想史/文本阐释取向**：补充文本范围、版本、历史语境与竞争诠释；
- **混合取向**：明确主次路径及各自承担的材料分工。

## 触发条件

- 用户选择 `frame` 模式，或以「理论框架」「找理论」「理论定位」「理论锚点」为任务目标；
- `FULL` 模式第一阶段；
- 学科路由仅命中单一核心学科时建议先执行本模式。

## 输入要求

| 字段 | 是否必需 | 说明 |
|---|---|---|
| 研究主题 | 是 | 具体研究现象、核心议题或论题 |
| 主学科 | 是 | 经关键词初筛确定或由用户指定 |
| 目标期刊 | 否 | 用于校准理论定位深度与表述风格 |
| 已有理论偏好 | 否 | 用户既有的理论视角倾向 |

## 执行流程

### Step 1：关键词发散与框架初筛

1. **Step 1a（联网检索关键词发散）**：围绕研究主题执行至少 2 次联网检索（学术概念视角、跨学科视角），提取 5–10 个候选词并筛选为 3–8 个核心检索关键词（优先学术概念词、覆盖 ≥ 2 个学科视角、包含机制或方法线索词）。检索式、候选词与筛选理由写入过程日志。
2. **Step 1b（`frame_locator.py` 全库检索）**：将关键词传入检索脚本，获取候选框架文件、相关度分数、命中词与建议读取行号区间 `read_ranges`（即使用户已指定学科，仍须运行脚本记录 `read_ranges`）：

```bash
python3 scripts/frame_locator.py --topic "[研究主题]" --keywords "[关键词，空格分隔]"
# 若需限定学科：
python3 scripts/frame_locator.py --topic "[研究主题]" --keywords "[关键词]" --discipline "[学科key或中文名]"
```

脚本结果写入过程日志，并与原始研究主题及关键词一并作为顾问输入包。输出路由摘要：

```text
ROUTING RESULT
- 研究主题: [用户主题]
- 检索关键词: [3–8 个关键词]
- 主学科: [sociological / public-admin / ...]
- 备选学科: [如有]
- 相关度分数与命中词: [来自 frame_locator.py]
- 框架文件: frame/theory-frameworks-[discipline].md
- 建议读取行号: [read_ranges]
```

### Step 2：按行号区间加载框架条目

依据 `frame_locator.py` 输出的 `read_ranges`（`read_ranges[].start` 至 `read_ranges[].end`）读取候选框架文件的 3–8 个区间建立索引；仅当行号区间缺少理论边界、竞争理论或适用情境时，再向相邻标题段落扩展阅读（禁止未检索即全篇通读）：

```bash
FRAME_FILE="frame/theory-frameworks-${DISCIPLINE}.md"
sed -n '[start],[end]p' "$FRAME_FILE"
```

汇总学科理论框架总览（含板块、理论名、核心主张概括 ≤ 30 字、命中区间数与候选条目数）。

### Step 3：理论定位与机制映射

对每个高相关理论执行五维评估：
1. **匹配度（1–5★）**：★★★★★ 核心命题直接解释且概念可操作；★★★★☆ 有力视角需微调；★★★☆☆ 部分覆盖需补其他理论；★★☆☆☆ 边缘辅助；★☆☆☆☆ 基本不相关、强行套用易失焦。
2. **解释潜力**：提炼概念工具箱、机制链条与适用分析层次（个体/群体/组织/制度/国家）。
3. **机制映射**：将抽象机制映射至研究现象，按 `master/output-protocol.md` 绘制 Mermaid 机制图并附 2–4 条中文解释（说明节点、映射关系、可检验命题/论题与证据缺口）：

```mermaid
flowchart LR
  A[理论条件 A] --> B[理论机制 B]
  B --> C[经验/文本过程 C]
  C --> D[核心命题/论题 D]
```

4. **边界条件**：提取适用层次、适用情境（稳定/变迁/危机）、适用社会类型及已知学术批评。
5. **输出理论定位矩阵**（至少包含 5 个候选理论，前 2–3 个标为首选推荐）：

| # | 理论 | 板块 | 匹配度 | 解释潜力 | 机制可用性 | 边界条件 | 推荐等级 |
|---|---|---|---|---|---|---|---|

### Step 4：研究空白识别

依据框架条目中的「竞争/替代理论」「理论地位」「未解决的问题」梳理四类空白：
- **理论内部空白**：未充分检验的核心命题、机制黑箱或微观基础缺失；
- **理论间空白**：竞争理论对立预测及其调节/裁决条件；
- **经验/材料空白**：人群、情境、时间追踪、跨区域比较或文本语境缺失；
- **方法论空白**：因果识别不足、缺乏过程追踪、混合方法脱节或样本局限。

按创新潜力排序输出 **至少 5 项研究空白**：

| # | 空白类型 | 具体描述 | 理论依据 | 可研究性 | 创新潜力 | 推荐方法/路径 |
|---|---|---|---|---|---|---|

### Step 5：输出 FRAME 报告与日志记录

保存至 `paper-workspace/01-design/frame-report-[discipline]-[slug]-[date].md`，须包含六章：
1. 研究主题与学科定位（含路由依据）；
2. 理论框架总览；
3. 理论定位矩阵（前 5 个理论的五维详细分析）；
4. 研究空白清单（按四类分类）；
5. 推荐研究方向（3–5 个方向，含理论根基、预期贡献与初步可行性）；
6. 下一步建议（进入 STORM 跨学科拓展或直接进入 DESIGN 蓝图构建）。

将本步结果追加写入 `paper-workspace/_logs/process-log-design-[YYYY-MM-DD].md`。

## FRAME 质量自检

- [ ] 已按 `frame_locator.py` 的 `read_ranges` 加载框架条目并记录扩展行号
- [ ] 理论定位矩阵包含 ≥ 5 个候选理论且均具五维评估
- [ ] 研究空白引用框架中的竞争理论与理论地位信息，覆盖 ≥ 2 类空白
- [ ] 推荐研究方向具备清晰理论根基，且符合已确认的 `research_orientation`
- [ ] 报告包含全部六个必需章节
