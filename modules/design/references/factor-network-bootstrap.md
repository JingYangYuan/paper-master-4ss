# 因子分析、社会网络与 Bootstrap 参考

> 为 DESIGN 模式提供：因子分析完整决策链、社会网络分析设计规范与结构测度、Bootstrap 重抽样推断。

---

## 一、因子分析

### 核心原则

因子分析是**测量模型**而非数据化简技巧。每个因子携带关于"为什么这些指标一起变动"的实质主张。旋转是必要的——初始数学因子很少是可解释因子。

### 完整决策链

```
选择抽取方法 → 确定因子数目 → 选择旋转 → 解释载荷 → 稳定性检验 → （可选）CFA
```

### 抽取方法

| 方法 | 目标 | 适用 |
|------|------|------|
| PCA | 汇总方差（加权组合） | 降维 |
| 共同因子 | 建模共享潜变量 | 测量模型 |
| 最大似然 | 假设多元正态下的潜变量 | CFA 前提、拟合检验 |
| Alpha / 影像 | 信度导向 / 预测导向 | 特殊需求 |

**PCA ≠ 共同因子**——前者汇总方差，后者建模潜结构。选择取决于目的而非默认。

### 因子数目：多准则收敛

**不允许单一机械规则**。需要以下准则的收敛：
1. 显著性检验（Bartlett/Maximum Likelihood χ²）
2. 特征值准则（>1 仅作为次参考）
3. 碎石检验（视觉拐点——最推荐的启发式）
4. 平行分析（Horn 1965：随机数据特征值作为基准）
5. 实质重要性（因子可被清晰命名和理论解释）
6. 稳定性（分半/交叉验证中因子结构是否保持）

### 旋转

- **正交旋转**（varimax/quartimax）：因子不相关
- **斜交旋转**（promax/direct oblimin）：允许因子相关
- **选择依据**：理论——如果你的潜变量理论上相关（大多数社科情境），默认斜交
- **旋转改变视角而非底层相关**：旋转重新分配方差以提升可解释性，不改变再产生相关矩阵

### CFA（验证性因子分析）

- **不同于 EFA**：CFA 检验预先指定的载荷模式——看到拟合不好后修改=不再是验证
- **拟合指数**：CFI ≥ .95, TLI ≥ .95, RMSEA ≤ .06, SRMR ≤ .08（启发式而非绝对）
- **修正指数 > 3.84**：需理论辩护，非自动释放
- **测量不变性**：跨组/跨时间比较的前提——层级检验（configural → metric → scalar → strict）

### 因子得分

- 因子得分不确定性是根本问题——多个得分估计可能与同一因子模型一致
- 在后续模型中使用因子得分时报告不确定性
- 报告替代得分方法（回归得分/Bartlett/Anderson-Rubin）的敏感性

### 关键反模式

- 特征值>1 作为自动规则
- 看到载荷后命名因子而无理论和稳定性
- 潜变量理论上相关却默认正交旋转
- 把因子得分当作无误差观测变量输入下游模型

## 二、社会网络分析

### 核心原则

关系先于属性——如果属性本身能回答问题，可能不需要网络分析。**边界是理论决策**——改变边界可以改变所有网络统计量。

### 设计规范（必须在分析之前）

| 决策 | 问题 |
|------|------|
| **行动者集合** | 谁是节点？ |
| **关系内容与类型** | 什么构成联结？方向？权重？ |
| **边界规则** | 谁在网内？谁在网外？标准？ |
| **分析层级** | 个体/二元/三元/子群/全网？ |
| **数据收集** | 自我中心网 vs 全网？ |

### 自我中心网 vs 全网

- **自我中心网**：个人关系环境——适合大规模调查中的社交资源研究
- **全网**：所有行动者间的结构模式——适合组织/社区/政策网络研究
- 两者回答不同问题，不可互换

### 结构测度：选择匹配理论的机制

| 理论问题 | 网络概念 | 典型测度 |
|---------|---------|---------|
| 全网有多连通？ | 凝聚 | 密度、成分、k-核 |
| 谁最活跃？ | 局部活动 | 度数中心度 |
| 谁能快速到达他人？ | 可达性 | 接近中心度 |
| 谁在他人之间搭桥？ | 中介/经纪 | 中介中心度 |
| 谁与重要者连接？ | 递归声望 | 特征向量中心度 |
| 谁占据相似位置？ | 角色等价 | 结构等价、块模型 |
| 行动者如何共享事件？ | 隶属/二模 | 二模网络测度 |

**中心度不是单一概念**——度数、接近、中介和特征向量中心度回答不同的重要性问题。

### 高级模型

- **ERGM / p***：建模联结概率作为局部网络构型（边、互惠、传递性）的函数——解决联结非独立问题
- **隶属/二模网络**：连接行动者与事件的双层结构
- **ERGM 退化问题**：某些参数组合导致模型只产生空网或全网——GOF 诊断是关键

### 关键反模式

- 收集便利联结列表而无边界规则——最根本的设计错误
- 报告单一中心度测度作为"一般重要性"
- 混合有向和无向解释
- 忽视知情者偏误、回忆偏误和信度
- 用可视化代替定量检验作为证据

## 三、Bootstrap 推断

### 核心原则

Bootstrap 通过从观测数据的经验分布有放回重抽样来估计未知抽样分布——当参数公式不可用、脆弱或误导时。**Bootstrap 是诊断和推断工具**——它不修复差设计或差测量。

### 核心假设

**原始样本必须合理代表总体结构**——Bootstrap 继承了原始样本的代表性问题，不能从差的原始样本中创造新信息。

### 工作流

```
计算原始统计量 → 有放回重抽样 B 次 → 每重抽样计算统计量 → 
Bootstrap 分布 → 估计标准误（分布 SD）→ 估计偏误（均值 - 原始值）→ 构建 CI
```

### 四种置信区间

| 方法 | 原理 | 适用 |
|------|------|------|
| 正态近似 | Bootstrap SE × 正态分位数 | 分布对称、大样本 |
| 百分位 | Bootstrap 分布的 α/2 和 1-α/2 分位数 | 偏态弱-中 |
| 偏误校正百分位（BC） | 修正 Bootstrap 分布中位数与原始估计的偏离 | 中等偏态 |
| 百分位-t | 基于 Bootstrap t 统计量的分位数 | 标准误变异大时 |

### 适用边界

| 可以 | 不可以 |
|------|--------|
| 估计复杂统计量的 SE/偏误/CI | 修复差的原始样本 |
| 替代不可靠的参数推断 | 弥补偏误设计或测量 |
| 处理聚类数据（以聚类为重抽样单位） | 忽略聚类/复杂调查设计 |
| 评估推断程序性能（Monte Carlo） | 自动降低点估计偏误 |

### Monte Carlo 评估

从已知 DGP 重复采样和重抽样，比较不同推断程序的覆盖率和错误率——当真值通过构造已知时，这是方法论比较的最干净方式。

### 关键反模式

- 原始样本太小或不具代表性时使用 Bootstrap
- 假设更多重抽样修复偏误设计
- 报告 Bootstrap 点估计作为"自动偏误更小"
- 忽略尾部行为（CI 依赖极端分位数时）
