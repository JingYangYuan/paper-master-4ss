# 定量方法路由器

> 为 DESIGN 模式提供：从研究问题到模型选择的快速路由、七步诊断序列、报告规则和各学科方法偏好。

## 一、快速模型路由

| 研究情境 | 起点 | 详细参考 |
|---------|------|---------|
| 连续 Y，条件均值差异 | OLS / 多元回归 | `regression-models.md` §一 |
| 二分类 Y | Logistic 回归 | `regression-models.md` §二 |
| 名义或序次 Y | 多项式 / 序次 Logistic | `regression-models.md` §三 |
| 相同单位随时间变化，因果顺序 | 面板因果模型 | `panel-models.md` §一 |
| 设计或评估重复测量 | 纵贯设计审计 | `panel-models.md` §二 |
| 多个指标反映潜变量构念 | 因子分析 | `factor-network-bootstrap.md` §一 |
| 行动者之间的关系 | 社会网络分析 | `factor-network-bootstrap.md` §二 |
| 未知抽样分布、参数推断可疑 | Bootstrap 推断 | `factor-network-bootstrap.md` §三 |
| 估计政策因果效应 | DiD / RD / IV / SCM | `identification-strategies.md` §一 |
| 需要数学解释 | 矩阵/概率/MLE 基础 | `regression-models.md` §〇 |

## 二、七步诊断序列

**通用工作流——方法不可知，适用于所有定量模型：**

1. **定义 estimand**：均值差异、概率变化、发生比率、因果效应、潜变量、网络位置或抽样不确定性——在选模型之前明确要估计什么
2. **映射数据结构**：截面 / 面板 / 纵贯队列 / 重复截面 / 关系矩阵 / 指标组——数据结构决定可用的模型族
3. **检查测量**：变量尺度、缺失机制、信度、边界定义、测量误差——构念是观测的还是潜变的
4. **拟合最简可辩护模型**：从直接编码 estimand 的模型出发，仅针对已识别的偏误/设计/理论增加复杂度
5. **诊断假设**：线性、独立、分布、共线性、分离、损耗、自相关、共同因子、旋转模糊性、网络边界偏误
6. **转换系数到实质尺度**：用回答实质问题的尺度报告效应——不是估计尺度，是沟通尺度
7. **压力测试推断**：稳健检验、替代规格、Bootstrap、模拟或模型比较——当假设不确定时

## 三、红牌警告速查

| 症状 | 可能问题 | 检查方向 |
|------|---------|---------|
| 加控制后系数大变 | 混淆或共线性 | `regression-models.md` §一 |
| Logistic 估计极大或不稳 | 分离/稀疏格 | `regression-models.md` §二 |
| 加滞后 Y 后面板效应消失 | 持续性或过度控制 | `panel-models.md` §一 |
| 多波次大量受访者丢失 | 损耗偏误 | `panel-models.md` §二 |
| 因子难以命名 | 因子数目或旋转错误 | `factor-network-bootstrap.md` §一 |
| 边界改变后中心度变化 | 边界依赖性 | `factor-network-bootstrap.md` §二 |
| Bootstrap 尾部不稳定 | 小样本或不具代表性 | `factor-network-bootstrap.md` §三 |
| DiD 处理前趋势不平 | 平行趋势违反 | `identification-strategies.md` §一 |
| 第一阶段 F < 10 | 弱工具变量 | `identification-strategies.md` §二 |

## 四、报告规则

| 模型 | 必须报告 |
|------|---------|
| OLS | 斜率 + 标准误 + R2 + 残差诊断 + 实质单位变化量 |
| Logistic | 预测概率 + 发生比率 + 分离/稀疏性检查 + 伪 R2 |
| 面板因果 | 时序假设 + 滞后结构 + 未观测稳定性威胁 |
| 纵贯设计 | 设计类型 + 各波损耗率 + 缺失数据处理假设 |
| 因子分析 | 抽取方法 + 旋转方法 + 因子数目准则 + 载荷表 + 得分构建逻辑 |
| 网络分析 | 行动者边界 + 联结定义（方向/权重）+ 缺失联结处理 + 选择的中心度逻辑 |
| Bootstrap | 重抽样单位 + B 值 + 区间类型 + 为何参数推断不足 |
| 因果识别 | 识别假设陈述 + 假设检验策略 + 稳健性/安慰剂检验 |

## 五、各学科定量方法偏好

| 学科 | 主流识别策略 | 典型数据来源 | 期刊偏好 |
|------|-------------|-------------|---------|
| 社会学 | FE / DiD / 自然实验 / 混合方法 | GSS, Add Health, PSID, CFPS, CGSS | ASR 偏好强识别+理论深度 |
| 公共管理 | DiD / RD / IV / 案例比较 | 行政数据, 调查数据 | JPART 偏好定量因果 |
| 心理学 | 实验（实验室/调查/田野） | 实验数据, 面板调查 | 顶刊偏好多实验+大样本+预注册 |
| 传播学 | 调查实验 / 内容分析 / 面板调查 | 媒体内容数据, 调查面板 | 偏好混合方法 |
| 经济学 | DiD / RD / IV / RCT / 结构估计 | 行政数据, 面板调查 | 偏好"干净识别"+ 稳健性 |
| 教育学 | RCT / 准实验 / 设计研究 | 学校行政数据, PISA | AERA 偏好 RCT |
| 政治学 | 自然实验 / DiD / 调查实验 / IV | 选举数据, 跨国调查 | APSR 偏好强因果识别 |
