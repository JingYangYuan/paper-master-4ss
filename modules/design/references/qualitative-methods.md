# 质性研究方法参考

> 为 DESIGN 模式提供：七种质性设计家族选择、全流程模型、数据收集与分析、质量逻辑、反身性伦理与写作规范。

---

## 一、质性适用性判定

**适合质性研究**当研究问题问的是：
- 某事物**意味着什么**
- 一个过程**如何展开**
- 人们**如何解释**某一处境
- 一个文化或群体**如何运作**
- 一个案例**如何阐明**某一议题
- 实践如何通过参与**被改变**

**不适合质性**当主要需求是：流行率估计、效应量大小、因果效应检验、广泛总体的假设检验——此时优先定量或混合方法。

### 认识论立场对设计的约束

质性设计不是认识论中立的。在方案阶段明确立场，因为它约束后续所有方法选择：

| 范式 | 认识论 | 分析取向 | 质量标准 |
|------|--------|---------|---------|
| **后实证主义** | 实在论 | 系统编码、信度评估、编码者间协议 | 内部效度、可复现性 |
| **建构主义/解释主义** | 意义由社会文化建构 | 归纳编码、主题涌现、情境化解释 | 可信性、反身性透明 |
| **批判理论** | 权力/意识形态揭示 | 权力分析编码、话语解构、解放导向 | 启蒙性、社会转化 |
| **实用主义** | "什么有效" | 混合方法整合 | 实用效度、可操作性 |

**设计时的自检**：你的认识论立场决定——编码是预定义还是涌现？是否需要报告信度系数？反身性的角色是什么？对"客观性"的宣称程度？

## 二、七种设计家族

| 研究意图 | 设计 | 核心产出 | 核心方法 |
|---------|------|---------|---------|
| 讲述个人/少数人的生命或经验故事 | **叙事研究** | 故事、转折点、主题 | 生活史访谈、叙事分析 |
| 描述多人对同一现象的共享经验本质 | **现象学** | 经验的本质结构 | 深度访谈、现象学还原 |
| 从资料中生成过程/行动/互动理论 | **扎根理论** | 过程理论/模型 | 理论抽样、三级编码、持续比较 |
| 理解一个文化共享群体 | **民族志** | 厚的文化描述 | 参与观察、田野札记、深描 |
| 通过有边界个案深入理解议题 | **案例研究** | 案例描述+主题/断言 | 多证据来源、模式匹配、证据链 |
| 与实践者共同改进实践 | **行动研究** | 行动循环+反思学习 | 参与式循环（计划-行动-观察-反思） |
| 保存和解释个人或集体记忆 | **口述史** | 叙事化历史+档案 | 口述访谈、档案收集 |

**方法标签不是装饰**——称研究为扎根理论、民族志或现象学却不遵守该设计的分析义务是根本性方法错误。

### 抽样策略选择

抽样在设计阶段决定，不是数据收集时才考虑：

| 策略 | 说明 | 适用 |
|------|------|------|
| 目的性抽样 | 按理论相关性选择个案 | 典型/关键案例 |
| 最大变异抽样 | 覆盖最广泛的变异范围 | 异质性大的总体 |
| 极端/偏差案例 | 选择极端值或异常值 | 检验理论边界 |
| 滚雪球抽样 | 通过受访者推荐下一个 | 隐藏或难以接触的人群 |
| 理论抽样 | 边收集边分析，按新兴理论引导下一步 | 扎根理论专用 |
| 分层目的抽样 | 在子群体内做目的性抽样 | 跨群体比较 |

### 饱和度标准

在设计阶段就确定停止收集的规则：

- **理论饱和**：新数据不再产生新的理论见解或范畴属性——扎根理论的核心停止标准
- **主题饱和**：新数据不再产生新主题——适用于主题分析和框架分析
- **数据饱和**：没有新的信息/模式出现——最保守的标准
- **实操建议**：在预计数据收集量的 80% 时做一次饱和评估，决定是否需要补充

## 三、全流程模型（七步）

```
定位研究立场 → 聚焦研究问题 → 设计方案 → 收集密集资料 → 
归纳迭代分析 → 验证与反身审计 → 学术写作
```

### 步骤 1：定位研究立场
澄清世界观（实证主义/建构论/实用主义/批判）、理论取向、价值立场，以及质性探究为何适合该问题。

### 步骤 2：聚焦研究问题
命名中心现象、目标读者、文献缺口和知识贡献。一个中心问题 + 若干子问题。中心问题应命名**中心现象**、**参与者或场域**和**开放的探索性动作**。好的动词：理解、探索、描述、解释、呈现、考察。避免过早使用因果性、变量驱动或评价性语言。

### 步骤 3：设计方案
选择设计家族（§二）、确定场域和参与者、目的抽样逻辑、资料类型、伦理方案和分析路径。

### 步骤 4：收集密集资料
三合一收集（§四）：访谈（意义与叙述）+ 观察（行为与情境）+ 文件/影像（制度痕迹与历史脉络）。每种来源要么三角验证同一主张，要么提供独特的分析角度。不要把无关来源仅仅因为数量多称为"三角验证"。

### 步骤 5：归纳迭代分析
精益编码模型（§五）：准备资料→通读→备忘录→编码→缩减→聚类→发展主题→关联主题→检验解释。

### 步骤 6：验证与反身审计
质量逻辑（§六）：三角测量、成员互查、负面案例、同行检视、审计轨迹、编码者一致性和反身写作。

### 步骤 7：学术写作
按照设计类型组织章节结构，报告厚描述、证据、研究者角色、局限性和设计特定的呈现方式。

## 四、资料收集三合一

质性资料是**密集证据**，不是原始插图。

| 来源 | 收集什么 | 核心技能 |
|------|---------|---------|
| **访谈** | 意义、叙事、解释、参与者语言 | 半结构化访谈指南梯级法（从经验近的问题开始→具体事件→意义比较→反思→参与者补充） |
| **观察** | 行为、场域、互动、日常实践、身体化实践 | 田野札记五层堆叠（描述性/分析性/方法论/反身性/后续追问），观察后尽快记录 |
| **文件/影像/实物** | 制度痕迹、话语、视觉证据、历史脉络 | 系统收集、来源标注、与访谈和观察交叉印证 |

**设计原则**：规划研究时确保每种资料来源要么三角验证同一主张，要么贡献独特的分析角度。案例研究尤其需要多证据来源。

### 访谈指南七要素

设计访谈协议时逐项覆盖：

1. **基本信息记录**：日期、地点、时长、编号
2. **介绍与同意**：研究目的、保密承诺、录音许可、退出权
3. **开场问题**：宽泛轻松的问题让受访者进入叙述状态
4. **核心问题**：围绕研究问题的开放式问题（5-8 个）
5. **追问提示**：为每个核心问题预设 2-3 种追问方向
6. **跟进问题**：根据受访者回答灵活跟进
7. **结束说明**：感谢、后续联系方式、资料用途确认

**追问十类**：举例 / 原因 / 对比 / 时间线 / 感受 / 含义 / 情境 / 行动者 / 后果 / 澄清。

### 田野札记五层结构

设计观察协议时明确五层记录格式：

| 层次 | 标注 | 内容 |
|------|------|------|
| 描述层 | (D) | 事件、行为、对话、空间、物品、时间的客观记录 |
| 分析层 | (A) | 初步分析直觉、涌现模式、与已有编码或理论的连接 |
| 方法层 | (M) | 观察选择、焦点变化、数据收集决策及其理由 |
| 反身层 | (R) | 研究者的情感反应、角色感知、权力关系变化 |
| 追问层 | (Q) | 下次观察或访谈需要追问的问题 |

**观察抽样五维度**：时间（哪些时段？）、地点（哪些空间？）、事件（哪些类型？）、行动者（观察谁？）、互动（哪些互动类型？）。

## 五、精益编码模型

```
通读资料库 → 备忘录（第一印象） → 切分文本 → 贴短标签 → 
缩减重叠标签 → 聚类 → 发展主题（5-7个）→ 关联主题 → 检验解释
```

**建议规模**：初始 30-50 个代码 → 缩减到约 20 个代码 → 聚类为 5-7 个主题。

**关键动作**：
- **开放编码**：在资料中识别概念并贴上初始标签
- **轴心编码**：分析类别之间的条件、行动/互动和后果关系
- **选择性编码**：围绕核心类别整合其他类别并形成理论叙事
- **实境代码**：当参与者语言携带分析力量时优先使用
- **持续比较法**：数据与数据、数据与概念、概念与概念的系统比较
- **理论饱和**：新资料不再显著增加类别属性或理论关系

**反模式**：代码只列不聚类、不发展为概念/主题/理论——代码本身不是分析结果。

### 编码本设计八要素

在方案阶段就规划编码本结构，每条编码必须包含：

1. **编码名称**：简短标签（最多 4-5 词）
2. **清晰定义**：该编码捕捉什么现象
3. **纳入标准**：什么文本属于该编码
4. **排除标准**：什么文本不属于该编码（边界）
5. **典型例子**：至少 2 条，附原文摘录
6. **边界案例**：模棱两可的情况及处理规则
7. **与相近编码的区别**：如"焦虑"≠"恐惧"
8. **修订记录**：日期 + 修订理由

**编码本演进计划**：V1.0（前 20% 数据归纳，20-50 编码）→ V2.0（应用到 50% 数据后合并/拆分/新增）→ V3.0（终版锁定）。每次演化需记录理由。

## 六、质量逻辑

用**适合目的的可靠性**取代泛泛的"效度/信度"话语：

| 质量需求 | 策略 | 检验问题 |
|---------|------|---------|
| **可信性** | 成员互查、长期投入、持续观察、三角测量、负面案例、同行检视 | 参与者是否认可你的解释？ |
| **可转移性** | 对案例、情境、参与者和边界的厚描述 | 读者能否判断其是否适用自身情境？ |
| **可依靠性** | 审计轨迹、清晰协议、记录的分析决策 | 另一位研究者能否追踪你的分析路径？ |
| **可确认性** | 反身备忘录、证据链、外部审计、区分资料与解释 | 结论是否植根于资料而非研究者预设？ |
| **分析深度** | 主题主张、过程模型、理论或案例断言 | 分析是否超越了描述？ |

**负面案例检验**：初步主题浮现后，主动搜索与之矛盾的个案、段落、事件或文件——修正、限定或拆分主题。

**证据链**：每条主张→编码资料→来源类型→参与者/案例→备忘录→分析决策——形成可追踪的完整链条。

## 七、反身性规则

研究者的角色应作为**方法的一部分**书写，而非作为道歉。

追踪以下如何塑造抽样、提问、解释和写作：
- 背景（学科训练、理论取向）
- 进入（门路、身份、权力、语言）
- 情感（共鸣、疏离、情绪反应）
- 场域关系（信任、距离、互惠）
- 先前承诺（期望、价值观、理论偏好）

**反模式**：反身性缺失（研究者的在场被完全抹去）或纯自传式（只写自己而脱离方法）。

## 八、伦理贯穿全程

伦理不是同意书形式主义——是贯穿田野前、田野中、田野后的持续实践。

| 阶段 | 风险 | 保障 |
|------|------|------|
| 进入 | 知情同意、自愿参与 | 清晰说明目的、流程和退出权 |
| 收集 | 录音/记录、隐私、互惠 | 匿名化、参与者审查权、合理回报 |
| 分析 | 呈现、偏见、泄露 | 成员互查、反身审计、安全存储 |
| 发表 | 呈现方式、署名、再利用 | 参与者审查、数据使用协议 |

## 九、主题段落标准

质性主题段落六要素：
1. **主题标题**植根于资料语言
2. **多种证据**（访谈+观察+文件）
3. **短而有力的引语或观察**
4. **多资料来源**（如相关）
5. **解释该模式的意义**
6. **回到研究问题的连接**

**反模式**：引语堆砌——用长段参与者原话替代分析性解释。

## 十、常见反模式

| 反模式 | 表现 | 修复 |
|--------|------|------|
| **变量漂移** | 使用质性语言但设计了伪装的变量研究 | 回到研究问题语法——它问的是意义还是效应？ |
| **话题太近** | 在自己后院研究而无反身性和伦理保障 | 明确角色、边界和退出策略 |
| **访谈榨取** | 把参与者当作答案机器而非意义的共同建构者 | 互动式对话而非问卷式提取 |
| **薄编码** | 代码只列不聚类，不发展为主题或理论 | 强制自己写出主题主张和证据链 |
| **引语堆砌** | 用长段参与者原话替代分析性解释 | 先写主题主张，再用浓缩引语作为支撑证据 |
| **假三角测量** | 收集多种资料但不验证或深化同一主张 | 明确每种来源的分析角色 |
| **方法标签装饰** | 自称扎根理论/民族志/现象学但不遵守设计义务 | 要么执行该设计的核心方法，要么改用更合适的设计名称 |
| **伦理止于同意书** | 忽视权力、风险、互惠、保密和呈现 | 伦理审计全程化 |

---

## 十一、发表适配扫描

提交前检查：期刊读者群、方法期待、字数限制、贡献类型、引用规范、伦理报告要求和质性严谨标准。质性论文的发表适配不仅是投稿技术——期刊的方法论取向决定了你的设计是否被认真对待。
