# 回归与 Logistic 参考

> 为 DESIGN 模式提供：OLS 回归设定与诊断、Logistic 回归三尺度解释与诊断、数学基础速查。

---

## 〇、数学基础速查

### 矩阵代数
- **秩（rank）**：设计矩阵中独立信息的量——不满秩则系数不可分别估计
- **特征值与特征向量**：协方差结构→降维的桥梁（因子分析/PCA 的核心）
- **正定矩阵**：有效方差-协方差矩阵的必要条件
- **思维方式**：线性代数=记账+几何——同一方程同时告诉你变量如何组合和观测在空间中位于何处

### 优化与估计
- **最小二乘**：选择使残差平方和最小的系数
- **MLE**：选择使观测数据在假设模型下最可能出现的参数——似然函数是"模型合同"
- **贝叶斯**：先验信念 × 数据似然 → 后验分布
- **渐近理论**：大数定律+中心极限定理——解释大样本行为，不修复差测量或差设计

### 关键反模式
- 不验证维度就套公式（矩阵维度、秩）
- 把显著性等同于模型充分性
- 说不清目标函数（在最小化/最大化什么？）

## 一、OLS 回归

### 核心逻辑

回归系数是比较规则而非因果效应。二元拟合线是形状的总结——先看形状（散点图），再看线（斜率）。

```
散点图 → 二元拟合 → 残差检查 → 发现遗漏变量 → 加入理论控制变量 → 
比较系数变化 → 诊断 → 报告条件效应
```

### 关键概念

| 概念 | 含义 | 注意事项 |
|------|------|---------|
| 截距 | X=0 时 Y 的期望值 | 仅当零值有意义时可用 |
| 斜率 | X 变动一单位时 Y 的期望变化 | 在多元回归中=条件效应 |
| R² | 模型解释的结果变异比例 | 高 R² 可与偏误并存 |
| 残差 | 观测值 - 预测值 | 模型未学到什么的最快诊断 |
| 共线性 | 预测变量之间的冗余 | 不一定偏误系数，但使系数过不稳定 |

### 五大诊断维度

1. **线性**：残差 vs 拟合图——系统性弯曲=非线性
2. **残差结构**：等方差（Scale-Location）、正态（Q-Q）、独立（Durbin-Watson）
3. **影响点**：Cook's D > 4/n、高杠杆值——哪些个案不成比例地拉动拟合
4. **共线性**：VIF > 10 或条件指数 > 30 = 严重
5. **遗漏变量**：系数在加控制后大幅移动=混淆或共线性信号

### 关键反模式

- 非显著结果不检查功效或共线性就声称"无效应"
- 机械加控制——控制可能减少偏误也可能制造偏误（取决于因果结构）
- 零值不在数据范围内却直译截距
- 把预测误差和因果误差当成同一问题

## 二、Logistic 回归

### 核心逻辑

结果尺度驱动模型选择——二分类/多分类/序次结果需要 Logistic 而非 OLS。S 曲线而非直线：同一系数在概率接近 0.5 时效应最大。

### 三尺度解释栈

| 尺度 | 用途 | 注意 |
|------|------|------|
| Logit 系数 | 估计和假设检验 | 实质解释困难 |
| 发生比率（OR） | 乘法比较 | ≠ 风险比，基线概率高时 OR 大幅偏离 RR |
| 预测概率 | 实质沟通和情境比较 | 依赖协变量取值剖面 |

**转换原则**：用 Logit 做诊断、OR 做紧凑比较、预测概率做实质解释。

### 专属诊断

| 问题 | 表现 | 应对 |
|------|------|------|
| 完全分离 | 标准误极大、系数极大、迭代不收敛 | 惩罚似然（Firth）、精确 Logistic |
| 零格/稀疏格 | 交叉表某些格频数为零 | 合并类别、精确方法 |
| 过离散 | Pearson χ²/df >> 1 | 准二项模型、负二项替代 |
| 伪 R² | 不等于 OLS R² 的解释效能含义 | 用似然比检验和预测准确度补充 |

**稀有事件偏误**（King & Zeng 2001）：当事件发生率极低（<5%）时，MLE 向零偏误，用惩罚似然或 Firth 修正。

## 三、多项与序次 Logistic

### 多项 Logit（名义结果）

- 基准类别对比：每个类别 vs 参照类
- 核心假设：IIA（无关方案独立性）——在选项相似时被违反
- 诊断：Hausman-McFadden IIA 检验

### 序次 Logit/Probit（有序结果）

- 核心假设：比例发生比（各切点处系数相同）
- 诊断：Brant 检验
- 通过=序次 Logit；不通过=广义序次 Logit 或多项 Logit

### 决策链

```
判断类别性质 → 名义：多项 Logit（检验 IIA）
            → 序次：检验比例发生比 → 通过：序次 Logit
                                  → 不通过：广义序次 / 多项 Logit
```

## 四、跨章连接

- 矩阵基础 → OLS 投影几何 → 特征值/因子分析
- OLS 诊断 → Logistic（推广到非线性链接）
- Logistic 的 Logit 逻辑 → p*/ERGM 网络模型
- MLE → 所有广义线性模型（Logistic/Poisson/Tobit）的估计基础
- Bootstrap → 当残差或抽样假设可疑时的推断替代
