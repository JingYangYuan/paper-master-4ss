# 因果识别策略与稳健性参考

> 为 DESIGN 模式提供：识别策略匹配矩阵、面板数据方法、稳健性检验清单和因果推断设计优先原则。

---

## 一、识别策略匹配矩阵

根据数据结构、处理分配方式和理论要求的因果强度，匹配识别策略：

| 理论要求 | 数据结构 | 推荐识别策略 | 关键检验 |
|---------|---------|-------------|---------|
| 无混淆估计 X→Y（金标准） | 实验数据 | RCT | 平衡检验、ITT/ATE 分析 |
| 无混淆估计 X→Y（观测） | 面板/重复测量 | 双向固定效应 | 平行趋势检验（事件研究图） |
| 政策因果效应 | 面板/渐进实施 | 交错 DiD | 前趋势检验 + 异质性处理效应诊断（CS-DiD/Sun-Abraham） |
| 阈值附近因果 | 截面/面板，规则性断点 | RDD（精确/模糊） | McCrary 密度检验 + 前定变量平衡 |
| 外生变异来源 | 截面/面板，有效 IV | 2SLS / IV | 第一阶段 F > 10 + 过度识别检验 |
| 观测混淆下的因果 | 截面/面板，丰富协变量 | PSM / IPW / CEM | 平衡检验 + 共同支撑区 + 敏感性分析 |
| 单一处理单位 | 长面板（单一聚合单位） | SCM / SDID | 安慰剂检验、留一交叉验证 |
| 机制检验 | 面板/实验，M 可测量 | 因果中介分析 | 序贯可忽略性假设的敏感性分析 |
| 非因果（描述/关联） | 任意 | 描述统计/关联分析 | 抽样代表性、测量信效度 |

## 二、核心识别策略详解

### RCT（随机对照试验）
- **优势**：随机化消除所有可观测和不可观测混淆——金标准
- **局限**：黑箱（估计平均效应但不揭示机制）、外部效度（局部 ATE 不可推广）、伦理约束
- **处理不遵从**：ITT（保守无偏）vs CACE/LATE（需排他性约束）

### DiD（双重差分）
- **核心假设**：平行趋势——若无处理，处理组与对照组的趋势相同
- **诊断**：事件研究图——处理前系数应统计不显著
- **交错 DiD 的陷阱**：TWFE 在异质性处理效应下产生负权重偏误 → 用 Callaway-Sant'Anna / Sun-Abraham / Goodman-Bacon 分解
- **标准误**：需聚类标准误（Bertrand, Duflo and Mullainathan 2004）

### RDD（回归不连续设计）
- **优势**：最接近 RCT 的观测因果推断方法——断点处局部随机化
- **精确 RD**：断点完全决定处理 → Sharp 估计
- **模糊 RD**：断点影响处理概率 → IV 型估计（ITT/遵从率）
- **带宽选择**：过宽=偏误，过窄=方差大——局部线性+数据驱动带宽（CCT 2014）

### IV/2SLS（工具变量）
- **识别条件**：相关性（Z 与 X 强相关）+ 排他性（Z 仅通过 X 影响 Y）+ 单调性
- **弱 IV**：第一阶段 F < 10 → 有限样本偏误向 OLS 收缩，推断失效
- **LATE**：IV 估计"遵从者"的局部平均处理效应，非总体 ATE
- **排他性不可直接检验**——过度识别检验提供间接证据

### PSM/IPW（倾向值匹配/逆概率加权）
- **核心假设**：CIA（条件独立性）——所有混淆变量已测量
- **匹配后必须检查平衡**：标准化偏差 < 0.1 或方差比接近 1
- **共同支撑区**：处理组和对照组的倾向值分布重叠区域
- **敏感性分析**：Rosenbaum bounds（评估未观测混淆的潜在影响）

### SCM/SDID（合成控制/合成双重差分）
- **SCM**：构造处理单位的加权组合作为反事实——要求预处理期足够长
- **SDID**：融合 DiD 的时间维度和 SCM 的截面维度——预处理趋势不完美平行时优于 DiD
- **安慰剂检验**：核心诊断工具——对每个对照单位做"假处理"并比较效应

## 三、面板数据方法

### FE vs RE vs 混合 OLS

| 方法 | 假设 | 估计 | 何时用 |
|------|------|------|--------|
| 混合 OLS | α_i = 0 或与 X 无关 | OLS | 几乎总被拒绝 |
| 随机效应 (RE) | α_i 与 X_it 无关 | GLS | Hausman 检验不显著时 |
| 固定效应 (FE) | α_i 可与 X_it 相关 | 组内变换 | Hausman 检验显著时（默认） |

**Hausman 检验**：H ~ χ²(k)——显著 → 拒绝 RE 一致性 → 用 FE

### 动态面板 GMM

- **Arellano-Bond 差分 GMM**：用滞后水平作为差分方程的工具变量
- **Blundell-Bond 系统 GMM**：进一步用差分的滞后水平作为水平方程的工具变量——序列相关性高时优于差分 GMM
- **"太多矩条件"问题**（Roodman 2009）：限制工具变量矩阵列数不超过 N 或 T 的较小值

### 面板模型的局限

- FE 仅消除时不变异质性——时变混淆仍可能造成偏误
- 动态面板 GMM 在 T 大时工具变量激增——过度拟合和弱 IV
- 面板单位根和伪回归——长面板需先做单位根检验

## 四、稳健性方案清单

| 检验 | 目的 | 对应理论关切 |
|------|------|-------------|
| 替代操作化 | X/Y 的测量依赖性 | 理论构念是否被特定操作化所绑定 |
| 替代样本限制 | 样本构成的敏感性 | 理论的边界条件/人群适用范围 |
| 加入/移除控制 | 混淆变量的敏感性 | 竞争理论是否通过遗漏变量解释结果 |
| 排除影响点 | 极端值的驱动 | 理论是否仅适用于特定子群 |
| 安慰剂结果 | 虚假关联 | 理论指定的机制是否特定于 Y |
| 安慰剂处理 | 虚假时机（DiD 用） | 处理效应的时间结构是否与理论一致 |
| 敏感性分析 | 未测量混淆的界值 | 竞争解释在多大混淆强度下可推翻结论 |
| Bootstrap/随机化推断 | 参数假设的脆弱性 | 推断对分布假设的敏感度 |

## 五、因果推断设计优先原则

**研究设计优先于统计模型**——因果推断的可信度首先取决于识别策略，其次才取决于估计方法。

### 设计优先流程

```
明确因果问题 → 选择识别策略 → 陈述核心假设 → 检验策略 → 稳健性
```

### 识别策略选择决策树

```
有随机化？
  → 是：RCT
  → 否：有断点？
    → 是：RD
    → 否：有外生工具变量？
      → 是：IV
      → 否：有处理前后数据？
        → 是：DiD（交错？→ CS-DiD / Sun-Abraham）
        → 否：有丰富截面数据+可观测混淆？
          → 是：PSM + 敏感性分析
          → 否：描述 + 机制推断（过程追踪/案例研究）
```
