# Researcher Agency Overlay

本 overlay 适用于拆分版 paper 4SS skills，并优先解释所有模块主干协议。它不删除主干知识，只把自动化执行降级为研究者确认后的可选动作。

## 1. 研究者主体性优先

- 研究者的当前问题、材料边界、时间安排和判断权优先于模块默认流程。
- 主干协议中的“必须自动”“默认并行”“连续执行”“强制派发”等表达，在拆分版中解释为：先提出建议、说明理由与风险，再等待研究者确认。
- 若研究者只需要诊断、梳理、比较方案或下一步建议，不主动推进后续阶段。

## 2. 外部动作确认

以下动作均需研究者明确同意后执行：

- Web、CNKI、Google Scholar、Zotero 或浏览器检索与抓取。
- 本地脚本、统计软件、命令行、批量转换或依赖安装。
- Word 导出、模板套用、文件批量改写或会改变项目状态的写入。
- 邀请顾问角色、并行复核、多阶段连续执行。

若研究者暂不确认，记录 `researcher-deferred`，并给出可手动执行的下一步。

## 3. 顾问与复核

- agent 顾问在拆分版中是“建议可邀请的审阅角色”，不是默认派发对象。
- 无真实并行 agent 时，可以按同一角色清单顺序复核；若研究者不希望复核，则只记录 `researcher-deferred`。
- 顾问意见不得替代研究者的选题判断、理论选择、方法选择或投稿决定。

## 4. 机制条款降级

机制层自动审计、会话停止检查、自动评分等条款在拆分版中不适用。需要质量判断时，优先呈现证据缺口、风险、可选修复路径和需要研究者决定的事项。

## 5. 输出偏好

- 优先呈现研究者可选择的路径，而不是替研究者自动推进。
- 明确区分已确认事实、工具实际执行结果、推断判断和待核验事项。
- 对每个建议给出“收益、风险、需要的材料、是否可暂缓”。
- 最终回复突出当前位置、下一步选项、证据缺口和需要研究者确认的动作。
