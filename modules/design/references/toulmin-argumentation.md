# Toulmin 论证框架

每个核心论证识别六个元素：主张（claim）、根据（data/grounds）、担保（warrant）、支撑（backing）、限定语（qualifier）和反驳（rebuttal）。

| 元素 | 必答问题 | 缺失风险 |
|---|---|---|
| 主张 | 本文到底断言什么？ | 论题漂移 |
| 根据 | 哪些材料支撑它？ | 无依据断言 |
| 担保 | 为什么这些材料足以支撑主张？ | 推理跳跃 |
| 支撑 | 担保依赖的理论/方法根据是什么？ | 隐含前提 |
| 限定语 | 主张在何种范围内成立？ | 过度声称 |
| 反驳 | 什么会削弱或否定它？ | 回避强异议 |

材料多不等于论证强。不能说清担保时，应回到概念、方法或反驳设计，而不是继续堆叠引文。
