# 大纲模板与范式微调规则

本文档提供四种论文类型的详细大纲模板，以及两种发表范式的微调规则。

---

## 一、实证研究论文大纲模板

```
一、引言
  1.1 研究背景与问题提出
  1.2 研究缺口
  1.3 研究问题
  1.4 研究贡献

二、文献综述与理论框架
  2.1 [文献脉络一]
  2.2 [文献脉络二]
  2.3 [争议与缺口]
  2.4 分析框架 / 理论机制
  2.5 研究假设（如适用）

三、研究方法与数据
  3.1 研究设计
  3.2 数据来源与样本
  3.3 变量定义与测量
  3.4 分析模型 / 估计策略

四、经验分析 / 研究发现
  4.1 描述性发现
  4.2 主检验结果
  4.3 [分维度/分群组分析]
  4.4 稳健性检验
  4.5 [机制检验 / 进一步分析]

五、理论对话
  5.1 回到文献脉络
  5.2 理论贡献

六、结论与讨论
  6.1 研究总结
  6.2 理论贡献回顾
  6.3 实践 / 政策启示
  6.4 研究局限
  6.5 未来研究展望
```

## 五、范式微调规则

### 社会学研究范式微调

| 原文位置 | 微调要点 |
|---------|---------|
| 引言 | 强调"知识脉络中的缺口"，而非现实问题 |
| 文献综述 | 独立成章，篇幅占 15-20%；必须有"交汇段落" |
| 理论对话 | 独立成章；必须明确"与谁对话、对话什么、对话后的贡献" |
| 结论风格 | "总结发现 → 回到知识脉络 → 讨论意义与局限" |

### 管理世界案例研究范式微调

| 原文位置 | 微调要点 |
|---------|---------|
| 引言 | 从"中国现实问题"或"实践悖论"切入 |
| 文献综述 | 与理论框架合并为一章；篇幅可压缩至 10-12% |
| 案例分析 | 标题改为"案例分析 / 研究发现"；强调机制建构 |
| 理论贡献 | 替代"理论对话"章节；侧重"从案例中建构的概念/机制/模型" |
| 结论 | 标题改为"结论与启示"；增加"政策含义"分量 |

### 通用学术范式（IMRaD）微调

| 原文位置 | 微调要点 |
|---------|---------|
| 引言 | 标准三段式：背景 → 缺口 → 本研究 |
| 文献综述 | 可融入引言或独立，视期刊而定 |
| 方法 | 强调可复现性：数据、变量、模型完整描述 |
| 结果 | 与讨论分离或合并，视期刊而定 |
| 讨论 | 可与结论合并为"Discussion and Conclusion" |

## 七、毕业论文五章结构完整模板

> 毕业论文（含本科、硕士、博士）采用五章结构。核心逻辑：展示独立研究能力，强调系统性、完整性和深度。每章独立成篇，共同构成"提出问题→理论界定→研究设计→实证分析→结论讨论"的完整闭环。

### 七-A 实证研究（毕业论文）

```
第一章 绪论
  1.1 研究背景
    - 宏观背景（政策/社会/学术背景）
    - 现实问题与学术缺口
  1.2 研究目的与意义
    1.2.1 理论意义
    1.2.2 实践意义
  1.3 研究问题与研究目标
    - 核心研究问题（2-3个）
    - 具体研究目标
  1.4 研究方法与技术路线
    1.4.1 研究方法概述
    1.4.2 技术路线图
  1.5 论文结构与创新点
    1.5.1 章节安排说明
    1.5.2 核心创新点（2-3个）

第二章 理论界定与文献综述
  2.1 核心概念界定
    - 关键术语的操作性定义
    - 与邻近概念的辨析
  2.2 理论基础
    - 本研究所依托的理论框架
    - 理论的适用性分析
  2.3 国内外研究现状
    2.3.1 [主题/流派一]（文献梳理 + 文献对比表）
    2.3.2 [主题/流派二]
    2.3.3 [主题/流派三]
  2.4 研究述评与本研究的切入点
    - 现有研究的不足与空白（视角/方法/场景三维）
    - 本研究的定位与贡献

第三章 研究方法与设计
  3.1 研究框架
    - 理论框架图/分析框架图（文字描述）
    - 研究假设（如适用）
  3.2 研究方法选择
    - 方法类型 + 选择理由（"为什么用这个方法"）
  3.3 研究对象与抽样
    - 研究对象描述
    - 抽样策略与样本量说明
  3.4 数据收集与处理
    - 数据来源与收集过程（含时间、地点、流程）
    - 数据分析方法（编码方案 / 统计模型）
    - 分析工具（SPSS/Stata/NVivo 等）
  3.5 研究伦理与信效度保障
    - 知情同意、匿名化处理
    - 信度/效度报告（量化：Cronbach's α、KMO）
    - 可信性/可转移性保障（质性）

第四章 研究发现与机制解释
  4.1 数据总体描述
    - 样本/案例基本特征描述
  4.2 核心发现一（对应研究问题一）
    - 数据呈现（图表/引用/叙述）
    - 结果分析与初步解释
  4.3 核心发现二（对应研究问题二）
    - 数据呈现
    - 结果分析与初步解释
  4.4 核心发现三（对应研究问题三）
    - 数据呈现
    - 结果分析与初步解释
  4.5 综合分析与机制解释
    - 跨维度/跨群组比较
    - 深层机制与逻辑链条
    - 替代解释的排除

第五章 结论与讨论
  5.1 研究结果的理论解释
    - 核心发现的凝练总结（3-5点）
    - 与前人研究的对话与对比
    - 理论贡献的阐明
  5.2 研究结果的实践意涵
    - 对政策/实践/行业的启示
    - 对策建议（如有）
  5.3 研究的局限性与反思
    - 方法论局限（样本、测量、设计）
    - 研究范围局限
    - 研究者立场反思（质性研究尤重）
  5.4 研究展望
    - 未来可拓展的研究方向
    - 研究的延伸应用可能
```

## 八、期刊论文定量研究专项模板

> 期刊论文追求精炼高效。定量实证研究的核心特征是：**文献综述的每个主题脉络末尾必须包含"分析框架与假设"子节**。这是期刊论文区别于毕业论文的关键结构特征。

### 八-A 实证研究（定量期刊）——经验分析与理论对话合并结构

```
一、引言
  1.1 研究背景与问题提出
  1.2 研究缺口
  1.3 研究问题
  1.4 研究贡献

二、文献综述与研究假设
  2.1 [主题脉络一]
    2.1.1 [子脉络梳理]
    2.1.2 分析框架与研究假设
      - 基于上述文献，梳理出 X → Y 的理论逻辑
      - H1：[假设一的具体陈述]
      - H2：[假设二的具体陈述]
  2.2 [主题脉络二]
    2.2.1 [子脉络梳理]
    2.2.2 分析框架与研究假设
      - H3：[假设三的具体陈述]
  2.3 [主题脉络三]
    2.3.1 [子脉络梳理]
    2.3.2 分析框架与研究假设
      - H4：[假设四的具体陈述]
  2.4 整体分析框架
    - [框架图的文字描述，整合所有假设]

三、数据与方法
  3.1 数据来源与样本
  3.2 变量定义与测量
  3.3 分析模型 / 估计策略

四、经验分析与理论对话
  ⚠️ 核心结构：每个分析子节内部采用"发现呈现 → 理论对话 → 贡献提炼"的三段节奏
  4.1 描述性统计与初步发现
    4.1.1 数据总体描述
    4.1.2 初步发现的理论含义
  4.2 主检验结果与理论对话
    4.2.1 假设检验结果呈现
    4.2.2 与[脉络一]的理论对话
    4.2.3 与[脉络二]的理论对话
  4.3 [分维度/分群组分析]与理论对话
    4.3.1 [维度一]结果呈现
    4.3.2 理论对话与贡献提炼
  4.4 稳健性检验
  4.5 综合讨论
    - 跨维度理论贡献
    - 回到引言的研究缺口
    - 替代解释的排除

五、结论
  5.1 研究总结
  5.2 理论贡献回顾
  5.3 实践/政策启示
  5.4 研究局限与展望
```

## 九、毕业论文字数分配指南

> 毕业论文以五章为单位分配字数。以下为各学历层次和各章的建议字数范围。

| 章节 | 本科（1-1.5万字） | 硕士（2-3万字） | 硕士深度（3-5万字） | 博士（8万字以上） |
|------|-----------------|---------------|-----------------|----------------|
| 第一章 绪论 | 1500-2000 | 3000-5000 | 5000-7000 | 8000-12000 |
| 第二章 理论界定与文献综述 | 2000-3000 | 5000-7000 | 7000-10000 | 15000-20000 |
| 第三章 研究方法与设计 | 1500-2000 | 3000-5000 | 5000-7000 | 8000-12000 |
| 第四章 研究发现与机制解释 | 4000-5000 | 8000-10000 | 12000-18000 | 25000-35000 |
| 第五章 结论与讨论 | 1000-1500 | 2000-3500 | 3500-5000 | 8000-10000 |

**字数分配原则**：
- 第四章（研究发现）应占全文的 **30-40%**，是绝对核心
- 第二章（文献综述）应占全文的 **15-20%**
- 第一章和第五章合计占全文的 **15-20%**
- 第三章占全文的 **10-15%**

### 期刊论文字数分配指南（对照）

| 章节 | 1万字以下 | 1.2-1.8万字 | 1.8-2.5万字 |
|------|----------|------------|------------|
| 引言 | 1000-1500 | 1500-2500 | 2500-3500 |
| 文献综述与研究假设 | 2000-2500 | 2500-4000 | 4000-5500 |
| 研究方法与数据 | 800-1200 | 1200-2000 | 2000-3000 |
| 经验分析/研究发现 | 3500-4500 | 4500-7000 | 7000-10000 |
| 理论对话 | 1000-1500 | 1500-2500 | 2500-3500 |
| 结论与讨论 | 800-1200 | 1200-2000 | 2000-3000 |

## 十、毕业论文与期刊论文的核心差异速查

| 维度 | 毕业论文 | 期刊论文 |
|------|---------|----------|
| **核心目标** | 展示独立研究能力 | 发表创新性成果 |
| **文献综述** | 全面系统，独立成章，三维分类（主题/流派/方法），含文献对比表 | 聚焦前沿，与理论框架合并，每部分末尾出假设 |
| **概念界定** | 独立子节，详尽的术语操作化 | 融入文献综述或引言 |
| **方法章节** | 独立成章，含选择理由、研究伦理、信效度报告 | 精简到可复现即可 |
| **发现分析** | 多维度分层次展开，每发现对应研究问题 | 聚焦核心发现，**与理论对话同章合并**，边呈现边对话 |
| **理论对话** | 多元展开（理论解释+实践意涵+局限性+反思），独立成章 | **与经验分析合并为同一章**，每个发现呈现后立即对话，禁止先堆砌再单独对话 |
| **结论** | 独立成章，含局限与展望 | 可并入讨论，简洁扼要 |
| **学历差异** | 本科（描述+对策）、硕士（理论应用+方法创新）、博士（理论/方法/应用创新） | 统一要求创新性 |

## 十一、毕业论文写作顺序建议

> 推荐写作顺序（按此顺序可避免反复返工）：
> 
> **第一章 绪论 → 第二章 文献综述 → 第三章 研究方法 → 第四章 研究发现 → 第五章 结论 → 摘要 → 关键词 → 目录 → 参考文献 → 致谢 → 附录**
>
> 理由：核心章节需基于完整的研究过程撰写；摘要是全文的凝练，应在正文完成后撰写；目录应在全文定稿后自动生成。

## 十二、双轨要素标准

以下标准根据论文目的分为**毕业论文轨**和**期刊论文轨**。两条轨道共享核心要素，但在展开深度和章节独立程度上有所不同。

### 12.1 毕业论文轨（五章结构 + 完整展开）

| # | 要素 | 对应章节 | 章节级别 | 素材映射要求 | 质量标准 |
|---|------|---------|---------|-------------|---------|
| 1 | **标题 + 摘要 + 关键词** | 封面/摘要页 | 暂拟（终稿前修订） | 标题需从素材核心主张中提炼 | 标题 ≤ 25 字；摘要 300 字（本科）/ 500 字（硕士）/ 800 字（博士），含"问题→方法→发现→结论"闭环 |
| 2 | **现状与问题（绪论）** | 第一章 | 四级标题（背景→意义→问题→方法→结构→创新点） | ≥ 5 份素材支撑研究背景和缺口 | 含研究背景、目的意义、研究问题、研究方法概述、技术路线图、论文结构与创新点 |
| 3 | **理论界定与文献综述** | 第二章 | 四级标题（概念界定→理论基础→国内外现状[按主题分类]→述评与切入点） | ≥ 15 条文献支撑，按主题/流派/方法三维分类 | 独立成章；每篇文献含"内容+优缺点+与本文关联"；含文献对比表或思维导图；含批判性述评 |
| 4 | **研究方法与设计** | 第三章 | 四级标题（研究框架→方法选择→对象与抽样→数据收集→伦理与信效度） | 素材中有数据来源或案例完整描述 | 独立成章；方法选择须说明"为什么"；含信度/效度报告；质性研究须含研究者立场反思 |
| 5 | **研究发现与机制解释** | 第四章 | 四级标题（总体描述→发现一→发现二→发现三→综合讨论） | 每个分节 ≥ 3 条素材支撑；含图表/引用/叙述 | 核心章节，占全文 30-40%；每个发现对应一个研究问题；含跨维度比较和深层机制分析 |
| 6 | **讨论** | 第五章 | 三级标题（理论解释→实践意涵→局限性→反思） | 与文献综述章节形成呼应 | 与前人研究对话对比；阐明理论贡献；不引入新内容 |
| 7 | **结论与展望** | 第六章 | 二级标题（总结→贡献→展望） | 与绪论、文献综述、讨论形成闭环 | 核心结论 3-5 点凝练提炼；创新贡献明确；未来方向具体 |

### 12.2 期刊论文轨（五要素紧凑结构，经验分析与理论对话合并）

| # | 要素 | 章节级别 | 素材映射要求 | 质量标准 |
|---|------|---------|-------------|---------|
| 1 | **标题 + 摘要 + 关键词** | 暂拟（终稿前修订） | 标题需从素材核心主张中提炼 | 标题 ≤ 25 字，摘要 300-500 字框架 |
| 2 | **引言** | 三级标题（问题提出→研究缺口→研究问题→贡献陈述） | 素材中 ≥ 3 个引文支撑"研究缺口" | 含转折词、缺口和贡献陈述 |
| 3 | **文献综述与研究假设** | 三级标题（脉络→争议→框架→假设/RQ） | 素材中 ≥ 10 条文献支撑，按流派归类 | 含分析框架和交汇段落；**定量文章的每个脉络末尾必须有"分析框架与研究假设"子节** |
| 4 | **数据与方法** | 三级标题（数据→变量→方法） | 素材中有数据来源或案例描述 | 精简到可复现即可；不过度展开 |
| 5 | **经验分析与理论对话（合并）** | 四级标题（每个子分析含：发现→对话→贡献） | 每个分节 ≥ 3 条素材支撑（含数据+理论） | **核心要求**：每个经验发现呈现后立即进行理论对话，边呈现边对话，防止叙事冗余。回到引言脉络，有理论贡献 |
| 6 | **结论** | 二级标题（总结→贡献→延展→限制→展望） | 与引言、文献综述、经验分析形成闭环 | 不重复前文；覆盖总结、延展、限制、展望 |

> ⚠️ **期刊论文的核心结构特征**：经验分析与理论对话必须合并为同一章节。每个分析子节内部采用"发现呈现 → 理论对话 → 贡献提炼"的三段节奏，而不是先堆砌所有发现再单独对话。这既是期刊论文篇幅限制的要求，也是防止叙事冗余的最佳实践。

### 12.3 定量期刊论文的特殊要求

定量实证研究的期刊论文，**文献综述的每个主题脉络末尾**必须包含以下结构：

```markdown
### X.X [脉络名称]
[文献梳理与评述...]

### X.X 分析框架与研究假设
基于上述文献梳理，本文提出以下分析框架：
- **框架描述**：[理论逻辑的文字描述，含框架图]
- **核心变量关系**：A → B → C 的逻辑链条
- **研究假设**：
  - H1：[假设一，基于[理论/前人发现]]
  - H2：[假设二，基于[理论/前人发现]]
  - H3：[假设三，基于[理论/前人发现]]
```

> 这条要求是定量期刊论文与毕业论文在文献综述章节的核心分水岭。毕业论文可以将假设推导放在研究方法章节中，但定量期刊论文必须在文献综述的每个脉络末尾完成假设推导。
