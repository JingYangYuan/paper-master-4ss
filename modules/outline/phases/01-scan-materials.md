# Phase 1：素材扫描与分类

本阶段扫描用户指定输入路径、总控输入登记表或当前目录候选材料，提取核心内容并映射至论文七要素与双轨章节结构。

## 顾问派发门控

素材扫描完成后，须派发 `modules/outline/agents/evidence-map-consultant.md` 与 `modules/outline/agents/structure-consultant.md`（无并行能力时按序复核并记录 `sequential-review`），复核素材功能归类与学位论文/期刊论文结构选型。意见与综合结论写入 `paper-workspace/_logs/agents/outline-[YYYY-MM-DD]/agent-synthesis-outline-[YYYY-MM-DD].md` 后进入 Phase 2。

## 执行步骤

### Step 1：全量文件扫描

```bash
find "$INPUT_PATH" -type f \( -name "*.md" -o -name "*.txt" -o -name "*.csv" \) | sort
```

记录文件路径、大小与修改时间。若输入包含 `paper-workspace/02-literature/`：先读取 `paper-registry.csv` 建立题录索引（`paper_id`、`citation_key`、全文路径、核读状态），再读取 `review-evidence.csv`（`claim_id`、`paper_id`、`evidence_level`）；逐篇全文通过 `fulltext/<paper_id>/document.md` 按需定位读取，不一次性全量载入。

### Step 2：分批读取

按文件体积从小到大以每批 3–5 个文件读取：
- ≤ 5 KB：全文读取；
- 5–50 KB：读取前 200 行并检索关键词；
- > 50 KB：读取前 100 行并检索二级/三级标题（`##`、`###`）。

### Step 3：章节功能归类

对每份素材记录：文件路径、核心主题（≤ 20 字）、类型（文献/数据/方法）、期刊对应章节、毕业论文对应章节、关键引文或数据点及置信度（高/中/低）。

| 素材特征 | 期刊论文对应章节 | 毕业论文对应章节 |
|---|---|---|
| 研究意义、现实背景、政策或社会关切 | 引言 | 第一章 绪论 |
| 核心概念界定、术语辨析 | 文献综述（融入） | 第二章 理论界定与文献综述（独立子节） |
| 已有理论、前人发现归纳、框架比较 | 文献综述 | 第二章 理论界定与文献综述 |
| 研究不足、空白梳理与述评 | 文献综述（结尾） | 第二章（独立子节） |
| 数据来源、变量定义、模型设定、案例设计 | 研究方法 | 第三章 研究方法与设计 |
| 抽样策略、信效度、研究伦理 | 研究方法（精简） | 第三章（完整展开） |
| 统计分析、案例证据、图表与回归结果 | 经验分析 | 第四章 研究发现与机制解释 |
| 深层机制分析、跨维度比较 | 经验分析与理论对话 | 第四章（综合分析与机制解释） |
| 理论含义讨论、文献对话、贡献提炼 | 理论对话（合并入经验章） | 第五章 结论与讨论 |
| 发现总结、实践启示、局限与展望 | 结论与讨论 | 第五章 结论与讨论 |

### Step 4：输出分类汇总表

按引言、文献综述、研究方法、经验分析、理论对话、结论、跨章节素材与未归类素材八类汇总文件清单及置信度。

### Step 5：素材充分度初步评估

**期刊论文参考标准**：
- 引言：≥ 3 份高置信度素材为充足；
- 文献综述：≥ 8 份高置信度素材为充足（定量研究每条脉络须有 ≥ 2 份支撑假设推导）；
- 研究方法：≥ 1 份完整方法/数据描述为充足；
- 经验分析：≥ 3 份实质内容为充足；
- 理论对话：≥ 5 份理论文献为充足；
- 结论：依赖以上各节。

**毕业论文参考标准**：
- 第一章 绪论：≥ 5 份支撑研究背景与缺口；
- 第二章 理论界定与文献综述：≥ 15 份，覆盖概念界定、理论基础、国内外现状与述评；
- 第三章 研究方法与设计：≥ 3 份，含方法论文献与数据/材料说明；
- 第四章 研究发现与机制解释：≥ 5 份实质内容，含数据报告或案例材料；
- 第五章 结论与讨论：依赖前四章并有 ≥ 3 份理论文献支撑讨论。

## 阶段输出

- 素材分类汇总表；
- 各章节素材充分度初步评估；
- 初步识别的材料与结构缺口（供 Phase 2 使用）。
