# Phase 1: 素材扫描与分类

## 目标

扫描用户指定输入路径、master 输入登记表或当前目录候选材料中的文本素材，读取每份素材的核心内容，将其映射到论文七要素的对应章节。

## 顾问派发闸门

素材扫描完成后，必须并行派发 `modules/outline/agents/material-classification-consultant.md` 与 `modules/outline/agents/structure-consultant.md`，复核素材功能归类和毕业论文/期刊论文结构选择。意见写入 `paper-workspace/_logs/agents/outline-[YYYY-MM-DD]/`，并生成或更新 `agent-synthesis-outline-[YYYY-MM-DD].md` 后再进入 Phase 2。

## 执行步骤

### Step 1: 全量扫描

```bash
find "$INPUT_PATH" -type f \( -name "*.md" -o -name "*.txt" -o -name "*.csv" \) | sort
```

记录所有发现文件的路径、大小和修改时间。

**若输入包含 `02-literature/`**：先读 `paper-registry.csv` 建立题录索引（paper_id、citation_key、全文路径、核读状态），再读 `review-evidence.csv` 的 claim_id/paper_id/evidence_level；逐篇全文按 `fulltext/<paper_id>/document.md` 定位，按需读取，不全文载入。

### Step 2: 分批读取

按文件大小从小到大分批读取。每批 3-5 个文件。

**读取策略**：
- ≤ 5KB 的文件：全文读取
- 5-50KB 的文件：读取开头 200 行 + 搜索关键词
- > 50KB 的文件：只读取前 100 行 + 搜索章节标题（##、###）

### Step 3: 内容分类

对每份素材，提取以下信息并归类：

```markdown
| 文件路径 | 核心主题(≤20字) | 文献/数据/方法 | 期刊对应章节 | 毕业论文对应章节 | 关键引文/数据点 | 置信度 |
|---------|----------------|--------------|------------|----------------|----------------|--------|
```

**章节分类规则**：

| 素材特征 | 期刊论文归入章节 | 毕业论文归入章节 |
|---------|----------------|----------------|
| 讨论研究意义、问题背景、政策/社会关切 | 引言 | 第一章 绪论 |
| 界定核心概念、辨析术语 | 文献综述（融入） | 第二章 理论界定与文献综述（独立子节） |
| 综述已有理论、归纳前人发现、比较框架 | 文献综述 | 第二章 理论界定与文献综述 |
| 前人研究不足与空白、述评 | 文献综述（结尾） | 第二章（独立子节） |
| 描述数据来源、变量定义、模型设定、案例设计 | 研究方法 | 第三章 研究方法与设计 |
| 描述抽样策略、信效度、研究伦理 | 研究方法（精简） | 第三章（完整展开） |
| 呈现统计分析、案例证据、图表、回归结果 | 经验分析 | 第四章 研究发现与机制解释 |
| 深层机制分析、跨维度比较 | 经验分析/理论对话 | 第四章（综合分析与机制解释） |
| 讨论理论含义、对话文献、提炼贡献 | 理论对话 | 第五章 结论与讨论 |
| 总结发现、讨论启示、局限、展望 | 结论与讨论 | 第五章 结论与讨论 |

**置信度标注**：
- **高**：素材内容与章节高度匹配，可直接支撑
- **中**：素材内容部分相关，需要结合其他素材
- **低**：素材内容仅边缘相关，仅作参考

### Step 4: 分类汇总

输出分类汇总表：

```markdown
## 素材分类汇总

### 引言相关（N 份）
- /path/to/xxx.md：讨论了 xxx（置信度：高）

### 文献综述相关（N 份）
- ...

### 研究方法相关（N 份）
- ...

### 经验分析相关（N 份）
- ...

### 理论对话相关（N 份）
- ...

### 结论相关（N 份）
- ...

### 跨章节素材（N 份）
- ...

### 未归类素材（N 份）
- ...
```

### Step 5: 素材充分度初步评估

**期刊论文评估标准**：

| 章节 | 素材数量 | 充分度 | 判断依据 |
|------|---------|--------|---------|
| 引言 | N | 充足/一般/不足 | ≥3份高置信度=充足 |
| 文献综述 | N | 充足/一般/不足 | ≥8份高置信度=充足（定量文章额外检查：每脉络≥2份支撑假设推导） |
| 研究方法 | N | 充足/一般/不足 | ≥1份详细描述=充足 |
| 经验分析 | N | 充足/一般/不足 | ≥3份实质内容=充足 |
| 理论对话 | N | 充足/一般/不足 | ≥5份理论文献=充足 |
| 结论 | N | 充足/一般/不足 | 依赖以上各节 |

**毕业论文评估标准**：

| 章节 | 素材数量 | 充分度 | 判断依据 |
|------|---------|--------|---------|
| 第一章 绪论 | N | 充足/一般/不足 | ≥5份支撑研究背景和缺口 |
| 第二章 理论界定与文献综述 | N | 充足/一般/不足 | ≥15份支撑，覆盖概念界定+理论基础+国内外现状+述评 |
| 第三章 研究方法与设计 | N | 充足/一般/不足 | ≥3份支撑，含方法论文献+数据来源描述 |
| 第四章 研究发现与机制解释 | N | 充足/一般/不足 | ≥5份实质内容，含数据报告+案例材料 |
| 第五章 结论与讨论 | N | 充足/一般/不足 | 依赖以上各节 + ≥3份理论文献支撑讨论 |

## 输出

- 完整的素材分类汇总表
- 素材充分度初步评估
- 识别到的结构与缺口（作为 Phase 2 的输入）
