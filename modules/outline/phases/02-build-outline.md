# Phase 2: 大纲构建

## 目标

基于 Phase 1 的分类结果和用户在 SKILL.md 第一层中的选择，构建完整的论文大纲。

本 phase 的大纲、段落级写作蓝图、证据映射和缺口报告必须遵守 `master/output-protocol.md`。章节递进、证据流和缺口回流路径必须包含 Mermaid 图示，例如：

```mermaid
flowchart LR
  M[素材分类] --> T[核心主张]
  T --> S[一级结构]
  S --> E[证据映射]
  E --> G[缺口报告]
  G -.回流.-> M
```

图后用 2-4 条中文解释说明章节逻辑、证据来源、缺口位置和回流建议。

## 顾问派发闸门

大纲初稿和段落级写作蓝图形成后，必须并行派发 `modules/outline/agents/chapter-logic-consultant.md` 与 `modules/outline/agents/evidence-map-consultant.md`，复核章节递进、计划段落功能和证据映射充分度。主流程必须把采纳和未采纳建议写入 `agent-synthesis-outline-[YYYY-MM-DD].md`，再生成最终大纲、段落蓝图、证据映射和缺口报告。

## 前置条件

- Phase 1 的素材分类汇总已完成
- 用户已确认**论文目的**（毕业论文/期刊论文）、论文类型、目标范式和预期字数
- 已加载 `modules/outline/references/outline-patterns.md` 中对应的结构模板（毕业论文 → §七，期刊论文 → §八）

## 执行步骤

### Step 1: 提取核心主张

从素材中提炼论文的核心论点（thesis statement）。

**提炼方法**：
- 扫描所有素材的研究问题、核心发现和理论贡献
- 寻找不同素材之间的共同指向
- 形成一句话核心主张（≤50 字）

```markdown
**核心主张**：[一句话]
**素材依据**：
  - /path/to/xxx.md L45-60：[支撑该主张的关键证据]
  - /path/to/yyy.md 摘要：[支撑该主张的关键证据]
```

### Step 2: 确定一级结构

根据论文目的和类型，加载对应模板：

#### 毕业论文一级结构（五章）

| 类型 | 一级结构 | 模板来源 |
|------|---------|---------|
| 实证研究 | 第一章 绪论 → 第二章 理论界定与文献综述 → 第三章 研究方法与设计 → 第四章 研究发现与机制解释 → 第五章 结论与讨论 | `modules/outline/references/outline-patterns.md` §七-A |
| 阐释研究 | 第一章 绪论 → 第二章 理论界定与文献综述 → 第三章 研究设计与案例选择 → 第四章 案例叙述与机制解释 → 第五章 结论与讨论 | `modules/outline/references/outline-patterns.md` §七-B |
| 规范研究 | 第一章 绪论 → 第二章 概念界定与理论资源 → 第三章 规范标准的确立 → 第四章 争议反驳与制度含义 → 第五章 结论与讨论 | `modules/outline/references/outline-patterns.md` §七-C |
| 文献综述 | 第一章 绪论 → 第二章 综述范围与方法 → 第三章 领域演进与理论版图 → 第四章 争议发现与空白汇总 → 第五章 结论与展望 | `modules/outline/references/outline-patterns.md` §七-D |

#### 期刊论文一级结构（五要素紧凑结构，经验分析与理论对话合并）

| 类型 | 一级结构 |
|------|---------|
| 实证研究 | 引言 → 文献综述与研究假设 → 数据与方法 → **经验分析与理论对话**（合并） → 结论 |
| 阐释研究 | 现象 → 困惑 → 概念工具 → 材料来源 → **案例叙述与机制解释**（合并） → 结论 |
| 规范研究 | 问题提出 → 概念界定 → 理论资源 → 规范标准 → 争议反驳 → 制度含义 → 结论 |
| 文献综述 | 引言 → 范围方法 → 领域演进 → 理论版图 → 争议发现 → 空白汇总 → 结论展望 |

> ⚠️ **定量期刊论文特殊要求**：文献综述的每个主题脉络末尾，必须生成"分析框架与研究假设"子节（见 `modules/outline/references/outline-patterns.md` §八-A）。
>
> ⚠️ **经验分析与理论对话合并**：期刊论文中，经验分析与理论对话必须为同一章节。每个分析子节内部采用"发现呈现 → 理论对话 → 贡献提炼"的三段节奏，禁止先堆砌所有发现再单独开一章对话。这是防止叙事冗余的核心约束。

根据用户选择的目标范式和预期字数进行结构调整（详见 `modules/outline/references/outline-patterns.md` §五 范式微调规则）。

### Step 3: 生成二级标题

每个一级结构下生成 2-5 个二级标题。

**生成规则**：
- 每个二级标题必须有至少 1 份高置信度素材支撑
- 二级标题之间必须有逻辑递进关系（不是并列罗列）
- 标题采用陈述句，不使用"以……为例"等套路化表达
- 禁止在标题中嵌入完整论文标题

**二级标题生成检查**：
```markdown
| 二级标题 | 逻辑角色 | 支撑素材数 | 与前节的递进关系 |
|---------|---------|-----------|----------------|
| 2.1 xxx | 铺陈背景 | 2 | — |
| 2.2 xxx | 指出缺口 | 3 | 从背景转向缺口 |
| 2.3 xxx | 提出RQ | 1 | 从缺口中凝练问题 |
```

### Step 4: 细化下级标题

在素材支撑充分的二级标题下，生成下级标题。

**毕业论文：细化到四级标题**
- 二级标题下的素材 ≥ 5 份 → 生成 2-4 个三级标题，每个三级标题下再生成 1-2 个四级标题
- 二级标题下的素材 2-4 份 → 生成 1-2 个三级标题，标注"待补充"
- 二级标题下素材 < 2 份 → 不生成三级标题，直接标注"待补充"

**期刊论文：细化到三级标题**
- 二级标题下的素材 ≥ 3 份 → 至少生成 2 个三级标题
- 二级标题下的素材 1-2 份 → 生成 1 个三级标题，标注"待补充"
- 二级标题下无素材 → 不生成三级标题，直接标注"待补充"

**标题要求**：
- 每个下级标题对应一个具体的论证步骤
- 标注所需素材的具体段落/行号
- 标注素材之外是否需要补充论证
- 毕业论文标题编号使用"第X章 > X.X > X.X.X > X.X.X.X"格式

### Step 5: 生成段落级写作蓝图

在每个最低层级标题下生成若干计划段落，作为 `write` 模块的直接输入。最低层级指：毕业论文四级标题；期刊论文三级标题；若某处因素材不足未生成到目标层级，则使用当前最末级标题并标注缺口。

每个计划段落必须包含以下固定字段：

| 字段 | 要求 |
|---|---|
| 段落编号 | 使用稳定编号，如 `P-3.2.1-01` 或 `P-4.2.1.1-02` |
| 段落大意 | 1-2 句说明该段写什么，必须能直接指导正文写作 |
| 论证功能 | 背景铺垫 / 概念界定 / 文献述评 / 假设推导 / 方法说明 / 发现呈现 / 理论对话 / 结论提炼等 |
| 中心判断 | 该段要成立的判断，不能只是"介绍某某" |
| 使用材料 | 文件路径 + 行号/段落；文献类材料附 `review-evidence.csv` 的 claim_id 与 paper_id；无材料时写"无" |
| 预期证据 | 文献观点、数据结果、访谈摘录、案例事实、方法依据或表图占位 |
| 衔接关系 | 说明承接上一段和引出下一段的逻辑 |
| 不可声称内容 | 明确不得写入正文的结论、因果、数据或文献声称 |

无素材支撑的计划段落必须标注 `暂不写入正文`，并说明需要补充何种材料；不得把无素材段落派发给 write 模块生成正文。

```markdown
### [最低层级编号] [标题]

| 段落编号 | 段落大意 | 论证功能 | 中心判断 | 使用材料 | 预期证据 | 衔接关系 | 不可声称内容 | 写作状态 |
|---|---|---|---|---|---|---|---|---|
| P-3.1-01 | [1-2句] | [功能] | [判断] | `/path/file.md` §2 | [证据] | [承上启下] | [禁写] | 可写 |
| P-3.1-02 | [1-2句] | [功能] | [判断] | 无 | [缺口] | [承上启下] | [禁写] | 暂不写入正文 |
```

### Step 6: 证据映射

为每个计划段落建立证据映射条目。

**毕业论文**：证据映射覆盖到四级标题下的计划段落。额外的证据要求：
- 每个概念界定需 ≥ 2 条教材/经典文献支撑
- 每个研究方法选择理由需 ≥ 1 条方法论文献支撑
- 每个机制解释需 ≥ 2 条理论文献支撑

**期刊论文**：证据映射覆盖到三级标题下的计划段落。

```markdown
### [段落编号] [所属标题]

- **核心主张**（≤30字）：[该节要论证的观点]
- **论证逻辑**（≤50字）：[如何从素材走向该主张]
- **素材支撑**：
  - ✅ `/path/to/xxx.md` §2.3：[具体支撑内容，20字] — 置信度：高
  - ✅ `/path/to/yyy.md` L120-180：[具体支撑内容] — 置信度：中
  - 文献类素材须附证据表回查键：`claim_id=<id>、paper_id=<id>`（对应 `02-literature/review-evidence.csv`）
- **素材充分度**：充足（期刊≥3份/毕业论文≥5份）/ 一般（期刊2份/毕业论文2-4份）/ 不足（1份）/ 空
- **补充方向**（如不足）：需要 [描述] 类型的文献或数据
```

### Step 7: 识别结构缺口

遍历所有计划段落的证据映射，汇总素材不足的章节和段落：

```markdown
## 结构缺口

### 严重缺口（章节完全无素材）
- [章节路径]：[影响描述]

### 段落缺口（计划段落不可写）
- [段落编号]：[所属标题]：缺少 [具体材料/分析/理论对话]，写作状态为"暂不写入正文"

### 中等缺口（素材不足，论证可能不充分）
- [章节路径]：现有素材仅覆盖 [X%]，缺少 [具体内容]

### 轻微缺口（素材充分但质量或时效可改善）
- [章节路径]：[具体问题]
```

### Step 8: 生成最终大纲文件

将以上所有内容按 `modules/outline/references/output-formats.md` 定义的标准格式，生成四类输出文件：

1. `paper-workspace/03-outline/outline-[slug]-[YYYY-MM-DD].md` — 完整论文大纲（期刊论文用格式一，毕业论文用格式二）
2. `paper-workspace/03-outline/paragraph-blueprint-[slug]-[YYYY-MM-DD].md` — 段落级写作蓝图（格式三）
3. `paper-workspace/03-outline/evidence-map-[slug]-[YYYY-MM-DD].md` — 段落级证据映射表（格式四）
4. `paper-workspace/03-outline/gap-report-[slug]-[YYYY-MM-DD].md` — 缺口报告（格式五）
