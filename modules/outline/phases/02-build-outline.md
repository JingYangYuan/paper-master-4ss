# Phase 2：大纲构建

本阶段基于 Phase 1 分类结果与用户确认的论文目的、类型、发表范式及篇幅要求，构建论文大纲、段落级写作蓝图、证据映射与缺口报告。输出须遵守 `master/output-protocol.md`，在文中以 Mermaid 图呈现章节递进、证据流与缺口退回路径并附 2–4 条中文解释：

```mermaid
flowchart LR
  M[素材分类] --> T[核心主张]
  T --> S[一级结构]
  S --> E[证据映射]
  E --> G[缺口报告]
  G -.退回.-> M
```

## 顾问派发门控

大纲初稿与段落级写作蓝图形成后，须派发 `modules/outline/agents/gap-review-consultant.md` 与 `modules/outline/agents/evidence-map-consultant.md`（无并行能力时按序复核并记录 `sequential-review`），复核章节递进、计划段落功能与证据映射充分度，并将采纳与未采纳建议写入 `agent-synthesis-outline-[YYYY-MM-DD].md` 后定稿输出文件。

## 前置条件

- Phase 1 素材分类汇总已完成；
- 已确认论文目的（毕业论文/期刊论文）、论文类型、目标范式与预期字数；
- 已加载 `modules/outline/references/outline-patterns.md` 对应模板（毕业论文见 §七，期刊论文见 §八）。

## 执行步骤

### Step 1：提炼核心主张

从素材中提炼一句话核心主张（≤ 50 字），并列明支撑该主张的素材文件路径与位置。

### Step 2：确定一级结构

**毕业论文（五章结构，模板见 `outline-patterns.md` §七）**：
- 实证研究：绪论 -> 理论界定与文献综述 -> 研究方法与设计 -> 研究发现与机制解释 -> 结论与讨论（§七-A）；
- 阐释研究：绪论 -> 理论界定与文献综述 -> 研究设计与案例选择 -> 案例叙述与机制解释 -> 结论与讨论（§七-B）；
- 规范研究：绪论 -> 概念界定与理论资源 -> 规范标准的确立 -> 争议反驳与制度含义 -> 结论与讨论（§七-C）；
- 文献综述：绪论 -> 综述范围与方法 -> 领域演进与理论版图 -> 争议发现与空白汇总 -> 结论与展望（§七-D）。

**期刊论文（五要素紧凑结构，模板见 `outline-patterns.md` §八）**：
- 实证研究：引言 -> 文献综述与研究假设 -> 数据与方法 -> 经验分析与理论对话（合并） -> 结论；
- 阐释研究：现象 -> 困惑 -> 概念工具 -> 材料来源 -> 案例叙述与机制解释（合并） -> 结论；
- 规范研究：问题提出 -> 概念界定 -> 理论资源 -> 规范标准 -> 争议反驳 -> 制度含义 -> 结论；
- 文献综述：引言 -> 范围方法 -> 领域演进 -> 理论版图 -> 争议发现 -> 空白汇总 -> 结论展望。

期刊论文特殊约束：
1. 定量期刊论文文献综述的每条主题脉络末尾须包含「分析框架与研究假设」子节（§八-A）；
2. 期刊论文的经验分析与理论对话须合并为同一章节，各子节采用「发现呈现 -> 理论对话 -> 贡献提炼」节奏；
3. 依据 `outline-patterns.md` §五完成目标发表范式微调。

### Step 3：生成二级标题

每个一级章下设 2–5 个二级标题：每节须有 ≥ 1 份高置信度素材支撑，各节之间形成逻辑递进（非平行罗列），标题采用陈述句且不嵌入完整论文题名。

### Step 4：细化下级标题

- **毕业论文（细化至四级标题）**：素材 ≥ 5 份生成 2–4 个三级标题（每三级下设 1–2 个四级标题）；2–4 份生成 1–2 个三级标题并标「待补充」；< 2 份直接标「待补充」。编号采用 `第X章 > X.X > X.X.X > X.X.X.X`。
- **期刊论文（细化至三级标题）**：素材 ≥ 3 份生成 ≥ 2 个三级标题；1–2 份生成 1 个三级标题并标「待补充」；无素材直接标「待补充」。

### Step 5：生成段落级写作蓝图

在每个最末级标题下生成计划段落，作为 `write` 模块的直接输入。每个段落固定包含九字段：
- `段落编号`（如 `P-3.2.1-01`）
- `段落大意`（1–2 句具体内容指导）
- `论证功能`（背景铺垫/概念界定/文献述评/假设推导/方法说明/发现呈现/理论对话/结论提炼）
- `中心判断`（明确可论证判断，而非「介绍某某」）
- `使用材料`（文件路径与行号/段落；文献类须附 `review-evidence.csv` 的 `claim_id` 与 `paper_id`；无材料写「无」）
- `预期证据`
- `衔接关系`（承上启下逻辑）
- `不可声称内容`
- `写作状态`（`可写` / `暂不写入正文`）

无材料支撑的计划段落须标为 `暂不写入正文` 并注明需补充的材料方向，严禁派发给 `write` 成稿。

### Step 6：段落级证据映射

为每个计划段落建立证据映射：核心主张（≤ 30 字）、论证逻辑（≤ 50 字）、素材支撑（含路径、位置、置信度及 `claim_id`/`paper_id`）、素材充分度（充足/一般/不足/空）及补充方向。毕业论文额外核查：概念界定 ≥ 2 条经典/教材文献、方法选择 ≥ 1 条方法论文献、机制解释 ≥ 2 条理论文献。

### Step 7：汇总结构与材料缺口

按四级严重度分类汇总缺口：严重缺口（整章无素材）、段落缺口（`暂不写入正文` 段落）、中等缺口（素材覆盖不足）与轻微缺口（时效或质量可提升）。

### Step 8：输出四份交付文件

按 `modules/outline/references/output-formats.md` 写入：
1. `paper-workspace/03-outline/outline-[slug]-[YYYY-MM-DD].md`（期刊用格式一，毕业论文用格式二）
2. `paper-workspace/03-outline/paragraph-blueprint-[slug]-[YYYY-MM-DD].md`（格式三）
3. `paper-workspace/03-outline/evidence-map-[slug]-[YYYY-MM-DD].md`（格式四）
4. `paper-workspace/03-outline/gap-report-[slug]-[YYYY-MM-DD].md`（格式五）
