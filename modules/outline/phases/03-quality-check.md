# Phase 3: 质量检查

## 目标

对生成的大纲进行系统性质量检查，确保达到可交付标准。

## 顾问派发闸门

交付前必须派发 `modules/outline/agents/gap-review-consultant.md`，复核章节缺口、材料缺口、论证缺口和写作风险。未解决风险必须写入 `agent-synthesis-outline-[YYYY-MM-DD].md` 和 `gap-report-[slug]-[YYYY-MM-DD].md`，并同步到 `paper-workspace/_index/handoff-status.md`。

## 前置条件

- Phase 2 的大纲、段落级写作蓝图、证据映射和缺口报告已生成
- 已知论文目的（毕业论文/期刊论文）、论文类型、目标范式

## 检查清单

### 第一轮：结构完整性

**所有论文通用**：
- [ ] 七要素或五章齐全
- [ ] 一级结构符合论文类型模板
- [ ] 各章节权重合理（经验分析/研究发现占 30-40%，结论占 10-15%，等）
- [ ] 标题层级正确（毕业论文 ≥ 四级，期刊论文 ≥ 三级）
- [ ] 标题采用陈述句，无"以……为例"套路
- [ ] 核心观点明确可辨识
- [ ] 每个最低层级标题下都有段落级写作蓝图
- [ ] 每个可写段落都有段落大意、论证功能、中心判断、使用材料、预期证据、衔接关系和不可声称内容
- [ ] 无素材段落均标注"暂不写入正文"，不得进入 write 派发

**毕业论文额外检查**：
- [ ] 五章结构完整：绪论 → 理论界定与文献综述 → 研究方法与设计 → 研究发现与机制解释 → 结论与讨论
- [ ] 第一章含：研究背景、目的与意义、研究问题、研究方法与技术路线、创新点
- [ ] 第二章含：核心概念界定、理论基础、国内外研究现状（按主题分类）、研究述评
- [ ] 第三章含：研究框架、方法选择与理由、对象与抽样、数据收集、研究伦理与信效度
- [ ] 第四章含：数据总体描述、各研究发现（对应研究问题）、综合分析
- [ ] 第五章含：理论解释、实践意涵、局限性、展望
- [ ] 每章独立成篇，章与章之间有逻辑递进

**期刊论文额外检查**：
- [ ] 经验分析与理论对话是否**合并为同一章节**（禁止分开为两章）
- [ ] 每个分析子节内部是否采用"发现呈现 → 理论对话 → 贡献提炼"三段节奏
- [ ] 是否有先堆砌所有发现再单独对话的冗余叙事
- [ ] 定量文章：文献综述每部分末尾是否包含"分析框架与研究假设"子节
- [ ] 定量文章：每个假设是否有理论依据标注
- [ ] 结构紧凑，无冗余展开

### 第二轮：论证严密性

**所有论文通用**：
- [ ] 引言/绪论包含：问题背景 → 研究缺口 → 研究问题 → 贡献陈述
- [ ] 文献综述包含：脉络梳理 → 争议/缺口 → 分析框架（或假设推导）
- [ ] 分析各分节有递进关系（不是平行罗列）
- [ ] 理论对话/讨论回到引言的研究缺口，形成闭环
- [ ] 结论覆盖总结、理论贡献、启示/含义、局限、展望
- [ ] 从引言→文献综述→方法→分析→对话→结论的逻辑链完整无断裂

**毕业论文额外检查**：
- [ ] 核心概念界定有操作化定义，且与后文分析一致
- [ ] 研究述评明确指出了"视角/方法/场景"三维中的具体缺口
- [ ] 研究方法选择有"为什么用这个方法"的理由陈述
- [ ] 每个研究发现明确标注对应哪个研究问题
- [ ] 机制解释有理论文献支撑（≥ 2 条）
- [ ] 结论不重复前文，是"提炼升华"
- [ ] 理论与实践无脱节（每个结论有案例/数据支撑）

**期刊论文额外检查**：
- [ ] 定量文章：假设推导链条完整（理论→逻辑→假设）
- [ ] 文献综述每个脉络的"分析框架与研究假设"子节不缺失
- [ ] 理论对话聚焦，不泛化
- [ ] 方法描述精简到可复现但不过度展开

### 第三轮：段落蓝图与证据映射质量

- [ ] 每个计划段落都有素材支撑或明确的"暂不写入正文"标注
- [ ] 段落大意不是标题复述，而是可指导正文写作的 1-2 句内容说明
- [ ] 论证功能与中心判断匹配，不出现只有材料堆放、没有判断的段落
- [ ] 素材标注包含文件路径和具体段落/行号
- [ ] 素材充分度标注准确（充足/一般/不足/空）
- [ ] "待补充"章节和"暂不写入正文"段落有明确补充方向
- [ ] 无虚构素材、虚构数据、虚构文献
- [ ] 跨章节素材引用一致（同一素材在不同章节的引用不矛盾）

### 第四轮：范式一致性

- [ ] 结构风格与目标范式匹配
  - 社会学研究范式：引言→文献综述（独立）→方法→分析→理论对话→结论
  - 管理世界案例研究范式：引言→文献综述与理论框架（合并）→研究设计→案例分析→理论贡献→结论与启示
- [ ] 核心主张的表达方式与范式匹配
- [ ] 标题措辞风格与目标期刊匹配

### 第五轮：可操作性

- [ ] 每个章节有明确的核心主张（不是"讨论某某"而是"论证某某"）
- [ ] 段落级写作蓝图可直接转入 `write` 模块的 `writing-dispatch-plan`
- [ ] 推荐的写作资源（章节标准、范文、提示词卡片）准确
- [ ] 各章节相对独立，可按任意顺序写作
- [ ] 字数和篇幅分配与预期总字数匹配

## 检查输出

```markdown
## 质量检查报告

### 通过项（N/总项）
- [具体通过项]

### 需修正项
| # | 项目 | 问题描述 | 修正建议 |
|---|------|---------|---------|
| 1 | [项目名] | [具体问题] | [如何修正] |

### 修正后状态
- 修正项数：N
- 修正后通过率：X%
- 是否可交付：是 / 否（如否则列出阻塞项）
```

## 修正循环

1. 按"需修正项"逐条修正大纲
2. 修正后重新运行本检查清单
3. 所有"需修正项"清零后进入输出阶段

## 输出

- 质量检查报告追加到 `paper-workspace/_logs/process-log-outline-[YYYY-MM-DD].md`
- 最终大纲文件（已通过检查的版本）
