# Phase 3：大纲质量检查

本阶段对已生成的论文大纲、段落级写作蓝图、证据映射与缺口报告执行五轮系统性核查。

## 顾问派发门控

交付前须派发 `modules/outline/agents/gap-review-consultant.md` 复核章节缺口、材料缺口、论证缺口与写作风险。未解决风险须写入 `agent-synthesis-outline-[YYYY-MM-DD].md` 与 `gap-report-[slug]-[YYYY-MM-DD].md`，并同步更新 `paper-workspace/_index/handoff-status.md`。

## 前置条件

- 已完成 Phase 2 的四份输出文件；
- 已明确论文目的（毕业论文/期刊论文）、论文类型与目标发表范式。

## 五轮检查清单

### 第一轮：结构完整性

**通用核查**：
- [ ] 核心要素或五章齐全，一级结构符合对应模板；
- [ ] 各章节权重与比例合理；
- [ ] 标题层级符合要求（毕业论文 ≥ 四级，期刊论文 ≥ 三级），标题采用陈述句；
- [ ] 核心论点清晰可辨；
- [ ] 每个最末级标题均配有段落级写作蓝图；
- [ ] 可写段落具备完整八要素，无素材段落均标为 `暂不写入正文` 且不传入 `write`。

**毕业论文专项**：
- [ ] 五章结构完整（绪论 -> 理论界定与文献综述 -> 研究方法与设计 -> 研究发现与机制解释 -> 结论与讨论）；
- [ ] 各章必备子目齐全（第一章含背景/意义/问题/方法/创新点；第二章含概念/理论/现状/述评；第三章含框架/方法/抽样/收集/伦理与信效度；第四章含总体描述/分项发现/综合分析；第五章含理论解释/实践意涵/局限/展望）；
- [ ] 章与章之间形成完整逻辑递进。

**期刊论文专项**：
- [ ] 经验分析与理论对话已合并为同一章节（子节采用「发现呈现 -> 理论对话 -> 贡献提炼」三段节奏）；
- [ ] 不存在先集中罗列全部发现再另开一章对话的冗余结构；
- [ ] 定量论文文献综述各脉络末尾包含「分析框架与研究假设」子节及理论依据标注。

### 第二轮：论证严密性

**通用核查**：
- [ ] 引言/绪论完整呈现「背景 -> 缺口 -> 问题 -> 贡献」；
- [ ] 文献综述实现「脉络梳理 -> 争议与缺口 -> 分析框架/假设」；
- [ ] 分析分节层层递进，理论对话回扣引言缺口形成闭环；
- [ ] 结论涵盖总结、理论贡献、启示、局限与展望。

**毕业论文专项**：核心概念有操作化定义且前后一致；研究述评指明具体三维缺口；方法选择有充分理由；每项发现对应研究问题；机制解释有 ≥ 2 条理论文献支撑；结论完成提炼而不重复前文。

**期刊论文专项**：定量假设推导链完整；文献脉络假设子节不缺漏；理论对话聚焦；方法说明精简至可复现边界。

### 第三轮：段落蓝图与证据映射质量

- [ ] 每个计划段落均有达标素材支撑或明确标为 `暂不写入正文`；
- [ ] 段落大意具备具体内容指导性，不简单复述标题；
- [ ] 论证功能与中心判断相称，不存在无判断的材料堆砌；
- [ ] 素材路径、段落/行号与充分度标注准确；
- [ ] 待补充章节与不可写段落具备清晰补充方向；
- [ ] 无虚构素材、数据或文献，跨章节引用口径一致。

### 第四轮：发表范式一致性

- [ ] 整体结构与目标范式匹配（社会学研究范式：独立文献综述；管理世界案例范式：综述与框架合并）；
- [ ] 核心主张与标题措辞契合目标期刊风格。

### 第五轮：可执行性

- [ ] 各章节核心主张明确（论证性而非介绍性）；
- [ ] 段落级蓝图可直接转换为 `write` 的 `writing-dispatch-plan`；
- [ ] 推荐参考的章节标准与范文匹配；
- [ ] 字数与篇幅分配符合预期总字数。

## 检查报告输出与修正循环

```markdown
## 质量检查报告

### 通过项（N / 总项）
- [通过项列表]

### 需修正项
| # | 检查项 | 问题描述 | 修正方案 |
|---|---|---|---|

### 修正后状态
- 未通过项数：N
- 是否可交付：是 / 否（若否，列出阻断项）
```

按「需修正项」逐条修改大纲后重新核查，直至需修正项清零，并将检查报告追加写入 `paper-workspace/_logs/process-log-outline-[YYYY-MM-DD].md`。
