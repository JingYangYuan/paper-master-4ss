# 投稿引用与参考文献规则

本文件用于 `paper-submission-4ss` 整理正文引用和文后参考文献。核心原则：只根据已有正文、write 阶段材料、lit 阶段题录和用户提供题录整理；不得虚构文献信息。

## 输入优先级

1. `paper-workspace/05-writing/` 中已进入正文、草稿或修订稿的引用和参考文献。
2. `paper-workspace/02-literature/` 中的 `paper-registry.csv` 与 `literature-map.md`；检索日志见 `paper-workspace/_logs/paper-search-log-[slug]-[date]-[run].md`。
3. 用户提供的 `.bib`、`.ris`、`.csv`、`.md` 题录。

`paper-registry.csv` 的 `citation_key` 列是 `[@key]` 形式引用的官方对照键：引用核查脚本会优先用它精确匹配，再回退作者-年份匹配。

若同一作者年份在 `write` 与 `lit` 中均存在，优先采用 `write` 阶段条目。

## 支持识别的正文引用

| 类型 | 示例 | 说明 |
|---|---|---|
| 中文叙述式 | `张三（2020）指出` | 保留作者进入句法结构 |
| 中文夹注式 | `（张三，2020）` | 中文标点统一 |
| 英文叙述式 | `Smith (2020) argues` | APA 常见形式 |
| 英文夹注式 | `(Smith, 2020)` | APA 常见形式 |
| Pandoc key | `[@smith2020]` | 可由 pandoc/csl 进一步处理 |
| 脚注式 | `[^1]` 或 Word 脚注 | 常见于人文社科投稿 |

## GB/T 7714

- 文后参考文献应包含作者、题名、文献类型、来源、年份、卷期页码或出版地出版社等可得字段。
- 中文作者使用原文姓名；英文作者按原文顺序保留。
- 信息缺失时不得补写猜测内容，应写入 `citation-gap-report.md`。

## APA

- 正文使用作者-年份格式。
- 文后参考文献按作者字母顺序排列。
- 期刊论文至少应尽量包含作者、年份、题名、期刊名、卷期、页码、DOI。

## 中文社会学夹注体例

- 正文可使用作者-年份夹注，如 `（张三，2020）`。
- 多篇文献并列时，用分号分隔，如 `（张三，2020；李四，2021）`。
- 同一作者同一年多篇文献需要 `2020a`、`2020b`，无法判断顺序时写入缺口报告。

## 输出要求

- `citation-normalized.md`：列出已识别引用、目标体例、对应文后条目。
- `citation-gap-report.md`：列出正文有引用但题录不完整、文后有条目但正文未引用、重复作者年份冲突、字段缺失。
- 不得把 `lit` 中未进入正文的候选文献自动加入文后参考文献。
