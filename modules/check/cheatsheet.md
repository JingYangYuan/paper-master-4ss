# 全流程审稿速查

| 维度 | 最快问题 | 主要依据 | 常见回流 | 顾问 | master路由意图 |
|---|---|---|---|---|---|
| 选题/创新 | 问题与贡献可见吗 | 七个意识 | design/lit | paper-check-argument-integrity-reviewer | 全文审稿/拒稿风险 → check |
| 标题 | 对象、关系、边界准确吗 | 三最/四要素 | write | paper-check-editorial-screening-reviewer | 全文审稿/编辑首筛 → check |
| 摘要 | 是否独立自明 | 摘要十项要求 | write | paper-check-editorial-screening-reviewer | 全文审稿/编辑首筛 → check |
| 关键词 | 是否有检索区分度 | 关键词规则 | write | paper-check-editorial-screening-reviewer | 全文审稿/编辑首筛 → check |
| 引言 | 是否导向明确问题 | 引导功能 | outline/write | paper-check-editorial-screening-reviewer | 全文审稿/编辑首筛 → check |
| 正文 | 论点证据结构闭环吗 | 五类结构/十六缺憾 | outline/analysis/write | paper-check-argument-integrity-reviewer | 全文审稿/论证闭环 → check |
| 结尾 | 是否回收而不新增 | 结尾闭环 | write | paper-check-argument-integrity-reviewer | 全文审稿 → check |
| 引文注释 | 来源可逐条追溯吗 | 引文核验 | lit/submission | paper-check-ethics-conformance-reviewer | 全文审稿/诚信规范 → check |
| 技术规范 | 细节与规则一致吗 | 增删改调 | submission | paper-check-ethics-conformance-reviewer | 全文审稿 → check；仅 Word/体例 → submission |
| 投稿 | 期刊公开要求已核验吗 | 投稿六问 | submission | paper-check-editorial-screening-reviewer | 全文审稿/期刊适配 → check；仅投稿包 → submission |

| 严重度 | 判定 | 动作 |
|---|---|---|
| 阻断 | 诚信、事实/引文、核心证据或闭环断裂 | 提交前解决并复核 |
| 重要 | 显著损害创新、结构、可读性或期刊适配 | 修订后复审 |
| 优化 | 非阻断表达或技术改进 | 可排入定稿清单 |

**快速决策**：有阻断→`大修后复审`或`不建议当前投稿`；无阻断但有重要→`小修后进入投稿整备`；仅优化→`可进入投稿整备`。缺少期刊规则写“期刊特定核验: 未执行”；缺少引文原文写“待核验”。
