# 全流程审稿速查

| 维度 | 最快问题 | 主要依据 | 常见回流 | 顾问 | master路由意图 |
|---|---|---|---|---|---|
| 选题/创新 | 问题与贡献可见吗 | 基础八问；七个意识（含折旧意识） | design/lit | paper-check-argument-integrity-reviewer | 全文审稿/拒稿风险 → check |
| 标题 | 四要素与三最定义句是否同时成立 | 最恰当、最简明、最重要的特定内容；研究对象、研究目的、研究范围、研究结论；五项要求 | write | paper-check-editorial-screening-reviewer | 全文审稿/编辑首筛 → check |
| 摘要 | 是否独立自含且第三人称 | 目的三、作用四、特点六、十项要求 | write | paper-check-editorial-screening-reviewer | 全文审稿/编辑首筛 → check |
| 关键词 | 是否为有检索意义的词或词组 | 定义丁四要点；选取三步；3–8个 | write | paper-check-editorial-screening-reviewer | 全文审稿/编辑首筛 → check |
| 引言 | 是否指出问题、必要性与本质区别 | 导游式诱导；编辑部总体三问与具体要求 | outline/write | paper-check-editorial-screening-reviewer | 全文审稿/编辑首筛 → check |
| 正文 | 论点证据结构闭环吗 | 五类结构；十六种缺憾（空枯浅平假倨伪重偏散俗冷乱抄隔冗） | outline/analysis/write | paper-check-argument-integrity-reviewer | 全文审稿/论证闭环 → check |
| 结尾 | 是否回收而不新增未经论证声称 | 结尾六类型；闭环三条 | write | paper-check-argument-integrity-reviewer | 全文审稿 → check |
| 引文注释 | 来源可逐条追溯吗 | 五项原则；十项规定；转引链 | lit/submission | paper-check-ethics-conformance-reviewer | 全文审稿/诚信规范 → check |
| 技术规范 | 八类细节与规则一致吗 | 序号、日期、数字、标点、人名、地名、图表、简称 | submission | paper-check-ethics-conformance-reviewer | 全文审稿 → check；仅 Word/体例 → submission |
| 投稿 | 期刊公开要求已核验吗 | 自我六问原句；期刊调研（期刊/目录/编辑/已刊论文） | submission | paper-check-editorial-screening-reviewer | 全文审稿/期刊适配 → check；仅投稿包 → submission |

| 严重度 | 判定 | 动作 |
|---|---|---|
| 阻断 | 诚信、事实/引文、核心证据或闭环断裂 | 提交前解决并复核 |
| 重要 | 显著损害创新、结构、可读性或期刊适配 | 修订后复审 |
| 优化 | 非阻断表达或技术改进 | 可排入定稿清单 |

**快速决策**：有阻断→`大修后复审`或`不建议当前投稿`；无阻断但有重要→`小修后进入投稿整备`；仅优化→`可进入投稿整备`。缺少期刊规则写“期刊特定核验: 未执行”；缺少引文原文写“待核验”。投稿篇比较标题的「最确切、最鲜明、最简洁」不得写入本表标题行。
