# 术语表

**报道性摘要** — 反映目的、方法、结果等核心内容的摘要，人文社科常见篇幅约400字（Ch 4）。
**编辑首筛** — 以题摘关键词、引言、创新可见度和五感快速作出的内部质量判断（Ch 1, 12）。
**闭环** — 结尾作为结构最后一环并与引言照应（Ch 8）。
**产品→作品→商品→品牌** — 学术生产从写出、投出、录用到信誉稳定的过程（Ch 1）。
**导游式诱导** — 引言吸引并引导阅读正文的功能（Ch 6）。
**独立自明 / 自含性** — 不读全文也能获得必要信息（Ch 4）。
**二级文献采用** — 摘要便于文摘类期刊稍作修改或不作修改即可采用（Ch 4）。
**发表后等待策略** — 按编辑部周期等待或联系，不把无消息当录用（Ch 12）。
**分标题** — 二至五级层次标题，树干与枝杈关系（Ch 2）。
**副标题** — 对主标题补充、强调，防止两张皮（Ch 2）。
**共轭回流** — check 工作流协议：10维须同时填写顾问、回流模块与 master 路由意图；来源为模块协议而非本书（Ch 7, 12）。
**关键词** — 从题名、摘要或正文选取、表示主题的词或词组（Ch 5）。
**期刊特定核验** — 以目标期刊公开规则核对；无规则则写未执行（Ch 12）。
**六有** — 言之有物、有故、有序、有文、有理、言必有中（Ch 12）。
**论文人八要素 / 新八股** — 标题、署名、摘要、关键词、引言、正文、结尾、注释（Ch 1）。署名信息不单列章节。
**七个意识** — 产品（知识产权，产品质量，产品包装）、规范（学术规范，技术规范，道德规范）、敬畏（敬畏学术，敬畏文字，敬畏读者）、创新（无新不说，无新不作）、超越（超越古今，超越时代）、生命（常读常新，活力隽永）、折旧（更新知识，与时俱进，存量折旧）（Ch 1）。
**三个类型（标题）** — 揭示研究范围、揭示主旨或论点、兼有主题副题（Ch 2）。
**三最（标题篇）** — 以最恰当、最简明的词语反映最重要的特定内容（Ch 2）。
**三最（投稿篇比较标题）** — 最确切、最鲜明、最简洁；仅用于投稿篇比较候选标题，不得与标题篇定义混条（Ch 12）。
**十六种缺憾** — 空、枯、浅、平，假、倨、伪、重；偏、散、俗、冷，乱、抄、隔、冗（Ch 7）。
**十项规定（注释）** — 引用即标、一次文献与转引限制等十条（Ch 9）。
**十项要求（摘要）** — 位置、第三人称、不写常识过程自评等十条，字数300–400汉字（Ch 4）。
**四重属性（关键词）** — 归类检索、选取形式、传递信息、独立表意（Ch 5）。
**四个要素** — 研究对象、研究目的、研究范围、研究结论（Ch 2）。不得写作对象、关系、视角、限定。
**特点六（摘要）** — 客观性、独立性、自明/自含性、完整性、概括性、诱导性（Ch 4）。
**五感** — 标题代入感、摘要故事感、引言诱导感、正文沉浸感、结尾共情感（Ch 1）。
**五类结构** — 三段式、并列式、递进式、对比式、混合式（Ch 7）。
**五项原则（注释）** — 原始性、新颖性、代表性、公开性、标准化（Ch 9）。
**五项要求（标题）** — 题文相符、简明（一般不宜超过25字）、醒目、词语规范、分行连词位置；宜有外文题名（Ch 2）。
**先全后简** — 简称首次用全称并括注（Ch 10）。
**引言** — 又称前言、导言、导语、导论、序言（Ch 6）。
**直接引用** — 保留原文并提供准确出处（Ch 9）。
**转引** — 注明转引自何处，禁止改成原始注（Ch 9）。
**自我六问** — 投稿篇初稿修改的六句原问（Ch 12）。
**自然型结尾** — 无提示词也无空行、靠逻辑收束（Ch 8）。
**主标题** — 体现写作意图与对象、内容、目的（Ch 2）。
**两尽两动** — 力尽才尽、打动感动的作者自检（Ch 12）。
