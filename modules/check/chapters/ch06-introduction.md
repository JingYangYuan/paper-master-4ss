# 第6章：引言：问题引导与研究定位

## Core Idea
引言是正文前的开场白，作用像导游诱导：让编辑看见真问题与解决思路，判断有无必要继续阅读。

## Frameworks Introduced
- **引言别名**：前言、导言、导语、导论、序言。
  - When to use: 稿件把「绪论」写成学位论文式万言章时。
  - How: 确认它是期刊短引言，不是专著序言。
- **导游式诱导**：导航+导游，提供兴奋点与情绪价值，决定编辑是否往下读。
  - When to use: 开头老生常谈、编辑无阅读欲望时。
  - How: 检查是否从不屑到刮目的递进，而非历史渊源堆砌。
- **形式 / 规则**：定义丙（2022）：背景、目的、理由、预期结果及其意义和价值；切合主题，言简意赅，突出重点创新点，客观评介前人，如实介绍自己成果。内涵五方面：选题背景范围缘由；现状问题原因；价值意义；方法；目的或新发现。要素核对：范围、参考点、问题、方法、点题。
  - When to use: 引言与摘要雷同或变成文献小综述。
  - How: 摘要讲「论文中有什么」，引言讲「为什么要做」；短文可用小段文字起引言效用。
- **编辑部总体要求**：是否指出目前研究存在的问题；是否阐述必要性；与以往研究不同之处和本质区别是什么。
  - When to use: 首筛引言能否过编辑三问。
  - How: 三问皆无则记重要或阻断（问题不清时）。
- **编辑部具体要求**：开门见山；言简意赅紧扣主题；实事求是不夸大不自谦；突出局限与创新点；不与摘要雷同；与结语呼应但不雷同；尽量不分段；一两段可省略「引言」二字，若加标题则需结语呼应；字数三档约 700–800 / 400–600 / 200–300。
  - When to use: 客套、填补空白、首次发现等不实之词出现时。
  - How: 按条删除常识、拉长史、自谦套话。
- **常见问题类型**：信息残缺型、自说自话型、论据失当型等（外加技法：举例引路、背景衬托、指出弊端、要点透露、设置疑问）。
  - When to use: 引言无法导向可回答问题。
  - How: 末端必须留下正文可回答的问题。

## Key Concepts
- **两个目的**：让读者知道为何选题、解决什么、有何意义；唤起注意并引导读正文。
- **内部特点**：与摘要近似但分工明确。
- **外部特点**：比学位论文引言精简得多。
- **作者三想法**：为什么选它；想解决什么；学术意义何在。

## Mental Models
- Use 导游式诱导 when Y=引言正确但不吸引继续读。
- Use 总体三问 when Y=只做了文献复述。
- Think of 引言 as 开车出发，结语是抵达终点。

## Anti-patterns
- **把引言写成文献小综述或立项过程**。
- **填补空白/很高学术价值/才疏学浅**。
- **引言与摘要、结语互相复制**。

## Key Takeaways
1. 引言必须指出问题、必要性与本质区别。
2. 与摘要、结语分工：为什么做 / 有什么 / 回应问题。
3. 字数按篇幅定制，不以短为美也不以长显博。
4. 书中经验是诊断支架；期刊公开规则优先并标注来源；无原文/无规则写「待核验」，不升级为违规、不给数值化录用率。
