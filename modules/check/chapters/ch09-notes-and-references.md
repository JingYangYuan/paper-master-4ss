# 第9章：注释与参考文献：可追溯的引用边界

## Core Idea
注释让前人贡献可定位，参考文献记录参考过的文献：二者涵盖面、作用、弹性不同，都必须可追溯。

## Frameworks Introduced
- **注释 vs 参考文献**：注释含释义性与引用性，可评议；参考文献只记录阅读引用过的文献，通常不评议。注释形式灵活（夹注脚注文末注等）；参考文献著录格式弹性小。
  - When to use: 把参考文献清单误当成已完成注释义务时。
  - How: 问读者能否看出他人贡献与本文关系。
- **五项原则**：原始性（读过且对论文产生作用的原始文献）；新颖性（最新或最有价值，体现前沿）；代表性（最有必要标注的）；公开性（公开发表、方便查证）；标准化（统一著录格式）。
  - When to use: 注释堆砌或只引自己熟悉的旧文献。
  - How: 五原则并行，缺公开性则读者无法查证。
- **十项规定**：引用即标；真实阅读的一次文献，转引须注转引自，禁止把转引改成原始注、禁止放弃可获得的原始文献；原则上公开发表；必要且新或最有价值；保持原貌不曲解；尽量原始作品/修订本；有的放矢不以数量取胜；项目齐全格式统一，当页相邻可「同上」；能在正文引的不放注释；除特别需要尽量不引教科书。
  - When to use: 逐条验收注码。
  - How: 先真实性与转引链，再格式。
- **引用/抄袭判别（核验支架）**：法律法规强调适当引用须指明作者作品名；编辑部常用五条提醒——使用他人观点不加注；无署名无合法来源；转引不标明或用无法证实的网络文献；以他人内容构成自己主要观点；以他人内容构成段落主体。
  - When to use: 存在直接引文、转引或题录缺口。
  - How: 只建核验表；无原文写待核验，不升级为违规。

## Key Concepts
- **直接引用 / 间接引用 / 启发引用**。
- **释义注**：说明性注释。
- **常见问题**：互捧型、唬人型、抄袭型、造假型、自恋型、隐瞒型。

## Mental Models
- Use 五项原则 when Y=注释很多但不可查证。
- Use 十项规定 when Y=转引伪装成原始阅读。
- Think of 注释 as 论文人的服饰：规范得体，不是炫富。

## Anti-patterns
- **转引改成原始性注释**。
- **无原文即断言抄袭或造假**。
- **注释互捧、自引过量、隐瞒关键来源**。

## Key Takeaways
1. 注释与参考文献不可互相替代。
2. 五项原则与十项规定是检查清单，期刊体例优先。
3. 引用/抄袭五条只作核验支架。
4. 书中经验是诊断支架；期刊公开规则优先并标注来源；无原文/无规则写「待核验」，不升级为违规、不给数值化录用率。
