# 第10章：技术规范：细节的一致性检查

## Core Idea
技术规范让层次、数目、专名和视觉元素可被统一核验：序号、日期、数字、标点、人名、地名、图表、简称八类必须前后一致。

## Frameworks Introduced
- **序号**：层级常用五级：一、 / (一) / 1. / (1) / ①。八项要求：先中国后阿拉伯；只能从大到小；可向下越级不可逆序；同层格式一致；下级标法统一；层次少可不用括号序号；括号序号后不加顿号逗号；单独「一」作标题后不加顿号。正文序与图表序分开。① 易与圈码注混淆。
  - When to use: 标题跳号、中阿混用、括号后加顿号。
  - How: 列层级表，查逆序与跳号。
- **日期**：年份中「O」与数字 0 区分；含月日的专名按规范书写，避免混用汉字与阿拉伯数字造成歧义。
  - When to use: 历史年份、会议日期、专名中的月日。
  - How: 计量用 0/零，编号用 O 的对应规则见数字节。
- **数字**：计量与编号优先阿拉伯数字；概数、定型词、节日等用汉字；相邻数字防歧义；一般数值不中阿混用；零与○、二与两、翻番与倍数、减少不用倍数、百分率与百分点分清。
  - When to use: 统计结果、年代、数量对比。
  - How: 对照项目清单，冲突时期刊体例优先。
- **标点**：问号可表存疑；引号书名号并列成分之间一般不再用顿号；书名号用于作品名而非课程机构会议；增加竖线 / ；连接号、冒号、省略号、句号分号、引号常见误用要逐项查。
  - When to use: 书名号套机构名、并列书名加顿号。
  - How: 先范围后具体误用类型。
- **人名**：中国历史人名特点（同姓名等）；期刊要求准确、必要时加注；帝王称呼按规范；外国人名：名从主人、约定译名、加注原文。
  - When to use: 同姓名、译名分歧、中西顺序。
  - How: 关键人名首次给辨识信息。
- **地名**：古地名查词典并加注今地；今地名注意更名重名中外同名；外国地名汉语名后加注外文、用约定译名、注意港台译名与国家更名、古今归属。
  - When to use: 历史地理或跨境地名。
  - How: 首次出现给充足定位。
- **图表**：目的是「三更加」「四节省」。总要求：自明性且不与正文重复；术语符号单位与正文一致；序号图下表上，题在序号后空一字；说明与来源在下方；仅一个也要图1/表1；正文先文字后图表并括注序号。
  - When to use: 图表不可脱离正文理解，或先图后文。
  - How: 按 CY/T 170 核表号表题表头。
- **简称**：构成有数字概括、取前舍后等；规范要求：国务院机构用官方简称；用学界接受的简称防歧义；先全后简；约定俗成；表意明白；避免歧义；汉语论文除必要不夹外文缩略词。
  - When to use: 首次即简称或机构简称口误。
  - How: 建全称—简称表。

## Key Concepts
- **自明性**：不看正文也能大致理解图表。
- **先全后简**：首次全称并括注简称。
- **层次只可向下越级**：一 可跳到 1.，不可从小到大。

## Mental Models
- Use 八类清单 when Y=内容成立但版式与专名混乱。
- Think of 技术规范 as 论文人服饰的缝线：开线则整体失信。

## Anti-patterns
- **层次逆序或同层多种序号**。
- **减少幅度用倍数**。
- **课程、机构、会议名加书名号**。
- **国家发改委、人社部等口误简称当规范**。

## Key Takeaways
1. 八类要逐项扫描，不要用笼统「格式问题」一笔带过。
2. 图表自明、先文后图、单独也编号。
3. 简称先全后简，机构简称以权威通知为准。
4. 书中经验是诊断支架；期刊公开规则优先并标注来源；无原文/无规则写「待核验」，不升级为违规、不给数值化录用率。
