# 第4章：摘要：精美摘要的提炼技巧

## Core Idea
摘要是对论文不加注释和评论的短文：第三人称陈述创新要点，使不读全文也能获得必要信息。

## Frameworks Introduced
- **目的三**：为读者提供论文精华缩写；提示主要概念与问题；补充标题信息不足。
  - When to use: 摘要像标题重复或像目录时。
  - How: 问这三句是否都被短文覆盖。
- **作用四**：短时间获得主信息以决定是否读全文；便利检索交流；便利二次文献采用；指引作者围绕精华再加工。
  - When to use: 摘要无法被文摘期刊直接采用时。
  - How: 检查是否含与正文同等量的主要信息，重点在结果和结论。
- **特点六**：客观性（不加注释评论）；独立性（可独立使用）；自明/自含性（信息明确可引用）；完整性（有论点论据的完整短文）；概括性（不遗漏精华）；诱导性（吸引读全文）。
  - When to use: 摘要依赖「本文」才能被理解时。
  - How: 脱离全文朗读，六性缺一即记问题。
- **十项要求**：(1) 置于标题、作者之后、关键词之前；(2) 第三人称，不出现「我认为」「本文」「作者」「我们」；(3) 不叙述常识；(4) 不列举例证、不描述过程、不写成结构介绍；(5) 不作自我评价；(6) 规范术语；(7) 非公知简称首次给全称；(8) 反映引言要点（研究内容）、正文要点（新发现）、结论要点（新成果）；(9) 概念与叙事次序前后一致；(10) 字数 300–400 个汉字、300 个外文实词，有特殊要求者按要求撰写。
  - When to use: 逐条验收摘要。
  - How: 先人称与冗余词，再信息量与字数；字数以征稿启事优先。
- **摘要十个问题**：含混不清型、理解偏差型、南辕北辙型、虎头蛇尾型、移花接木型、画蛇添足型、空洞宣言型、惜墨如金型、滥竽充数型、投机取巧型。
  - When to use: 诊断失败形态。
  - How: 对号入座，不搬具体案例故事。

## Key Concepts
- **文摘定义**：以提供梗概为目的，不加评论和补充解释。
- **报道性 / 指示性 / 报道—指示性摘要**：核心内容约400字；论题介绍约150字；介于其间约300字。
- **摘要 vs 内容介绍**：前者第三人称陈述新见解；后者第一人称叙述结构、意义、方法。
- **摘要 vs 引言**：摘要讲论文中有什么；引言讲为什么要做。

## Mental Models
- Use 第三人称 when Y=摘要读起来像作者广告。
- Use 特点六 when Y=不读全文就不知道发现是什么。
- Think of 摘要 as 编辑视角的二次文献短文，不是作者自述。

## Anti-patterns
- **以本文/本研究/我/我们/文章作主语**。
- **把摘要写成引言或方法路线图**。
- **自我评述「提出了自己的看法」**。
- **忽略目标期刊字数差异，按想象撰写**。

## Key Takeaways
1. 十项要求按书中十条检查，尤其第三人称与 300–400 字默认。
2. 六性中独立性、自明自含是首筛硬门槛。
3. 摘要压缩正文，不替代引言，不预支未经正文证明的评价。
4. 书中经验是诊断支架；期刊公开规则优先并标注来源；无原文/无规则写「待核验」，不升级为违规、不给数值化录用率。
