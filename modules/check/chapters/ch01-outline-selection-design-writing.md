# 第1章：纲要：选题、设计与撰写

## Core Idea
期刊论文是面向编辑与读者的公共精神产品：先用基础八问对齐概念，再用选题·设计·撰写把问题、证据和结构做成可检查对象。

## Frameworks Introduced
- **期刊论文基础八问**：什么是学术论文；学术论文分类；什么是学术期刊论文；学术期刊文章分类；期刊论文特点；写作逻辑；结构图式；编辑处理论文的常见方式。
  - When to use: 审稿开始、作者尚未与编辑建立共识时。
  - How: 逐问核对稿件是否提供新信息（二要一不要），是否可被同行“认”与“懂”。
- **论文人八要素 / 新八股**：标题、署名、摘要、关键词、导语/引言、正文、结尾/结论、注释，对应眼睛、耳朵、鼻子、嘴巴、脖子、身体、脚跟、服饰。
  - When to use: 检查形式规范是否让论文“立起来”。
  - How: 眼睛亮、耳朵正、鼻子挺、嘴巴清、脖子优、身体直、脚跟稳、服饰美。署名对应耳朵，诚信层仅待核验，不单列检查维。
- **产品 → 作品 → 商品 → 品牌**：产品=持续写出的学术生产；作品=以姓名信誉投给期刊；商品=三审三校后录用；品牌=批次稳定、供不应求。
  - When to use: 判断作者是否把私密写作误当成公共产品。
  - How: 查市场调研、成本核算、内外质量与包装是否同时存在。
- **七个意识**：产品意识（知识产权，产品质量，产品包装）；规范意识（学术规范，技术规范，道德规范）；敬畏意识（敬畏学术，敬畏文字，敬畏读者）；创新意识（无新不说，无新不作）；超越意识（超越古今，超越时代）；生命意识（常读常新，活力隽永）；折旧意识（更新知识，与时俱进，存量折旧）。
  - When to use: 对产品、规范、更新压力做并行扫描。
  - How: 前六个适用于所有生产；第七个是下一篇的开端，周而复始。
- **五感**：标题的代入感，摘要的故事感，引言的诱导感，正文的沉浸感，结尾的共情感。
  - When to use: 模拟编辑二十分钟首筛的可读性。
  - How: 五处各记一处可见承诺或断裂。
- **选题·设计·撰写**：选题从哪里来与原则；提纲拟分四块；各环节撰写要领。
  - When to use: 问题、材料、结构尚未对齐时。
  - How: 先让问题可回答，再设计标题框架，再写各部位。

## Key Concepts
- **二要一不要**：要新的学术信息，要有所发现/发明/创造/前进，不要重复、模仿、抄袭。
- **认与懂**：同行认可且能懂微言大义。
- **八特点**：学术性、理论性、专业性、科学性、创新性、逻辑性、规范性、可读性。
- **写作逻辑**：以文字与编辑对话，求作者与编辑双赢。
- **一见钟情**：首轮筛选更接近一见钟情，而非日久生情。
- **三为**：为公开发表、进入流通、引起关注下载引用。
- **两冲**：视觉冲激与阅读冲动（标题篇接口）。
- **积极型编辑**：辅助者，不能超越第二作者定位。

## Mental Models
- Use 基础八问 when Y=概念未对齐，先共识再评稿。
- Think of 论文人 as 让八部位各司其职的立人框架，不是束缚作者的旧八股。
- Use 折旧意识 when Y=旧稿循环投出，先更新知识再包装。
- Use 五感 when Y=形式完整但编辑可能无阅读欲望。

## Anti-patterns
- **只管生产不问学术市场**：重复性生产，拒稿后无法承受。
- **把学位论文章节原样当期刊论文**：未按发稿要求精练。
- **先写后找问题**：结构反复返工。
- **浅议/浅论/初探式低信息标题**：缺乏知识引流（检查点，案例不搬）。

## Key Takeaways
1. 选题要有对象、问题、材料与贡献边界；设计先对齐问题—证据—结构。
2. 七个意识必须写全称与括注；缺折旧意识等于切断生产循环。
3. 论文人可写八要素，署名信息不单列章节，诚信层仅待核验。
4. 书中经验是诊断支架；期刊公开规则优先并标注来源；无原文/无规则写「待核验」，不升级为违规、不给数值化录用率。
