# 第8章：结尾：回收论证并形成闭环

## Core Idea
结尾是整篇的结局：从全部材料归纳研究结果，回收引言所提问题，不新增未经论证的声称。

## Frameworks Introduced
- **结尾六类型**（功能定位）：
  - **结论型**：用「结论」或「结论与讨论」单独占行；与摘要呼应，表明已解决问题；可顺带遗留问题；不出现图表。
  - **结语型**：用「结语」单独占行；总结概括以呼应引言和大标题；内容比结论宽，主观判断更明显；多用于专题/综合论述。
  - **余论型**：前文未说或未展开的延伸；重点是还可以做什么，不是已经发现了什么。
  - **提示型**：用「总之」「要之」「概言之」「综上所述」等提示收束。
  - **空行型**：空一行暗示下文即结尾，无连词。
  - **自然型**：无连词也无空行，靠逻辑过渡让读者领悟结束。
  - When to use: 结尾重复摘要、误标余论或草草收兵时。
  - How: 先辨功能再辨样式；结论≠结语≠余论。
- **写作要求七项**：本位收住 / 宕出远神 / 放开一步三种收法之一；回答开头问题；与正文逻辑衔接；有启示性；客观科学语气；用语精练不复制前文；不要插图表格。
  - When to use: 结尾拖沓或展望假大空。
  - How: 删未经正文证明的新材料。
- **评判标准三条**：是否留下结尾印象；是否为从开始到结束的最后一环；是否符合闭环（外观完整且首尾照应）。
  - When to use: 判断结尾是必选项还是被作者省略。
  - How: 缺结尾即项链缺最后一颗珠。

## Key Concepts
- **形与神**：十类外貌样式 vs 六种功能类型。
- **结论 vs 结语**：结论是推论出的论断；结语是结构性总结，不代替最终结论。
- **余论 vs 结论**：已经做了什么 vs 还可以往哪走；总结评价误标「余论」应改。
- **摘要与结尾**：摘要是精华短文；结尾是闭环收束，角色不可混。

## Mental Models
- Use 六类型 when Y=有收束文字但功能错位。
- Use 闭环三问 when Y=结尾像另起一篇政策建议。
- Think of 结尾 as 论文人的脚跟：不稳则人立不住。

## Anti-patterns
- **虚张声势、角色混乱、喧宾夺主、草率将就**。
- **结尾新增正文未论证的理论声称**。
- **把余论写成结论性总结**。

## Key Takeaways
1. 结尾回收不新增未经论证声称。
2. 结论型、结语型、余论型、提示型、空行型、自然型六者功能不同。
3. 有引言标题则宜有收束与之呼应。
4. 书中经验是诊断支架；期刊公开规则优先并标注来源；无原文/无规则写「待核验」，不升级为违规、不给数值化录用率。
