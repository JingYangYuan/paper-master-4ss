# 第5章：关键词：关键词选择要关键

## Core Idea
关键词是从题名、摘要或正文选取、用以表示主题内容的词或词组，用来阐释标题并服务检索，不是句子，也不是标题的机械复制。

## Frameworks Introduced
- **关键词定义（定义丁通俗四要点）**：便利文献检索；从标题、摘要或正文选出；表示主题内容；词或词组。
  - When to use: 关键词像短语标题或整句时。
  - How: 对照 GB/T 7713.2-2022；学位论文「语词或术语」更宽，期刊要用词或词组。
- **四重属性**：作用=归类检索；选取形式=从标题摘要正文直接选取；功能=传递主要内容；内涵外延=能独立表意的名词或名词性词组。
  - When to use: 判断某词有无检索意义。
  - How: 泛指词「方法、理论、分析」不选。
- **基本要求**：国标六条（检索意义、CY/T 173、宜用主题词表、外文对应、3–8个、置于摘要之后）可细化为期刊十六项，核心是显著另起行、3–8个、规范词、名词或名词化词组、拆分五原则、不用模糊时间词、不用介词连词感叹词代词、同义近义不并列、外语须译、通用词不选、先大后小/先目的后结论。
  - When to use: 数量、词性、排序出问题。
  - How: 实证量化可 5–8，思辨综述可 3–5；先查投稿须知。
- **选取方法三步**：分析主题概念；从大标题、摘要、小标题、正文筛选；按先大后小、先目的后结论排序并决定直接用、规范处理或搭配组合。
  - When to use: 关键词与标题脱节或照搬文学化标题。
  - How: 紧扣主题但改造抽象标题用词。
- **与标题的区别**：关键词阐释标题；作用是切入点、多角度诠释、把抽象标题具象化。关联方式、形态、功能均不同。
  - When to use: 作者认为关键词叠床架屋时。
  - How: 标题是纲，关键词是对纲的注解。

## Key Concepts
- **索引词 / 主题词的灵活形态**。
- **拆分五原则**：整体与部分拆；交叉概念均分；拆后义变则保留原词组；固定搭配不拆；专业术语专名不拆。
- **常见问题**：关键性词语缺失；通用性词语；标引不适度（过细琐碎或错位）。

## Mental Models
- Use 选取三步 when Y=只会从标题原样复制。
- Use 先大后小 when Y=专名可能跨学科重名。
- Think of 关键词 as 论文人的嘴巴：说出核心。

## Anti-patterns
- **把「学科发展历史机遇」整串当一个期刊关键词**。
- **WTO 不译、CoT 不给中文**。
- **古代/新时期等模糊时间词入选**。

## Key Takeaways
1. 期刊关键词是词或词组，不是学位论文式长语词。
2. 数量与外文对应以目标期刊为准，默认 3–8。
3. 关键词阐释标题，不重复无信息功能词。
4. 书中经验是诊断支架；期刊公开规则优先并标注来源；无原文/无规则写「待核验」，不升级为违规、不给数值化录用率。
