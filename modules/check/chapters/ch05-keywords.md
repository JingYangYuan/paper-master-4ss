# 第5章：关键词：关键词选择要关键

## Core Idea
关键词是检索、分类和读者发现论文的索引语言，应从标题、摘要和正文中抽取能够区分研究对象与理论/方法位置的词。

## Frameworks Introduced
- **关键词选取方法**：作为审稿检查的明确框架，而不是可随意替换的修辞。使用时应记录适用条件、观察到的证据和不能判断的缺口。
- **标题—关键词区分**：作为审稿检查的明确框架，而不是可随意替换的修辞。使用时应记录适用条件、观察到的证据和不能判断的缺口。

## Key Concepts
- **主题词**：用于定位稿件中的可检查对象；结论必须对应原文位置或用户提供材料。
- **自由词**：用于定位稿件中的可检查对象；结论必须对应原文位置或用户提供材料。
- **检索性**：用于定位稿件中的可检查对象；结论必须对应原文位置或用户提供材料。
- **区分度**：用于定位稿件中的可检查对象；结论必须对应原文位置或用户提供材料。
- **同义词**：用于定位稿件中的可检查对象；结论必须对应原文位置或用户提供材料。
- **中英文对应**：用于定位稿件中的可检查对象；结论必须对应原文位置或用户提供材料。

## Mental Models
- 从题目、摘要、正文高信息密度名词中列候选。
- 删除过宽泛、同义并列和无实质信息的词，保留能定位对象、机制或方法的组合。
- 核对数量与中英文对应是否符合目标期刊。

## Anti-patterns
- **把关键词写成句子**：它把可核验的学术判断替换成形式、猜测或装饰，需在报告中说明具体风险。
- **使用介词、连词或泛化动词**：它把可核验的学术判断替换成形式、猜测或装饰，需在报告中说明具体风险。
- **重复标题中的无区分词**：它把可核验的学术判断替换成形式、猜测或装饰，需在报告中说明具体风险。
- **只选大类学科词**：它把可核验的学术判断替换成形式、猜测或装饰，需在报告中说明具体风险。

## Key Takeaways
1. 关键词不是缩短版标题；通常以3—8个为通用参考，目标期刊规则优先；每个词都应有正文落点。
2. 审稿应写出证据位置、依据、严重度、修改动作、回流模块与复核标准，不能只给泛泛评价。
3. 书中经验性方法是诊断支架；目标期刊的公开要求出现时优先，并标注其来源。
4. 缺少原始引文或期刊规则时，统一标记“待核验”，不推断违规。

## Connects To
- **标题、摘要、投稿**：本章的判断需要与相邻部分交叉验收，避免局部优化破坏全文一致性。
