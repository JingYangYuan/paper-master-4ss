# 第7章：正文：严谨论证与结构控制

## Core Idea
正文要把论点、证据和层次做成可追踪推理：先匹配五类结构的适用范围，再用十六种缺憾做病理扫描。

## Frameworks Introduced
- **五类结构及适用范围**：
  - **三段式**：短篇常用；实质是提出问题→分析问题→解决问题的纵贯式，段数可变为四段，魂魄是有头有尾层层推进。
  - **并列式**（横式）：围绕中心论点设平行分论点，多角度共同论证；适用于多侧面展开同一论题。
  - **递进式**：层次按逻辑加深，适用于需要层层逼近机制或历史发生的论题。
  - **对比式**：两造对照以显差异或张力，适用于比较、论争或概念辨析。
  - **混合式**：并列中的递进，或递进中的并列，适用于复杂论题不能单结构承载时。
  - When to use: 结构松散、段落失衡或分论点互相抢戏时。
  - How: 先命名结构，再问是否服务同一中心；类型是描述工具，不是强制模板。
- **十六种缺憾**：空、枯、浅、平，假、倨、伪、重；偏、散、俗、冷，乱、抄、隔、冗。
  - When to use: 正文可读但论证不可核验，或信息密度异常时。
  - How: 每字一句诊断，落到原文位置。

## Key Concepts
- **空**：内容空泛空洞，堆砌不证自明的概念句。
- **枯**：枯燥无场景感，论点孤立如记账。
- **浅**：直白无曲、根底漂浮，或靠新名词掩饰浅薄。
- **平**：结构、语言、感情三平，被动完成任务。
- **假**：从立场出发找二手材料站队，过程失真。
- **倨**：必须/一致认为/名家站台/毋庸置疑等居高临下。
- **伪**：论证的是伪问题——已解决、不存在或前提不成立。
- **重**：重复教科书、他人或自己，缺乏新范式。
- **偏**：以偏概全，按偏好剪裁正反材料。
- **散**：形散神也散，一篇多个中心。
- **俗**：内俗（市井口语）与外俗（翻译体欧化句）。
- **冷**：概念游戏无温度，多重定语让汉语隔膜。
- **乱**：思维碎片化与结构失序，层次颠倒。
- **抄**：隐性汇编式摘引，删引文后正文所剩无几；表面可有出处，是否违规待核验。
- **隔**：注释文献陈旧，与学术前沿隔膜。
- **冗**：信息密度低，一书架构写论文或车轱辘话。

## Mental Models
- Use 五类结构 when Y=需要先给正文一个可命名的骨架。
- Use 十六字 when Y=骨架在但病理不明。
- Think of 论文人身体 as 正文：层次分明才能站直。

## Anti-patterns
- **把并列三分误当成三段式纵贯**。
- **用经典语录替代自己的论证主体**。
- **结构类型当强制模板，削足适履**。

## Key Takeaways
1. 三段式要义不在「三」而在提出—分析—解决。
2. 十六字必须整串使用：空、枯、浅、平，假、倨、伪、重；偏、散、俗、冷，乱、抄、隔、冗。
3. 问题—论点—证据—结构—结尾任一断裂都要回流 outline/analysis/write。
4. 书中经验是诊断支架；期刊公开规则优先并标注来源；无原文/无规则写「待核验」，不升级为违规、不给数值化录用率。
