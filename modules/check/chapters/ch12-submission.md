# 第12章：投稿：期刊调研、修改与提交决策

## Core Idea
投稿是作者与编辑合力：先用自我六问和打磨把公共产品做到可交，再研究期刊/目录/编辑/已刊论文，而不是碰运气。

## Frameworks Introduced
- **初稿修改的自我六问**（书中六句）：(1) 「标题」能够凝练出论文的精华吗？(2) 「摘要」没有写成提要吧？编辑/读者能了解论文核心内容吗？(3) 「引言」能够引出深邃问题、「吸引」编辑注意吗？(4) 各个段落前后连贯、符合逻辑、不自相矛盾吧？(5) 引用的文献资料可靠吗？数据是最新的吗？(6) 从头到尾通顺吗？转换词、过渡词用得恰当吗？
  - When to use: 完稿沉淀后、投稿前。
  - How: 六句逐条回答并落到原文位置；旧口径「投稿六问」不是本书专名，已删除。
- **打磨要领**：口诀为「一增、二删、三改、四调」（增强鲜明与坚实；删除枝蔓；更改词不达意；调整矛盾跳跃）。细化为十环节：比较标题；锤炼摘要；核对文献数据；检查推理；审思段意；通理序号；精炼语句；润色文字；改正标点；查对注释。比较标题时从候选中选最确切、最鲜明、最简洁者——此「三最」出自投稿篇比较标题，不得与标题篇定义句「最恰当、最简明、最重要的特定内容」混成一条。
  - When to use: 六问后仍不踏实。
  - How: 先内容五环节后形式五环节。
- **定稿验收**：作者「两尽」（力尽、才尽）「两动」（打动、感动）；编辑「六有」：言之有物、言之有故、言之有序、言之有文、言之有理、言必有中。
  - When to use: 判断是否可投。
  - How: 六有对照问题矩阵，缺物或缺故不得声称可进入投稿整备。
- **期刊调研五招**：研究期刊（综合类 vs 专业类及发稿侧重）；研究期刊目录（栏目、作者档次、标题风格）；研究期刊编辑（实证/思辨、宏观/微观偏好，不虚构未核验偏好）；研究刊发的论文；细节决定成败。
  - When to use: 选刊前。
  - How: 公开目录与近刊为证据；无规则写「期刊特定核验: 未执行」。
- **投稿后等待**：给编辑审阅时间；超约定周期可另投；联系结果约三类：委婉拒绝、直接表达、要求修改。
  - When to use: 催稿或一稿多投风险时。
  - How: 按编辑部公开周期，不把无消息解释为录用。

## Key Concepts
- **综合类 / 专业类**：公共话题与学科全覆盖微观问题的功能差。
- **文责自负**：引文硬伤反映治学态度。
- **书中未找到**：独立专名「附录自检清单」「拆—仿—探」——不编造；检查问句用六问+十环节+六有代替。

## Mental Models
- Use 自我六问 when Y=稿件完整但作者未换位到编辑。
- Use 期刊调研 when Y=形式合格但屡投不中且未读目录。
- Think of 投稿 as 给作品找匹配的期刊，不是预测命中率。

## Anti-patterns
- **不看栏目目录、不区分综合类与专业类**。
- **把投稿篇比较标题三最写成标题篇定义**。
- **把「投稿六问」「拆—仿—探」标成田卫平框架**。
- **给出数值化录用率或伪造编辑偏好**。

## Key Takeaways
1. 自我六问必须用书中六句原文。
2. 调研期刊、目录、编辑、已刊论文，细节决定成败。
3. 期刊公开规则优先；无规则写未执行。
4. 书中经验是诊断支架；期刊公开规则优先并标注来源；无原文/无规则写「待核验」，不升级为违规、不给数值化录用率。
