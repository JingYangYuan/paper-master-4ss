# 第2章：标题：亮眼标题的制作诀窍

## Core Idea
标题是论文的额与目：以最恰当、最简明的词语，反映最重要的特定内容的逻辑组合，并承诺正文可兑现。

## Frameworks Introduced
- **三最**：所谓标题，就是以最恰当、最简明的词语，反映学术期刊论文中最重要的特定内容的逻辑组合。
  - When to use: 拟题、改题、比较候选标题时。
  - How: 同时检查恰当、简明、特定内容三拍是否齐。投稿篇另有「最确切、最鲜明、最简洁」用于比较标题，不得混成一条。
- **四个要素**：研究对象、研究目的、研究范围、研究结论。
  - When to use: 标题过宽、双主题或内涵外延无法由一篇论文承担时。
  - How: 四词作抓手通盘考虑；不要误以为涵盖越全越好；「甲与乙」须加限定。删除旧口径「对象、关系、视角、限定」。
- **五项要求**：(1) 题文相符——准确；(2) 简明扼要——精练（一般不宜超过25字）；(3) 语义清晰——醒目；(4) 词语规范——便于检索（三便于：转载、引用、检索）；(5) 分行注意——连词「和/与/及/暨」放下一行句首。另：宜有外文题名。
  - When to use: 验收题名是否可进入二次文献。
  - How: 先准确再鲜明；字数与外文以期刊公开规则优先。
- **主标题 / 副标题 / 分标题**：主标题展现意图、对象、内容、目的；副标题补充强调；分标题为二至五级层次。
  - When to use: 语意未尽、虚实分工或层次不清时。
  - How: 副标题防两张皮；分标题是树干与枝杈，下级不得大于上级。
- **三种类型与八种形式**：类型=揭示研究范围 / 揭示课题主旨或论点 / 兼有主题副题。形式=问题综论式、简论式、陈述式、悬念式、评论式、阐释式、问答式、比较式。
  - When to use: 需要给同一课题换面相时。
  - How: 「关于」与「对」不可连用；「分析」与「探讨」不可连用。

## Key Concepts
- **题名信息**：研究范围、研究论点、研究水平的第一个重要信息。
- **先起名后生孩子 / 生完孩子再起名**：两种习惯均可，定名都不可随意。
- **一篇一主题**：不能两个主题并行而无限定。
- **虚题与实题**：主标题虚则副标题须实。
- **基于**：作主标题易陈旧，必要时放副标题。

## Mental Models
- Use 四要素 when Y=标题像教科书章名或新闻标题。
- Use 三最定义句 when Y=需要判断是否反映特定内容而非空泛修辞。
- Think of 主副分标题 as 额目分层：一级承诺，二级补边界，三级推论证。

## Anti-patterns
- **文不对题 / 大而无当 / 名实不符**。
- **观点外露型**：期刊题名一般界定对象或范围，观点放结论。
- **浅议、浅论、初探** 及介词泛用、冗长堆砌。
- **把旧四要素（对象、关系、视角、限定）当作本书框架**。

## Key Takeaways
1. 拟题抓手是研究对象、研究目的、研究范围、研究结论，不是对象—关系—视角—限定。
2. 三最在本章只使用定义句；投稿比较标题的另一组「三最」见 ch12 并标注出处。
3. 副标题只在补足边界时使用；小标题服务论证推进。
4. 书中经验是诊断支架；期刊公开规则优先并标注来源；无原文/无规则写「待核验」，不升级为违规、不给数值化录用率。
