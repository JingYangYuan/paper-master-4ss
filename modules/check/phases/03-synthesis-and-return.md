# Phase 03：意见综合与精确退回

## 目标

整理去重审稿意见、裁决严重度、保留分歧记录，并依据问题矩阵给出四值总体结论，输出主报告、问题矩阵、按严重度排序的修订清单及 `write -> check -> submission` 退回 Mermaid 图。本阶段仅作诊断与退回指引，不直接覆盖稿件。

## 统一判定口径

- **总体结论（四值）**：`可进入投稿整备`、`小修后进入投稿整备`、`大修后复审`、`不建议当前投稿`。
- **严重度（三级）**：`阻断`、`重要`、`优化`。
- **问题矩阵字段（九项）**：`check_id`、检查维度、原文位置/证据、依据、严重度、诊断、修改动作、退回模块、复核标准。

## 执行步骤

1. 核对并去重顾问意见（或顺序复核 A/B/C 意见），保留分歧及未采纳理由，由主流程最终裁决严重度。
2. 依据问题矩阵确定唯一总体结论（存在未解决 `阻断` 项时，结论须为 `大修后复审` 或 `不建议当前投稿`）。
3. 在 `paper-workspace/05-writing/reviews/` 输出三份文件：
   - `paper-check-report-[slug]-[YYYY-MM-DD].md`（须含输入说明、审稿限制、总体结论、关键阻断项、10 维结论与退回 Mermaid 图）
   - `paper-check-matrix-[slug]-[YYYY-MM-DD].md`
   - `paper-check-revision-list-[slug]-[YYYY-MM-DD].md`
4. 综合记录写入 `paper-workspace/_logs/agents/check-[YYYY-MM-DD]/agent-synthesis-check-[YYYY-MM-DD].md`。
5. 按退回对照表精确指向负责修订的模块。

## 完成门槛

- 每条 `check_id` 均可追溯至顾问意见或主流程裁决；
- 修订清单严格按「阻断 -> 重要 -> 优化」排序并附可判定复核标准；
- 总体结论与阻断项一致，无逻辑冲突；
- 退回模块严格依据 10 维表定位，不得将前序设计与证据问题笼统推给 `write`。

## 问题退回边界对照

| 问题类型 | 退回目标 | 限制约束 |
|---|---|---|
| 选题 / 创新 / 理论锚点 | `design` / `lit` | 不得进入投稿整备 |
| 结构 / 证据映射 | `outline` | 不得以语言润色掩盖结构缺失 |
| 数据 / 识别 / 统计边界 | `analysis` | 不得超出已有结果外推 |
| 实质章节改写 / 语言残留 | `write` | 不得将实质改写交由 `submission` 处理 |
| 引文体例 / Word / 投稿包 | `submission` | 不得以排版模板掩盖论证或诚信问题 |
| 引文原文缺失 | 用户补充 | 不得未经核验直接判为违规 |

总控交接约束：仅当 `check` 通过（`可进入投稿整备` 或 `小修后进入投稿整备`）时进入 `submission`；结论为 `不建议当前投稿` 或 `大修后复审` 时默认不导出 Word。

## 顺序复核汇总要求

若 Phase 02 降级为 `sequential-review`，本阶段须完整综合 A/B/C 三组复核意见，并在 `agent-synthesis-check` 中记录降级原因与完成门槛核对结果。
