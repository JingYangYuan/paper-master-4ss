# Phase 02：分层审阅执行

## 目标

执行编辑首筛、论证闭环、诚信与规范、技术与期刊适配四层检查。完整审稿须派发 `paper-check-reviewer` 并等待其返回终态后保存原始意见；派发失败最多重试 1 次，仍失败时转入顺序复核并记录。

## 统一判定口径

- **总体结论（四值）**：`可进入投稿整备`、`小修后进入投稿整备`、`大修后复审`、`不建议当前投稿`。
- **严重度（三级）**：`阻断`、`重要`、`优化`。
- **问题矩阵字段（九项）**：`check_id`、检查维度、原文位置/证据、依据、严重度、诊断、修改动作、退回模块、复核标准。

## 执行步骤

1. 完整审稿派发 `paper-check-reviewer` 并等待终态，同一次评审内按三组清单逐维核查：
   - **A 组（题摘关键词引言）**：题目、摘要、关键词、引言、创新可见度与期刊适配（必读含 `chapters/ch12-submission.md`）；
   - **B 组（正文结尾）**：问题—论点—证据—结构—结尾闭环及十六种常见缺憾；
   - **C 组（引文技术规范）**：引文注释与十类技术规范细节。
2. 顾问意见开头须回填 `参考库回查: base=check-2026.10.24; tier=T2; 判据=…; 缺口=…`；缺少可核验的公开期刊规则时写明 `期刊特定核验: 未执行`。
3. 单项检查仅核对指定维度并记录未覆盖维度与未派发理由。
4. 统一填写九字段问题矩阵与三级严重度；引文或规则缺失仅标「待核验」，不得推断违规。
5. 派发失败最多重试 1 次，仍失败则执行 `sequential-review`（记 `agent-gate-block: failed×1 + sequential-review`）。

## 完成门槛

- 完整审稿：`paper-check-reviewer` 已返回终态意见，或已完整记录 `sequential-review` 及原因；
- 问题矩阵每条记录均具备九字段，严重度仅取 `阻断` / `重要` / `优化`；
- 仅学术诚信、事实/引文错误、核心证据缺失或论证闭环断裂可判 `阻断`；
- 四层检查（编辑首筛、论证闭环、诚信与规范、技术与期刊适配）均已有明确结论或跳过说明。

## 四层检查与检查组对应关系

本阶段仅识别与记录问题，不直接改稿或导出 Word：

| 检查层级 | 对应检查组 | 覆盖 10 维 |
|---|---|---|
| 编辑首筛 | A 组 | 标题、摘要、关键词、引言、投稿适配 |
| 论证闭环 | B 组 | 选题/创新、正文、结尾 |
| 诚信与规范 | C 组 | 引文注释 |
| 技术与期刊适配 | C 组（技术）+ A 组（期刊） | 技术规范、投稿适配 |

## 顺序复核归档规范

降级为顺序复核时，分 A/B/C 三组存为 `paper-check-reviewer--A.md`、`--B.md`、`--C.md`，综合文件中写明未并行原因、复核顺序与参考库回查执行情况。空返回或缺失回查行按失败处理。

## 阶段产物

报告、矩阵与修订清单写入 `paper-workspace/05-writing/reviews/`；顾问意见与综合报告写入 `paper-workspace/_logs/agents/check-[YYYY-MM-DD]/`。
