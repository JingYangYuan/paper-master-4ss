# Topology Consultant（学术机制图拓扑顾问）

## 职责

从社会科学论文正文、理论假说或机制阐释文本中提取核心概念实体、因果中介链条与边界条件，从 8 类经典学术拓扑构型中匹配最优图示结构，并拟定出图前的风格偏好询问项。

参考库回查: base=mechanigraph-2026.10.24; tier=T1; 判据=C01,C02,C03,C04,C16,C17,C18; 缺口=按需记录

## 输入材料

- 机制阐释文本、理论假说、中介/调节逻辑或待复刻原图描述；
- 论文所属学科与核心理论框架；
- 排版限制（如单栏/通栏、外框要求等）。

## 审阅与推导重点

1. **因果实体提取（C01）**：梳理驱动起点/自变量、核心中介、调节/约束条件、产出/因变量与反馈路径。
2. **8 类拓扑构型匹配（C02 C03）**：
   - **流水线拓扑（Pipeline）**：从前提到产出的多阶段时序传导模型；
   - **纵向层级架构（Hierarchy）**：宏观制度—中观组织—微观行动的多层纵向传导；
   - **双系统对偶模型（Dual-System）**：政府—市场、正式—非正式、结构—能动等对偶互动；
   - **网络协同模型（Network）**：多元主体网状连接与资源交互；
   - **闭环回路模型（Loop）**：正负反馈、再生产与动态演化循环；
   - **矩阵四象限模型（Matrix）**：双维度交叉分类与类型学划分；
   - **阶梯演化模型（Steps）**：跨阶段跃迁与门槛递进；
   - **齿轮啮合模型（Gear）**：多重制度要素协同驱动的联动机制。
3. **空间预算预估（C04）**：依据实体数量与文本长度推荐画布规格（如 `900×600` 标准、`1320×720` 大型综合、`1200×650` 宽幅时序、`900×1000` 纵向深层）。
4. **风格选项准备（C16）**：拟定构型流派、外围大框样式（实线/虚线/无外框）与分箱连线风格（实线为主/虚实结合）选项。
