# 文献综合框架

本文档涵盖论证结构、过渡短语、景观地图叙事模板和空白识别指南。由 `lit module/SKILL.md` Phase 4a-4b 按需加载。所有“共识”“空白”“贡献”句式都只是条件模板：实际成文前必须在 review-evidence.csv 中关联最近先例、原文位置、适用范围和不可声称内容。

---

## 综合 vs 罗列

**罗列**："A 论文发现 X。B 论文发现 Y。C 论文发现 Z。"
**综合**："总体而言，论文 A、B 和 C 表明，当[条件]时，X 成立；但当[替代条件]时，Y 或 Z 更可能成立。"

综合识别跨来源的模式、张力和关系。始终追求综合。

## 文献综述的论证结构

### 结构1：理论争论
适用于有竞争理论解释的主题。

```
开篇："对[现象]，学界提出了两种广义解释…"
第1节：理论A及其证据（3-5篇论文）
第2节：理论B及其证据（3-5篇论文）
张力："这些视角对[X]做出了相互冲突的预测…"
空白（须有证据支持）："在本次检索范围内，尚未发现使用[设计/人群]直接比较两种解释的研究；最近先例为[作者（年份）]，其[具体设计或范围]仍未覆盖这一比较。"
```

### 结构2：历史发展
适用于有清晰学术谱系的成熟领域。

```
早期："关于[主题]的早期研究确立了…"
转型："到1980年代，学者们开始质疑…"
当前证据格局："在本次检索覆盖的[范围]内，多数研究支持…；这一判断的适用边界是…"
前沿："近期工作开始研究…"
空白："然而，[具体局限]仍未解决。"
```

### 结构3：实证版图
适用于发现因情境/人群而异的主题。

```
已知："在已检索的[环境/人群]中，多项研究反复观察到[核心发现]；现有证据仍受[范围或设计]限制…"
变异："然而，效应在[群体A vs. B] / [情境1 vs. 2]间有实质性差异…"
机制："此变异归因于[机制1, 2, 3]…"
空白："在本次检索覆盖的文献中，对[人群/情境/机制]的证据仍有限；最近先例[作者（年份）]的[具体限制]使其不能直接回答…"
```

### 结构4：方法论批判
适用于有方法论贡献的论文。

```
先前发现："过往研究一致发现…"
方法论局限："然而，这些研究依赖[局限：截面数据/自报/选择偏误]…"
我们仍不知道的："没有[更好的设计]，不清楚[发现反映X还是混杂了Y]…"
你的贡献："本研究通过[使用外生变异/纵向数据/等]来解决此局限。"
```

### 结构5：跨学科桥梁
适用于跨社会学与邻域的主题。

```
开篇："尽管[领域A]关注[维度X]，[领域B]则强调[维度Y]…"
领域A贡献："[学科A]已确立[发现]，使用[典型设计]…"
领域B贡献："[学科B]补充了[发现]，使用[不同设计]…"
整合点："这些文献在[共同发现]上趋同，但在[争议问题]上分歧…"
空白："两个传统均未研究[交叉点/机制/人群]。"
你的桥梁："通过结合[A的洞见]与[B的方法/数据]，本文…"
```

### 结构6：计算方法创新
适用于引入新方法（NLP/ML/网络分析）解决旧问题的论文。

```
实质问题："[重要社会科学问题]已被研究数十年…"
传统方法："主导方法依赖[调查/实验/行政数据]…"
传统方法的局限："该方法受限于[规模/测量/生态效度/时间分辨率]…"
计算机会："[NLP/ML/网络分析/计算方法]的最新进展提供了[新能力]…"
先前的计算工作："增长中的文献已将[方法]应用于[相邻问题]，显示[结果]…"
空白（仅在核查后使用）："在本次检索的来源、时间和关键词范围内，尚未发现使用[方法]研究[具体问题]的先例；已有相邻研究[作者（年份）]显示该方法可提供[具体优势]，但尚未检验…"
你的贡献："我们将[具体技术]应用于[数据源]，使我们能够[具体进展]。"
```

## 景观地图叙事模板

### 领域演进叙事模板

```
[主题]的研究自[奠基人作者（年份）]首次[确立/提出/证明][关键洞见]
以来经历了显著转变。在[年代]，该领域由[范式/方法]主导，
学者聚焦[研究内容]使用[主导方法]（作者 年份; 作者 年份）。

[年代]发生了一次重大转变，[作者（年份）]通过[不同做法]
[挑战/拓展/重塑]了这一观点。这项工作[开辟了新问题/解决了一个谜题/
引入了新变量]，引发了一波研究[新焦点]的浪潮（作者 年份; 作者 年份）。

当代格局的特征是[在X上的共识/关于Y的持续争论/
碎片化为Z个子领域]。近期工作[趋势1]（作者 年份），[趋势2]
（作者 年份），以及[趋势3]（作者 年份）。尽管有这些进展，[仍未解决的是什么]。
```

### 争论映射模板

```
争论地图：[理论A] vs. [理论B]

立场A：[一句话总结]
  核心预测：[A对X→Y的预测]
  关键证据：[作者 年份 发现…; 作者 年份 用…证实]
  范围条件：[A在何时何地最成立]
  弱点：[A在何处失败或无法解释]

立场B：[一句话总结]
  核心预测：[B对X→Y的预测]
  关键证据：[作者 年份 显示…; 作者 年份 证明…]
  范围条件：[B在何时何地最成立]
  弱点：[B在何处失败或无法解释]

趋同点：[两传统一致的地方]
分歧点：[它们做出相反预测的地方]
未解决：[什么会解决争论——设计、数据、人群]
```

### 机制叙事模板

```
文献提出了[N]个主要机制，通过这些机制[X]可能影响[Y]。

第一，[机制1——名称和类型]。[作者（年份）]认为[机制解释]。
[支持证据：作者（年份）使用…直接检验，发现…]。然而，
[局限或限定：作者（年份）显示这仅在…时成立]。

第二，[机制2]。[作者（年份）]提出[解释]。与[机制1]不同，
该路径通过[不同渠道]运作。实证支持是[强/混合/有限]：
[作者（年份）]发现[结果]，但[作者（年份）]发现[在…时的矛盾结果]。

在这些机制中，[哪些被直接检验 vs. 仅被假设]。区分很重要，
因为[为什么对该研究问题重要]。
```

### 空白叙事模板

```
本综述识别出[N]个现有文献的关键空白，按其推进理论理解和
实证知识的潜力排序。

最重要的空白涉及[空白1——具体陈述]。最近先例是
[作者（年份）]，他们[做了什么]。然而，[作者（年份）]
[具体局限：未研究[人群]、使用[有限设计]、无法检验[机制]]。
此空白重要因为[理论或政策意义]。

第二个空白涉及[空白2]。尽管[已知什么]，在本次检索范围内仍未找到直接检验[缺失什么]的研究。
[作者（年份）]最接近但[局限]。因此，下一步需要用
[所需数据/方法/设计]检验这一尚待确认的解释边界。
```

## 综合过渡短语

**引入共识（须与证据范围相称）**：
- "在已检索且可核对的研究中，一个反复出现的发现是…"
- "多项研究在[条件/范围]内得到相近结论…"
- "截至[时间/检索范围]，证据大体指向…，但…仍未确定"

**引入分歧**：
- "然而，这一共识受到了…的挑战"
- "然而，一些工作使这一观点复杂化…"
- "当涉及…时，证据不那么清晰"
- "尽管有此，[X]仍然有争议，因为…"

**引入你的贡献**：
- "仍未充分研究的是…"
- "该文献的一个关键空白涉及…"
- "在本次检索范围内，尚未发现直接处理…的先例；最近先例为…"
- "本文在上述证据边界内检验…，并据此评估该解释是否成立"

**连接机制**：
- "这一关系背后的机制是…"
- "这一效应被认为通过…运作"
- "从[X]到[Y]的路径经由…"

**标记时间演进**：
- "关于[主题]的早期工作聚焦…"
- "转折点出现在…时"
- "最近，学者们将注意力转向…"
- "最新一代研究检视…"

**桥接学科**：
- "尽管社会学家强调[X]，经济学家聚焦[Y]…"
- "借鉴[邻域]的洞见…"
- "这一跨学科视角表明…"

**确认无效/负面发现**：
- "值得注意的是，[作者（年份）]未发现显著关系…"
- "这一无效发现有信息量，因为…"
- "[情境]中效应的缺失表明…"

## 引文惯例

### 分组引文
多条论文支持同一主张时，按时间顺序排列：
> "先前研究一致发现教育预测收入（Mincer 1974; Jencks et al. 1979; Card 1999; Goldin and Katz 2008）。"

### 归属特定论证
> "Granovetter (1973) 认为弱关系充当桥梁…"
> "根据 Bourdieu (1984)，文化资本通过…传递"

### 争议主张
> "一些研究发现正向效应（Author1 Year; Author2 Year），而其他研究报告零或负向结果（Author3 Year; Author4 Year）。"

### 质性 vs. 量化发现
> "民族志研究突显[模式]（Duneier 1999; Goffman 2014），这一发现得到调查数据证实（Author Year）。"

### 引用综述文章
> "正如[作者（年份）]在对[N]项研究的全面综述中记录的…"
> "一项对[N]项研究的最近元分析发现平均效应为[d = X]（Author Year）。"

## 空白识别清单

**人群空白**：
- 该现象是否在[代表不足群体：移民、少数族裔、女性、老年人、低社会经济地位]中被研究？
- 美国的发现是否推广到其他国家？
- 关系是否随世代或历史时期变化？
- 交叉性人群（如低收入移民、有色人种老年女性）是否被检视？

**机制空白**：
- 什么解释了为什么X导致Y？机制是否被直接检验？
- 是否有调节条件（谁、何时、何地）尚未被检视？
- 是否存在未被解决的逆向因果？
- 竞争机制是否被实证区分？

**方法论空白**：
- 现有研究是否依赖截面数据而需要纵向数据？
- 是否存在未被因果解决的选择偏误？
- 关键变量是否测量有误？
- 是否有人使用过[新数据源/新方法/计算方法]？

**理论空白**：
- 竞争理论是否做出未被检验的预测？
- 理论是否在所有相关范围条件下被检验？
- 是否存在未解决的理论矛盾？

**时间空白**：
- 基础研究何时进行？世界是否已变化？
- 1990年代的发现是否在2020年代仍成立？
