# 从空白到假设：桥接指南

由 `lit module/SKILL.md` Phase 3 按需加载。涵盖从文献综合到理论再到假设的关键过渡——这是大多数论文成败的关键步骤。识别了真实空白但应用通用理论的论文，理论贡献薄弱。正因为框架解决了已识别的空白才选择该框架的论文，做出了独特的学术贡献。

---

## 1. 空白类型与框架类型的匹配

每种解释空白需要不同的理论操作。

### 空白类型1：人群/情境空白

*X→Y关系已确立，但仅在人群A或情境C中。你正在人群B或情境D中检验。*

**理论操作**：将现有框架应用于新情境，并阐明机制为何应在新情境中操作不同（或相同）。
- 若预期相同机制：论证推广性（范围条件可转移）
- 若预期不同量级：明确情境间不同的调节条件
- 若预期机制失效：命名情境D中阻断机制的结构条件

**框架选择**：X→Y关系的经典框架是起点。你的理论贡献在于明确范围——而非整体导入新框架。

**弱版本**："我们将[理论X]拓展到[新人群]。"
**强版本**："我们将[理论X]拓展到[新人群]，预测机制将被减弱/放大，因为[具体结构条件不同]，这改变了[理论X的关键假设]。"

---

### 空白类型2：机制空白

*X→Y关联已在实证上确立，但路径(M)从未被直接检验。*

**理论操作**：选择一个明确路径的框架——而非仅仅预测关联。框架必须命名中间过程。

**框架选择清单**：
- 框架是否命名了具体的中介状态或过程(M)？
- M能否用现有数据测量？
- 框架是否预测了特定的*中介模式*——完全、部分还是条件性？

**常见错误**：提出的中介变量被结果隐含而非逻辑上先于结果（循环性）。修正：确认X、M和Y的时间顺序和独立性。

**机制检验的假设格式**：
> H1：X与Y正相关。
> H2：X→Y关联部分被M解释（中介假设）。
> H3：X通过M对Y的间接效应在条件Z下更强（有调节的中介）。

---

### 空白类型3：识别空白

*X→Y关联在观察研究中被发现，但因混杂、选择或反向因果，因果关系不确定。*

**理论操作**：理论贡献不是新框架——而是精确阐述为何X导致Y（机制），这也解释了为何在你的设计下选择/混杂不可能。

**框架选择**：你明确的机制是为何预期因果效应的论证。它应该：
1. 逻辑上先于Y（时间顺序）
2. 可信地外生（不由Y或未观察混杂因素导致）
3. 通过命名过程运作，你的设计可部分检验

**识别论文的假设格式**：
> H1（因果主张）：暴露于[X]*导致*[Y]通过[机制M]，如[设计特征：RD, IV, DiD]所证实。
> H2（机制检验）：X对Y的效应在M保持不变时减弱——与M作为操作路径一致。

**语气指导**：识别论文应直接陈述因果假设；仅在设计有明确局限时使用审慎语言。使用"我们估计……的效应"而非"我们检视……的关联"。

---

### 空白类型4：理论争论空白

*两个或更多理论对X→Y做出冲突预测；在已声明的检索范围内，尚未发现能裁决它们的直接检验。该判断须附最近先例及其限制。*

**理论操作**：从每个理论显式推导竞争预测，并展示你的数据/设计能区分它们。

**框架选择**：公平呈现两个理论。贡献在于检验本身，而非先验宣布一个理论正确。

**争论裁决的假设格式**：
> H1a（理论A）：X与Y*正*相关因为[机制A]。
> H1b（理论B）：X与Y*负*相关因为[机制B]。
> *我们的设计通过[设计特征或子群检验]区分H1a与H1b。*

**常见错误**：已经决定理论A正确却框架化为"我们检验理论A"。修正：保持真正的不确定性；让证据裁决；讨论零结果或理论B结果意味着什么。

## 2. 机制规格模板

使用这些从"我有一个理论"过渡到"我有一个可检验的机制"。

### 模板A：单中介链
```
[X] → [M：中介状态或过程] → [Y]

理论基础：[理论]预测X增加M因为[逻辑]。
          [理论]预测M增加Y因为[逻辑]。
可检验含义：控制M应减弱X→Y系数。
```

### 模板B：调节效应（异质性）
```
[X] → [Y]
      ↕ 被[Z：条件/群体]调节

理论基础：[理论]预测X→Y关系仅在[Z条件]下成立。
可检验含义：交互项 X×Z；效应量在Z=1 vs Z=0时不同。
```

### 模板C：调节中介
```
[X] → [M] → [Y]
            中介在[Z = 高]时更强

理论基础：M中介X→Y，但间接路径以Z为条件。
可检验含义：条件间接效应；使用有调节的中介检验。
```

### 模板D：竞争路径
```
[X] → [M1：路径1] → [Y]   (理论A)
[X] → [M2：路径2] → [Y]   (理论B)

双方预测相同X→Y方向但经由不同M。
可检验含义：同时纳入M1和M2；检验哪个更能减弱X→Y系数。
```

### 模板E：抑制/对抗性力量
```
[X] → [Y] 直接：正向效应
[X] → [M] → [Y]：通过M的负向间接效应

净观察X→Y可能为零，即使两个过程都在运作。
可检验含义：纳入M；直接效应和间接效应应有相反符号。
```

## 3. 假设写作规则

**规则1：每条假设必须命名一个理论。**
- 差："我们预期更高收入预测更好健康。"
- 好："与根本原因理论一致 (Link and Phelan 1995)，我们假设更高收入与健康结果正相关，因为收入提供了可用于避免或最小化多重健康风险的灵活资源(H1)。"

**规则2：仅方向性预测。**
- 差："收入与健康将相关。"
- 好："收入与自评健康将正相关。"

**规则3：范围条件写在假设中，而非仅陈述中。**
- 差："我们预期收入对健康的效应被种族调节。"
- 好："我们预期正向收入-健康关联在美国黑人中弱于美国白人，因为[机制：结构性种族主义限制了收入能为美国黑人购买的健康保护资源]。"

**规则4：区分验证性与探索性。**
若预测为探索性（无强方向先验），标明：
> "对[X₂]对Y的影响我们没有强方向性预期；我们探索性地检视此问题。"

**规则5：交叉性假设需要交互语言。**
- 差："我们预期效应因种族和性别而异。"
- 好："我们预期[X]对[Y]的效应在美国黑人女性中大于白人女性或黑人男性——一种无法从种族效应或性别效应单独预测的乘法劣势(H3; Crenshaw 1989; Collins 1990)。"

**规则6：按序编号假设并一致引用。**
理论章节的H1必须与分析策略和结果中的H1匹配。投稿后重命名是审稿人投诉的常见来源。

## 4. 空白到假设流程中的常见失败模式

### 失败1：通用理论应用
**症状**："我们借鉴社会资本理论，该理论已被广泛用于[主题]，来预测[X]增加[Y]。"
**问题**：文献综述所说的缺失与社会资本理论为何解决该缺失之间无联系。
**修正**：陈述具体空白；解释社会资本理论的哪个主张生成了缺失的预测；从该主张推导假设。

### 失败2：漂浮机制
**症状**：机制在陈述中被命名（"这通过网络过程发生"）但从未操作化或检验。
**问题**：无法区分框架是否正确。
**修正**：识别一个可测量的中介变量；将其纳入分析或承认其为范围局限。

### 失败3：大杂烩理论章节
**症状**：5-6个理论被同等地综述；假设来自不同理论却无整合。
**问题**：审稿人无法识别论文的理论贡献；假设显得随意。
**修正**：选择1-2个框架；论证选择；展示其他框架对该空白为何不足。

### 失败4：循环空白主张
**症状**："无研究在我们的具体样本中检视X。"
**问题**：样本新颖性不是空白，除非你能解释为何发现*应在*你的样本中不同（理论原因）。
**修正**：陈述为何机制应在新情境中操作不同（或相同）；推导针对该差异的预测。

### 失败5：从先前工作中平凡推导的假设
**症状**：H1已充分确立；论文用稍微不同的数据集重复它。
**问题**：贡献低；审稿人会问"这里有什么新东西？"
**修正**：将H1重新框架为基线；将H2作为主要贡献（机制检验、异质性发现或范围条件）。

## 5. 过渡短语：从文献综述到理论

**从文献综述引出空白：**
- "尽管有这些进展，一个问题仍未解决：……"
- "这一文献无法告诉我们的是……"
- "先前研究记录了关联但未直接检验机制。"
- "在本次检索范围内，理论A与理论B之间的争论仍未被直接裁决；最近先例为……"

**引出你的理论论证：**
- "我们借鉴[理论X]来检验上述证据边界，并明确其适用条件。"
- "为解释[结果]，我们提出[机制名称]解释，借鉴[理论传统]。"
- "基于[作者 年份]关于[核心主张]的论证，我们将此框架拓展至[新情境]。"
- "我们在一个关键方面与[理论X]的先前应用有所不同：……"

**从论证推导假设：**
- "此论证引出我们的第一个假设："
- "如果[机制]如理论所述运作，我们应观察到……"
- "[框架]因此预测X与Y之间正/负相关(H1)。"
- "将此逻辑延伸至[调节条件]，我们进一步预测……(H2)。"

**承认替代解释：**
- "一个替代解释是[理论B]，它预测[竞争结果]。"
- "我们通过[控制/设计特征/子样本检验]应对此替代。"
- "如果[替代]驱动结果，我们也应观察到[推论]；我们直接检验此点。"

---

## 6. 检查清单：空白到假设流程是否完整？

最终确定理论章节前验证：

- [ ] 空白陈述引用了具体先前论文并精确说明它留下什么未解决
- [ ] 选择的框架正因为解决了该空白而被选中——联系是显式的
- [ ] 机制陈述为 X → M → Y [在条件C下]
- [ ] M可测量或局限被承认
- [ ] H1从机制逻辑推导（而非仅从框架笼统推导）
- [ ] H2（如存在）检验范围条件、中介或调节——而非H1的重述
- [ ] 至少一个替代预测被命名和应对
- [ ] 所有假设编号且有方向性
- [ ] 交叉性假设使用交互语言
- [ ] 理论章节读作单一论证——非理论菜单
